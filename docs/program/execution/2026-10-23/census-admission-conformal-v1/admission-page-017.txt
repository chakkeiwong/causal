C    The policy view and the policies

The view. Static policies receive an evidence graph with inferred stances, surface-based copy groups,
source-type authority proxies, timestamp-based freshness and observing agents. Live policies receive the
candidate text, cited source texts and types, retrievable beliefs, and declared provenance. Live decisions
operate on candidate evidence rather than a fixed set of agent votes. Policies never see the retrieval log,
authored lineage or claim truth.

The policies. B0 never promotes and B1 always promotes. B2 thresholds a confidence proxy, B3 uses
nominal majority support, and B4 requires unanimity. B5 requires two supporting groups after copy col-

without contradiction, abstains under unresolved contradiction, and otherwise defers.
B6 is an LLM judge receiving the same view as text. Two prompt variants were specified before tuning,
