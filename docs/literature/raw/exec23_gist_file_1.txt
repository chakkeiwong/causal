# GIST-CMTF

Artifact repository for the paper **GIST-CMTF: Goal-State Inference for Causal Minimal Tool Filtering in LLM Agents** by Rahul Suresh Babu and Rohit Shukla.

arXiv: https://arxiv.org/abs/2606.16813

## Overview

GIST-CMTF adds an upstream goal-state inference layer to Causal Minimal Tool Filtering. The method predicts candidate symbolic goals, detects ambiguity or missing variables, and exposes clarification as a causal action when the goal is underspecified.

This repository contains the benchmark artifacts, tool registry, runner scripts, result tables, and figure-generation utilities used in the paper.

## Experimental setup

The released artifacts cover:

- 120 controlled tool-use tasks
- 32 tools
- 6 filtering methods
- 7 model backends
- 5,040 model-method-task runs

Request types:

- explicit goal
- ambiguous goal
- missing variable
- clarification required

Compared methods:

- all tools
- state-aware filtering
- top-goal CMTF
- semantic-goal CMTF
- GIST-CMTF
- gold-goal CMTF

## Reproducing paper tables and figures

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python scripts/generate_gist_tables.py
python scripts/generate_gist_figures.py
```

The released CSV files are sufficient to reproduce the aggregate tables and figures in the paper without re-running model calls.

## Full experiment runner

The main runner is provided in `src/gist_cmtf_runner.py`. Re-running the complete model experiment requires access to the model providers used in the paper and local environment configuration for those providers. The released result CSVs are the canonical outputs used for the paper.
