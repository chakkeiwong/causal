# R05S argument review plan

Develop a proposal-level successor argument, not a repeated-sample qualification
or a rewrite of earlier trials. The scope is a partially linear instrumental
variable target, an independent bounded pilot, sparse linear nuisance learning,
and a stationary evaluation sequence with known finite dependence range.

1. Reconcile both R05 attempts. The first attempt's selection, standardization,
   covariance and ignored-scenario defects were already identified and repaired
   in R05-v2. Use the latter as the relevant negative baseline. Re-read the
   primary PLIV score and its actual rate assumptions in the locally saved DML
   paper; do not inherit independent-sample results for dependent rows.
2. Derive the conditional moment bias exactly. Prove a learner-specific bound
   from the lasso basic inequality, a sparse cone eigenvalue and a simultaneous
   empirical/population Gram bound. State which constants are known, which need
   certification, and how approximation error changes the result. Provide an
   independent calibration-risk alternative when a sparse certificate is absent.
3. Derive finite evaluation bands by partitioning a known finite-dependent
   sequence into independent residue classes. Project the joint numerator and
   denominator rectangle without dividing by an estimated near-zero quantity.
   Preserve all set topologies and state how an unavailable error certificate
   changes the result.
4. Reproduce the nonlinear counterexample analytically and check finite moment
   identities by exact arithmetic. Verify the lasso bound on a small orthogonal
   design against its soft-threshold solution and a separate numerical optimum.
   Compare the ratio projection with direct rectangle feasibility.
5. Write the argument and a developed integrated chapter, review every contract
   criterion, record the scoped outcome, compile a preserving reader and continue
   the scheduler. No original capability gap or whole proposal is accepted.

Pre-execution review: a bounded finite-dependent law excludes the prior Gaussian
AR experiment. It must be called a restricted alternative. A population L2
certificate is not supplied by training error or a small KKT residual alone.
Unrestricted temporal dependence, unknown instrument validity, arbitrary
approximation error and useful weak-IV precision remain unresolved. A calibration
risk bound with no lower noise-variance information is valid but may not shrink.
The planned exact examples illustrate these limits; they are not fresh coverage
experiments and have no randomized qualification seed.
