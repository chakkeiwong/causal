\section{A scoped causal-learn reuse decision}
\label{exec14:causallearn-decision}

For the first Python discovery comparison, direct scoped integration of PC from
causal-learn is preferable to porting its search and orientation rules into a
new implementation. FCI remains a separately reviewed profile. The package name
\texttt{causal-learn}, import namespace \texttt{causallearn}, Tetrad's Python
bridge and the similarly named online service are distinct identities. The
selected source revision declares 0.1.4.8 and an MIT root license; six selected
source and license files match the same pinned Git tree. The inspected setup
file declares twelve direct dependencies without version bounds. That is
sufficient for a concrete reuse recommendation, but insufficient for an admitted
executable adapter \citep{exec14_causallearn_reuse}.

The first proposed PC profile assumes complete IID Gaussian observations,
causal sufficiency, acyclicity, faithfulness and no unmodeled selection. Its
output is a graph-equivalence object, not an effect or a confidence level. The
adapter must preserve the node bijection, both endpoint marks and isolated
nodes. A conflict mark produced by PC cannot be interpreted as an FCI latent
common cause. Singular Fisher-Z inverses, invalid effective degrees of freedom
and nonfinite p-values must produce an unavailable numerical query rather than
an independence assertion. Alpha belongs to the named CI procedure and is not
whole-graph or effect coverage \citep{exec14_causallearn_reuse}.

A complete implementation needs a locked executable environment, dependency
rights inventory, method-specific conversion, failure handling and a matched
engine comparison. Porting is deferred because no measured embedding constraint
currently justifies duplicating maintenance. Exposing every algorithm through
one generic operation is rejected for the initial adapter because their
assumptions and output meanings differ. R pcalg and Java Tetrad remain useful
comparators with separate contracts. Authentic bank validation is not a
prerequisite to this source-based proposal decision; it is a later condition
for a bank-specific scientific or operational claim
\citep{exec14_causallearn_reuse}.
