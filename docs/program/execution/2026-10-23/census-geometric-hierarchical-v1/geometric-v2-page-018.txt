    To establish the ergodicity of the noise, we assume the domain Ω is infinite and that the group’s
action can mix around the elements of the domain. Intuitively, this ensures the model generates
enough diverse examples to learn the i.i.d. noise distribution nonparametrically. For simplicity, the
condition below assumes discrete domains Ω and groups G; for continuous spaces Ω = Rd and the
group of shifts G = Td , Maruyama’s theorem guarantees ergodicity [Krishnapur, 2014, Dym and
McKean, 1976].
Assumption 2 (Mixing action on Ω). Let Ω and G be countable and infinite. Assume there exists a
sequence of index transforms ϕn ∈ G such that for any finite subset of the domain, S ⊂ Ω, |S| < ∞,
we have |ϕn (S) ∩ S| → 0 as n → ∞.
Note not all elements of G need to be index transforms, just a subset. To illustrate the condition,
we check the group of permutations, defined formally as S = ∪∞     n=1 S(n), where S(n) is the group of
permutations that act on the first n elements of the sequence. Choose ϕn ∈ S to be the permutation
that swaps the first n positions with the second n positions, ϕn (ω) = ω+nI(ω ≤ n)−nI(n < ω ≤ 2n).
Then |ϕn (S)∩S| = 0 for all n ≥ maxω∈S ω. Likewise for arrays, we can choose ϕn as the permutation
that swaps the first n rows and the first n columns with the second n rows and second n columns.
Overall, the intuition behind Assumption 2 is that no element of Ω is privileged: we can always use
transformations in the group G to map ω to an infinite number of other elements.
    With this assumption in place we can show GCMs are ergodic.
Proposition 2 (GCMs are ergodic). Let Assumption 2 hold for the action of G on each ϵv and xv
for v ∈ [V ]. Then the distribution p(xC ) for any C ⊆ [V ] is ergodic.
The proof is given in Section B.2. Taking C = Vobs , we find p(xVobs ) is ergodic, and so we can learn
the observational distribution of a GCM from a single sample.

6.2   Identification
We can learn the observational distribution of a GCM. Now, we identify the effect of an intervention,
computing it from the observational distribution and its conditionals.
   In GCMs, as with conventional causal models, we can identify with do-calculus.
Proposition 3 (do-calculus in GCGMs). Consider the effect of an intervention do(a = a⋆ ) on y,
where y and a may be individual variables or, more generally, non-overlapping subsets of xV . If
the causal effect p(y; do(a = a⋆ )) is identified by do-calculus on the graph G, it can be computed as
a functional of the joint distribution p(xVobs ) and its conditionals, p(y; do(a = a⋆ )) = ψ(p(xVobs )),
with ψ(·) the identification formula from do-calculus.
The proof rests on the fact that GCGMs follow a Markov decomposition according to their causal
graph, just like conventional causal models (Section B.3).
    Proposition 3 tells us that if an effect is identified by do-calculus, it is identified in a GCM. We
now consider the reverse direction: if an effect is identified in a GCM, can we compute it by do-
calculus? For conventional causal models, the answer is yes: do-calculus is complete [Shpitser and
Pearl, 2006]. For GCMs, the answer depends on the structure of the group action: so long as the
group transforms structured variables just by index transforms, and we do not add any restrictions
on the causal mechanisms, do-calculus is complete.
Proposition 4. Assume every ϕ ∈ G is an index transform (Assumption 1). Then if an effect
p(y; do(a = a⋆ )) can be computed as a functional of p(xVobs ), it can be computed by do-calculus.
The proof is in Section B.4.
    For group with actions that are not index transforms, do-calculus can be incomplete. For
example, consider the GCM in Figure 5, which has an instrumental variable (IV) graph. The
causal effect p(y; do(a⋆ )) is not identified by do-calculus [Pearl, 2009]. But the GCM respects the
orthogonal group. Now, the average effect becomes identified, under regularity conditions.
