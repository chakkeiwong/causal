Algorithm 3 S ERVE: online certified query serving
Require: running core (At , Rt , Cachet ); query q; k carrier traces; depth budget δ
Ensure: certified answer, or explicit abstention with any fallback flagged uncertified
 1: S1 Grounding Bridge: ground the traces via interface I; decline if the required agreement fails
 2: S2 Source Check: check agreed query facts against their source evidence using S OURCE mode
    of Algorithm 1; scope these facts to the query
 3: S3 Derivation Check: use D ERIVED mode to check a complete witness for q over the current
    checked premises
 4: if the gate returns CERTIFY then
 5:      S4: serve the certified answer
 6:      S5 Schedule: consider its witness for caching when f (q) > fc (q)
 7:      S6 Allocate: select among eligible witnesses under σ(X) ≤ B by partial-enumeration
    greedy
 8: else
 9:      decline explicitly; label any optional fallback uncertified
10: end if
11: S7 Premise Amendment: on source withdrawal or expiry of query-scoped facts, cascade-evict
    dependents, recompute the kernel, and revalidate surviving cache certificates

C2 (closure fidelity). Premise selection, theorem retrieval, and automated proof search depend on
entailment. Equivalent formulations of a lemma are interchangeable for this criterion. C2 holds.
C3 (redundancy). Proof libraries contain substantial derivable material (corollaries, specialized
instances, alias lemmas). The scan of Algorithm 4 is run per AFP session with the library order as ≺;
PO is taken (a) uniform and (b) proportional to downstream dependency counts (how often a lemma
is used as a premise), the latter approximating the service distribution. The protocol hypothesized
1 − PA ≥ 0.6 under both readings. A first kernel-verified run on a 14-entry subset finds 1 − PAu ≈
20% (uniform) and 46.7% with a τ -crossing interval (weighted). See Table 6.
C4 (depth and frequency). Derivation depth is the shortest premise-chain length in the dependency
DAG; the frequency surrogate is the dependency count. AFP-scale graphs have shallow depth (or-
der 10–102 ) and heavy-tailed usage, so a budget δ at the 95th percentile is affordable and query
frequencies span several orders of magnitude around fc . The kernel-level run supports C4, with
shallow depth (quantiles 0/2/3/4, max 10) and heavy-tailed usage (frequency quantiles 1/4/82) on
real proof-term dependencies.
