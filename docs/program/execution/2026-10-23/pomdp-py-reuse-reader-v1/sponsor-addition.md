# Treat hidden-state planning as a supplied-model service

POMDP-Py 1.3.5.1 provides useful model, belief, history and planner interfaces,
but a search result cannot establish that a bank's hidden-state model is
identified or its observation law is correct. Thirteen authenticated files at
the selected October 2025 revision support a reference-only reuse decision.
Complete adoption, native integration and an unrestricted optimal-policy
uncertainty claim remain unqualified.
\citep{exec23_pomdppy_sources}

An exact example shows why the observation law matters. With prior distress
probability 1/4 and a stipulated diagnostic sensor, posterior distress is 1/2
after a positive signal and 1/10 after a negative signal. A rescue action worth
USD 35 in distress and USD -15 otherwise gives expected net USD 7/4 when used
only after a positive signal, including a USD 2 test cost. If the actual sensor
is uninformative, the same policy gives USD -13/4. Better search of an incorrect
sensor model cannot repair that scientific gap. These are authored finite-law
examples, not measured banking or package performance.
\citep{exec23_pomdppy_reference}

The inspected numerical contracts need explicit qualification. An impossible
observation can leave a zero-mass histogram; a restricted next-state set can
silently renormalize away omitted support. Particle depletion is an explicit
failure, and repeating survivors does not create new evidence. Weighted
duplicate-state probability queries and sampling can imply probabilities 1/2
and 2/3 in a simple example, while ordinary unweighted particles override those
paths and preserve frequency 2/3. The proposed worker must distinguish these
representations and their failure modes.
\citep{exec23_pomdppy_sources,exec23_pomdppy_reference}

The planner's outer time check runs between simulations. A rollout repeatedly
choosing a zero-duration option can fail to advance, so an independent deadline
is required. Option reward clocks also matter: a two-step example gives value
15 under undiscounted internal rewards versus 11 under primitive-step discounting.
The finite policy-tree recurrence gives 13/8 where ordinary one-step discounting
gives 7/4 in a three-stage unit-reward example. The alternative small-state value
routine uses one-step discounting under its own finite deterministic assumptions.
These are static and exact-reference findings, with no native execution claim.
\citep{exec23_pomdppy_sources,exec23_pomdppy_reference}

The prototype route is concrete: bind complete model/source/compiler/runtime
identities and rights; resolve belief, history, duration, arity and horizon
contracts; run independent finite-state and adverse fixtures; then measure
search quality, time, memory and recovery. Library, CLI and MCP must return
the same supplied-model target, proposed action, diagnostics and refusal reasons.
An LLM can help formulate candidate states or diagrams, but cannot authenticate
the hidden observation law by supplying a plausible description.
\citep{exec23_pomdppy_sources}

native capability, scientific qualification, bank validation and adoption separate.
