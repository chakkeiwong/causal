196: class _RLearner(_OrthoLearner):
197:     """
198:     Base class for CATE learners that residualize treatment and outcome and run residual on residual regression.
199: 
200:     The estimator is a special of an :class:`._OrthoLearner` estimator, so it follows the two
201:     stage process, where a set of nuisance functions are estimated in the first stage in a crossfitting
202:     manner and a final stage estimates the CATE model. See the documentation of
203:     :class:`._OrthoLearner` for a description of this two stage process.
204: 
205:     In this estimator, the CATE is estimated by using the following estimating equations:
206: 
207:     .. math ::
208:         Y - \\E[Y | X, W] = \\Theta(X) \\cdot (T - \\E[T | X, W]) + \\epsilon
209: 
210:     Thus if we estimate the nuisance functions :math:`q(X, W) = \\E[Y | X, W]` and
211:     :math:`f(X, W)=\\E[T | X, W]` in the first stage, we can estimate the final stage cate for each
212:     treatment t, by running a regression, minimizing the residual on residual square loss:
213: 
214:     .. math ::
215:         \\hat{\\theta} = \\arg\\min_{\\Theta}\
216:         \\E_n\\left[ (\\tilde{Y} - \\Theta(X) \\cdot \\tilde{T})^2 \\right]
217: 
218:     Where :math:`\\tilde{Y}=Y - \\E[Y | X, W]` and :math:`\\tilde{T}=T-\\E[T | X, W]` denotes the
219:     residual outcome and residual treatment.
