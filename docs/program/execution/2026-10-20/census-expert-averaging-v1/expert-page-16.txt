F     LLM case study

F.1   Setup

In addition to a simulated expert, we conduct experiments with an LLM expert, using OpenAI’s gpt-
5-nano-2025-08-07 for all experiments. While we average all results across 20 seeds (consistent with
our other experiments), calls to the LLM were cached across seeds and sample sizes for cost saving
purposes, such that only one call to each of acceptConnection and determineOrientation is
made for the same variables. To reduce ordering sensitivity, we query the LLM with both possible
argument orders, and use the LLM’s choice only if it is consistent across both orders; otherwise, we
fall back to a majority vote among the ensemble models G. We use our standard hyperparameter
settings: θ1 = 0.0, θ2 = 0.9, B = 2N .
We exclude two networks from the case study: the Pathfinder network due to the lack of semantically
meaningful variable names, and the Formed network due to a high number of diagnostic rather than
causal edges (e.g. Violence → Age, ViolentConvictions → Violence). We also test only
the clean versions of the networks. The structure of the noisy versions of the networks differs only
by the inclusion of latent confounders, which are not directly considered in the current prompts, as
we believe handling latent confounders with expert input deserves targeted experiment design—as
such, it poses an interesting avenue for future work.
