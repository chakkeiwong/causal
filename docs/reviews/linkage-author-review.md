## Reconstruction of the mathematics

**Target and rank.** The fixed financial vector retains the induced-balance
interest cost and full horizon covariance. Within each stratum the average
candidate contrast equals the average true contrast; the half-difference
equals `(2p−1)` times the true half-difference. At p=1/2, a compatible
observed difference is zero and the focal portfolio value is unrestricted
within these mean restrictions while the other portfolio compensates.
The final review explicitly separates this outer moment-model set from a
sharp identified set for the full mixture distribution. Label switching
demonstrates named-portfolio ambiguity, but richer distributional restrictions
can still identify unordered components. Correctness-count audits also differ
from outcome-linked audits that can directly inform response estimation.
No sign convention silently assumes
p>1/2. The reversed regime and two-ray finite example check that boundary.

**Primitive uncertainty.** Four transformed response bands receive total
error alpha/2, hence individual two-sided error alpha/8 and normal quantile
1−alpha/16. Covariance is reduced after the complete date-level HAC matrix
is formed. Pilot independence, correct finite basis, nonvanishing response
information, fixed horizons and stable dependence remain restrictions. The
binomial interval inverts each tail at alpha/8, giving each audit total error
alpha/4. Its finite proof uses the ordered rejecting counts; no large-audit
normal approximation is substituted. Zero audit records yield [0,1].

**Coverage.** If all primitive parameters lie in their Cartesian region, the
true financial value lies in its projected set, including at exact rank one.
A union bound supplies 1−alpha plus the response approximation error. This
does not require independence between response coordinates, or additional
rank strength. The binomial component is finite-sample; the response component
is asymptotic. Uniformity across changing linkage probabilities is conditional
on a uniform primitive-band approximation, not proved by a pointwise CLT.
The implementation rejects zero estimated transformed variance because it
does not support an exact singleton sampling law in that case.

**Algorithm.** On each side of zero rank, extrema of D/r occur at rectangle
corners, with signed infinite limits. A region containing both D=0 and r=0
permits the whole real line. A singleton zero-rank region excluding zero
difference is incompatible and yields the empty set. Adding average intervals,
then forming fixed-weight Minkowski sums, retains disconnected components.
No bounded grid or convex hull silently truncates the answer. The independent
primal check fixes v and intersects the four-corner image of r(v−S) with the
difference band; all 16,800 comparisons agree. Binomial count enumeration
over sizes 1–25 and 201 probabilities has minimum nominal-.95 coverage .950958.
These finite checks corroborate the algebra, not the time-series theorem.

**Alternatives.** The first pilot's separate candidate-mean rectangle lost
substantial common-shock covariance. The fixed sum/difference transform was
selected before final draws and retained against that original challenger.
Neither shape is claimed uniformly superior. The manuscript also derives
the candidate-specific variance for a residual test and explains the further
critical-value/nuisance-elimination work a sharper procedure would require.
Ellipsoidal projection, a calibrated residual test and the preserved joint
Bayesian model address substantive precision or modeling choices. They are
not presented as interchangeable software switches with inherited coverage.
