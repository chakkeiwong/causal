48:         treatment exposure.
49:         Default is ``False``.
50: 
51:     use_other_treat_as_covariate : bool
52:         Indicates whether in the multiple-treatment case the other treatment variables should be added as covariates.
53:         Default is ``True``.
54: 
55:     force_all_x_finite : bool or str
56:         Indicates whether to raise an error on infinite values and / or missings in the covariates ``x``.
57:         Possible values are: ``True`` (neither missings ``np.nan``, ``pd.NA`` nor infinite values ``np.inf`` are
58:         allowed), ``False`` (missings and infinite values are allowed), ``'allow-nan'`` (only missings are allowed).
59:         Note that the choice ``False`` and ``'allow-nan'`` are only reasonable if the machine learning methods used
60:         for the nuisance functions are capable to provide valid predictions with missings and / or infinite values
61:         in the covariates ``x``.
62:         Default is ``True``.
63: 
64:     datetime_unit : str
65:         The unit of the time and treatment variable (if datetime type).
66: 
67:     Examples
68:     --------
69:     >>> from doubleml.did.datasets import make_did_CS2021
