20.13.2     Why an unrestricted latent answer can be the whole line

There is a constructive witness, not just a numerical timeout. For any observed positive definite
covariance, regress A and Y on Z and let their residual variance/covariance be vA , vY , c. For
any proposed effect b ∈ R, choose BA,Z = ΣZA /ΣZZ and BY,Z = ΣZY /ΣZZ − bBA,Z . The two
structural residuals then have covariance w = c − bvA and variances vA and v = vY − 2bc + b2 vA .
Their determinant is vA v − w2 = vA vY − c2 > 0. Set

             ℓ2A = 21 (vA + w2 /v),       ℓY = w/ℓA ,   DA = vA − ℓ2A ,   DY = v − ℓ2Y .

Both error variances are positive, and a single latent root shared by A, Y reproduces the
covariance for every b. The broad class therefore contains observationally equivalent models
with every effect value. The implementation checks this equality for several widely separated
values; the algebra, rather than the grid of checked values, establishes the unrestricted witness.

20.14      A faster graph search can preserve the wrong relationship
Before a bank asks whether a higher deposit rate attracts balances, it must distinguish the
effect of changing the rate from the information that led it to offer that rate. A graph search
can help compare explanations, but its computational shortcuts have scientific consequences. A
link retained because the search stopped is a different finding from a relationship that survived
the relevant tests.
   The detailed Java comparison in Section 35.4.2 identifies a concrete difficulty in the inspected
Aitiotita revision. Beyond conditioning depth two, one skeleton-search path tests a pair
conditional on the union of its neighbours. If dependence persists, it marks the link undeletable
and omits subsequent subset searches. That rule would be safe only if dependence after adding
variables excluded independence under a smaller conditioning set. The retained generic callback
allows independence procedures for which that implication fails. (Aitiotita contributors, 2023)
   This study examines a repair: continue the declared subset search, and report an unfinished
search explicitly when its budget is exhausted. The calculations compare project implemen-
tations with exact independence oracles. They do not execute the Java distribution. The
distinction matters because the inspected bundled linguistic oracle is not a Gaussian test, and
the orientation and graph-export stages require separate evaluation.

20.14.3     A computation budget should leave an honest question open

A depth limit can be sensible when there are many variables. It changes what has been learned.
In the depth-two comparison, 165 cases return a skeleton different from the generating one.
Each of those cases is explicitly marked incomplete because larger neighbouring conditioning
sets remain untested. The same warning also appears in some cases whose returned skeleton
happens to be correct. A stopping rule cannot know that fortunate outcome without doing
the omitted work or imposing additional justified restrictions.
   For the hypothetical bank, a retained X–Y link is therefore insufficient grounds to value a
repricing policy. A report should distinguish the independences actually found, the remaining
candidate links, and the search that was left unfinished. A graph skeleton alone also leaves
arrow directions and intervention effects unresolved. The economic next step may be stronger
pre-decision measurement, a justified model restriction or an experiment; another graph-search
heuristic need not supply the missing fact.
  The proposal recommendation is to retain full subset search as the declared reference and
exclude this all-neighbour freezing rule for a general Gaussian-oracle adaptation. A bounded
implementation should return an incomplete-search result when it stops early. Native package
comparisons, sampling calibration, orientation, prior-knowledge enforcement and endpoint
preservation remain distinct prototype tests. This result closes a specific repair question
and sharpens the software selection; it does not close the complete Java survey or establish

20.15.3     What is compared on the same observations

For each mechanism and each sample size n ∈ {100, 500, 2000}, the study generates 200
independent samples. It applies thresholds α = 0.01 and 0.05 to three searches: full stable
subsets, the all-neighbour dependence screen and a depth-two cap. This gives 1,800 datasets
and 10,800 search results. The methods receive identical observations within each comparison.
The depth cap keeps its unfinished-search flag whenever relevant larger sets remain.
  To reveal the consequence of graph errors, an explicitly naive rule chooses baseline variables
that are adjacent to both X and Y in the estimated skeleton. It then regresses Y on X
and those selected variables using the same observations, reporting an ordinary 95 per cent
Student-t interval for the coefficient on X. The later score C is always excluded from this
regression by its information date. This rule is a diagnostic comparator; common estimated
neighbours are not asserted to be a valid general adjustment criterion. The reference regression
uses every stipulated baseline cause.
   Coverage means the proportion of the 200 intervals that contain the known intervention
effect. It is distinct from graph recovery. A graph can be wrong in an economically irrelevant
edge while the selected adjustment is correct, or it can lose exactly the variable needed to
remove confounding. The study does not isolate the pure penalty from reusing observations
after selection: its interval failures combine selection, omitted confounders and inappropriate
confidence in the resulting regression. Splitting the sample would not by itself make an invalid
adjustment set valid.
