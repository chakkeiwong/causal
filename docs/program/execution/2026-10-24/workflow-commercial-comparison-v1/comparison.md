# Commercial workflow comparison

Eight families; edition/runtime qualification remains inconclusive. All treatment is already integrated in the current monograph.

| Family | Documented strength | Main remaining evidence |
|---|---|---|
| Databricks | Documents partial repair and run monitoring, including explicit warnings about non-idempotent tasks and current repair settings. | Authenticate cutoff manual/API and supported workspace/runtime profile; bind task repair, run-history retention, configuration and append/idempotency behavior. |
| Snowflake | Documents dependency graphs, finalizers, retries and overlap; task-graph versioning does not automatically bind called procedure bodies. | Acquire cutoff edition/version originals; bind stored-procedure snapshots, suspended/skipped tasks, overlap, retry and retention contracts. |
| Microsoft Azure Machine Learning | Documents reuse comparisons over code, environments, inputs, parameters and run settings; determinism is declared. | Pin cutoff component/SDK/API/environment and inspect reuse/cancellation/export semantics, identity, entitlement and failure outcomes. |
| AWS Step Functions | Documents ordered retries/catches, redrive and failure-class distinctions; retries have billing implications but no price is inferred. | Authenticate cutoff service/schema and Standard/Express profile, execution limits, redrive/error classes, idempotency and applicable pricing units. |
| Dataiku DSS | Scenario control, trigger/run distinction and explicit outcome handling; client source exposes cancellation-before-run and strict success behavior. | Bind immutable supported DSS server/client matrix, trigger precedence, full variable/clock and error contracts; qualify no_fail cancellation path and rights. |
| SAS Viya | Workflow prompt/request machinery and asynchronous job resources, state links, provider-specific results and logs are documented. | Acquire supported normative workflow and Job Execution schemas, complete state/errors and client/server matrix; separate Visual Investigator case-management from analytics workflow. |
| Domino | Job identity, start/stop/status/restart and revision controls; source review distinguishes transport retries, reauthentication and remote restart. | Acquire immutable v4/jobs terminal/error/idempotency schemas and supported server matrix; solve the dependency lock and register connection/read/status/restart cases. |
| Posit Workbench and Connect | Typed scheduler states/exit codes, plugin boundary and Connect task/job/schedule clients; sample Local backend has explicit unsupported cancellation. | Select supported Workbench/Launcher/Connect and SDK builds, backend, privilege/network/output profile; qualify nonzero exits, missing artifacts, kill/cancel races and conformance coverage. |

Current dispatcher exposes declared graph syntax, supplied-DAG back-door expression, supplied-moment Gaussian residual inversion, quadratic sensitivity and clock diagnostics. Preserved IN04 trials establish scoped local library/CLI/MCP parity, durable artifacts and local faults; they do not establish these commercial integrations.

No platform price, native trial or comparative ROI is inferred.
