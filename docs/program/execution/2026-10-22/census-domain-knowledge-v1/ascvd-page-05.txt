                                   Chain of Thought Prompt
                                   All three runs of the chain of thought prompt produced acyclic and nearly complete DAGs, with all DAGs missing only
                                   race (Figure 4). Additional variables like physical activity and BMI were included in Runs 1 and 2. None of the runs
                                   provided sources, but each included justification for variables and python code to generate the DAG. Overall, the chain of
                                   thought prompt provided consistency across runs, with output following a systematic methodology breaking the task
                                   down into clear steps such as identifying variables, constructing relationships, and implementing the DAG. The DAGs
                                   produced by the chain of thought prompt primarily focused on confounders and only Run 3 included mediators and risk
                                   factors.
