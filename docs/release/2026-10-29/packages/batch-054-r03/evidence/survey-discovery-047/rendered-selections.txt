34.1     Start with the banking comparison
A bank considering a causal library faces several different purchasing and engineering decisions.
It may need a defensible effect of an invitation, a description of plausible causal directions
among funding variables, or a policy for repeated servicing decisions. A package that produces
a directed graph does not necessarily answer the first question. A package that estimates an
average treatment effect does not necessarily answer the third. The survey therefore takes a
scientific operation as its unit of comparison: an input with a declared observation law, a causal
target, assumptions connecting the two, and an output whose meaning survives conversion
into the bank’s units.
   This choice changes what counts as competitive capability. Consider a request to increase
deposit funding by changing the offered rate. A system that returns several compatible
effects has provided useful information if the observations cannot distinguish their underlying
mechanisms. A system that returns one number after choosing a convenient graph may have
answered a more restrictive question. The comparison must expose the restriction before
comparing accuracy, speed or convenience. Similarly, a symbolic expression for an effect and
an estimate of that expression are different accomplishments. The expression identifies what
information is needed; its numerical evaluation adds statistical and computational obligations.
  The proposed common request is

                                  q = (U, T , O, A, Y, Ψ, G, S),                           (34.1)

where U specifies the eligible population and sampling unit, T the decision and measurement
clocks, O the observed variables and their units, and A the feasible intervention. Y specifies
the outcome and horizon. The functional Ψ is the requested causal quantity; G contains the
graph or graph class and its substantive restrictions; S describes sampling and uncertainty.
For example, one row may represent one independently sampled eligible customer, the action
may be a 25 basis point increase offered before account opening, and the outcome may be
net funding value over the next quarter. These declarations are scientific inputs. A software
interface cannot establish them merely by accepting a table with suitable column names. The
developed comparison below follows five R discovery paths from their documented outputs
to the intervention question. It supplies the graph, effect and unit distinctions behind the
broader selection in Chapter 26; it does not claim to exhaust the software landscape.

and reporting the resulting decision sensitivity.

   This structure also clarifies survey coverage. The fraction of predefined comparison cells
with a reviewed disposition measures completion of that declared plan. It does not estimate
the fraction of all software in the world that has been found. Ranked bibliographic results
have unknown inclusion probabilities, aliases can occupy several results, and broad queries

   A practical extension procedure is to search exact package names and aliases, method names,
implementation languages and competing commercial descriptions; then inspect the primary
technical sources for the resulting candidates. Reference following adds implementations that
keyword choice may miss. Backward and forward search have different date constraints: a
later search service can locate an earlier work, but a post-cutoff technical revision must not
be presented as the earlier implementation. Conflicting manuals or source versions create a
comparison question that needs resolution at a specific version. A later edit cannot silently
repair what a preserved earlier inspection established.
   The stopping rule should be chosen before interpreting omissions. A bounded proposal
pass may inspect a fixed number of query pages and one reference generation, retain every
discovered identity, and defer unresolved leads. Those are resource limits on the search, not
absence findings about a market. For a consequential adoption choice, the stopping condition
is stricter: each proposed operation needs its technical source, deployment and rights path,
alternatives and a testable behavior contract. If an essential source is missing, that adoption
decision stays conditional while other comparisons continue. This makes the unknown part of
the landscape visible and gives the next search a reason tied to a decision.


34.10       A matched comparison includes eligible requests and
            justified refusal
The common contract makes it possible to define a fair comparison before measuring a package.
First choose a service regime: for example, Gaussian iid discovery and singleton linear effects,
with the same named variables, sampling unit, units and background restrictions for every
candidate. Then separate three case families. In the first, the target is identified and a
reference is available. In the second, several causal models remain observationally compatible
and an effect set is the reference. In the third, the request violates the service regime or lacks
necessary input. A correct response in the last two families can be an unresolved set or a typed
refusal. Forcing every case into a point-estimate error would reward unsupported answers and
penalize scientifically useful ambiguity.
  Let zi indicate that case i has a reference answer within the agreed service, and let rij
indicate that path j returned a valid answer. Eligible availability is

36.1     Choose the observation experiment before the discovery
         engine
A bank may want a causal diagram for several quite different reasons. It may need to identify
an adjustment set for an offer, investigate whether a funding relationship survives a policy
change, or decide which experiment would resolve an ambiguity that matters financially. These
uses do not imply the same learning problem. A discovery engine can be useful while leaving
the effect unresolved; it can also orient more edges under assumptions that the bank has no
reason to accept. The proposal therefore treats discovery as a conditional inference about
a declared observation experiment, followed by a separate decision about what the inferred
object permits.
   Let V = (V1 , . . . , Vp ) denote the measured variables, G a causal graph and P their observa-
tional distribution. The observed data may be independent customer records, selected records
conditional on inclusion S = 1, trajectories Vit indexed by customer i and physical time t,
or observations from regimes e with different intervention targets. The symbol P must be
expanded accordingly. A pooled table need not represent independent observations from one
distribution. Independence across customers does not establish independence across their
months, and differences across regimes need not be interventions on the variables named by
an analyst.
   A discovery request should first state its admissible model family M, the observed law
or laws and the graph object it seeks. Under causal sufficiency and the relevant acyclicity,
Markov and faithfulness conditions, an observational conditional-independence procedure
can aim at a Markov equivalence class represented by a CPDAG. With hidden or selection
variables, the appropriate ancestral-graph representation and its guarantees change. Temporal
and interventional methods add further restrictions concerning lags, regimes, mechanisms and
sampling. The pcalg, Tetrad and causal-learn comparisons make these differences concrete at
their actual interfaces. (pcalg contributors, 2026; cmu-phil/tetrad, 2026a; py-why/causal-learn,
2026; Colombo et al., 2012)
   There are then three separate outputs to consider. The first is an estimated structural
object, such as a CPDAG, PAG, fitted structural model or candidate DAG. The second is
the collection of causal answers compatible with that object and the declared assumptions.
The third is a statistical statement about the uncertainty of the complete procedure. An
estimated graph is not automatically a confidence set for graphs. A collection of effects

36.4      Hidden variables and selection change the object being
          learned
Unmeasured borrower risk, market shocks and selection into a reviewed sample can invalidate
a causally sufficient graph interpretation. Introducing a hidden node in a diagram is not
enough: the learning procedure and the representation must preserve the relevant conditional-
independence and ancestral information. An ancestral graph can represent relationships
after marginalizing hidden variables. A partial ancestral graph records invariant endpoint
information across a class, with circles retaining unresolved marks. Its directed edge is not
generally a promise that an unconfounded regression coefficient equals a direct causal effect.
The inspected ancestral-graph definitions and the software comparisons distinguish these
meanings. (Zhang, 2008; pcalg contributors; CRAN source mirror, 2024a)
   FCI and RFCI illustrate why even two outputs called PAGs need additional method identity.
The RFCI definition permits an adjacency with a weaker interpretation than the corresponding
FCI adjacency. Its graph can retain edges that a more extensive search removes, and can
correspond to more than one Markov equivalence class. The oracle soundness statement
assumes a faithful distribution and the required conditional-independence information; it
is not a finite-sample confidence claim. The faster procedure is therefore a substantive
information/computation alternative, not a lossless substitute whose edges can automatically
be read under the stronger definition. (Colombo et al., 2012)
  Selection is equally concrete. Let X and U be independent fair binary variables, let Y = U ,
and retain a record only when S = 1, where S = 1{X = U }. The four population configurations
each have probability 1/4, while the retained sample consists of (X, Y ) = (0, 0) and (1, 1)
with equal conditional probability. Its observed conditional contrast is one. Yet replacing the
equation for X leaves U and Y unchanged, so the population intervention contrast is zero.

36.6     Interventions provide information only under a mecha-
         nism contract
Regimes are scientifically informative when their relation to the system is specified. Under
a perfect intervention on a target set I, the original mechanisms for variables in I are
replaced, while the stipulated mechanisms outside I remain unchanged. In the inspected
interventional-equivalence formulation, observations are independent across draws but need
not be identically distributed across known targets. A conservative target family leaves each
variable unmanipulated in at least one regime; an observational regime supplies that property.
This condition should not be confused with a claim that every such experimental design
identifies every graph direction. (Hauser and Bühlmann, 2012)
   The likelihood contribution of a variable’s original mechanism should not come from rows
on which that mechanism was replaced. This explains why regime-to-row maps and target
indices are part of the score, not incidental metadata. The inspected pcalg GIES path includes
R preprocessing, conversion to native indices, local-score configuration and a distinction
between an essential graph and a representative. The Python GIES and UTIGSP-related
comparisons likewise need their actual target, test and dependency contracts. Unknown targets
and soft interventions are separate methodological questions; the assumptions of one known-
target procedure cannot be silently transferred to them. (cran/pcalg, 2024; juangamella/gies
contributors, 2025; uhlerlab/causaldag contributors, 2022)

What an effect multiset would mean for a bank

Let the observed vector contain an offered rate change X, an intermediate customer response
M , and a monetary outcome Y . The initial model is a linear Gaussian structural system with
independently sampled units, no hidden common causes and a distribution faithful to its causal
DAG. The sampling unit could be a customer in a stipulated independent-unit experiment;
repeated customer months cannot be relabeled as independent rows. The graph search
estimates conditional independence structure. Its significance level is a level for individual
tests, not a confidence level for the entire graph or for the effect of a future bank action (pcalg
contributors, 2026).
  For a compatible DAG G, the singleton total effect is the derivative

uses admissible local parent configurations. They need not attach the same multiplicity to
a numerical value. Neither construction turns a frequency in this multiset into a posterior
probability of a graph (pcalg contributors, 2026; pcalg contributors; CRAN source mirror,

A correlation matrix alone is insufficient to restore monetary units. Further, naming X an

exclude competing graphs; vocabulary alone cannot. Sampling uncertainty remains a separate
obligation even when a graph class has been correctly represented.

   FCI+ supplies a different search strategy. Its method paper bounds the number of oracle
independence tests by order N 2(k+2) for N observed variables and a fixed bound k on node
degree. The result presumes the faithful acyclic model and the stated oracle conditions while
allowing latent variables and selection. Polynomial order at fixed k is not a practical runtime
promise, and the paper notes that sample versions can use larger conditioning sets and lose
power. The proposal should compare FCI+ as an alternative under the same generated regimes,
without translating the complexity result into a bank-scale performance claim (Claassen et al.,
2013).

Options are scientific choices, not cosmetic settings. The pinned implementation
exposes normal, anytime and adaptive-anytime FCI. A finite m.max restricts conditioning-set
size. A distinct parameter, pdsep.max, is checked against the size of a candidate Possible-D-
SEP set: when that size exceeds the limit, the selected code skips the corresponding search. It
does not simply enumerate all subsets up to that order. A job that reaches the limit therefore
needs an explicit restricted-search disposition. A faster answer is not automatically equivalent
to an unrestricted run (pcalg contributors; CRAN source mirror, 2024a).
   Missing conditional-independence results require equal care. In the inspected Possible-D-
SEP path, NAdelete=TRUE maps a missing test result to one and can remove an edge; false
maps it to zero and retains the edge in that path. This is a software rule, not evidence that
the missing result establishes independence or dependence. The proposed adapter should
retain the missing-test count and reason and apply an explicit admission policy. It should
not silently use either behavior to manufacture certainty. Hard-coded gaps and edges likewise
encode supplied restrictions; their provenance and sensitivity belong in the scientific result
(pcalg contributors; CRAN source mirror, 2024a).
   Conservative or majority-rule orientation reduces particular ambiguities but does not imply
full order invariance. The order-independent methods paper distinguishes stable skeletons,
decisions about unshielded triples and the subsequent orientation rules. RFCI can remove
further edges using order-dependent separating sets, so even a stable initial skeleton does not
make its final skeleton fully invariant. The package manual retains this warning. Permuting
the input columns and translating back to the original labels is therefore a useful proposed
diagnostic, not a theorem that the selected route must already pass (Colombo and Maathuis,
2014; pcalg contributors; CRAN source mirror, 2024a).
   Selection and context options must be admitted together. FCI and FCI+ default to allowing
selection bias. Setting selectionBias=FALSE imposes its absence and disables the selected
selection-related orientation rules. In this pinned implementation nondefault JCI assumptions
require the no-selection setting. A branch or policy-regime label is not automatically an
exogenous, unconfounded randomized context. The proposed workflow must ask why that
context restriction is justified and whether account inclusion is compatible with it. The wider
cyclic and JCI theoretical claims require their own source and method review; this comparison
does not inherit them from an exposed argument name (pcalg contributors; CRAN source
mirror, 2024a).

A restricted integration path and its alternatives. The preferred addition to the
proposal is an isolated R FCI/RFCI comparison route that preserves PAG versus RFCI-
PAG semantics and all endpoint marks. FCI is the richer reference; RFCI is the explicitly
less informative alternative when the proposed workload makes the full search unattractive.
FCI+ remains a candidate subject to complete diagnostic accounting and matched resource
evaluation. The initial PC/IDA path remains appropriate only when its separate causal-
sufficiency assumptions are defended. The existing Python and Java comparisons offer
independent implementation candidates, but equal algorithm names do not establish equal
defaults, conversion conventions or statistical outputs.
   Direct adoption of an arbitrary returned graph as a bank decision is rejected. A wholesale
port is also not yet justified: it would inherit a large scientific verification burden, and moving
the same logic into another language would not resolve latent information or selection. The
immediate reuse choice is a narrow adapter with explicit test, search and diagnostic contracts.
The package’s previously inspected GPL declaration and dependency inventory remain relevant
to any distribution decision; this scientific selection grants neither a new licensing conclusion
nor deployment approval.
   The proposed qualification should begin with independently specified independence oracles
and small known graphs, then use generated samples with hidden causes, selection, weak
associations and missing tests. It must retain all requests, budget exits and graph ambiguities;
compare FCI, RFCI and FCI+ on the same declared laws; and separate native numerical
behavior from serialization correctness. Endpoint pairs, isolated nodes, invalid graph types,
column permutations, diagnostic completeness and search truncation need individual fixtures.
Only after those results should a decision study evaluate whether a justified effect or refusal
changes contact policy value. No package execution, finite-sample calibration or accepted R
adapter is claimed by the present source review.
