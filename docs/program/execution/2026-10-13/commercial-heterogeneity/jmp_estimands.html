Statistical Details for Causal Estimands and Estimators

A causal estimand is a causal effect that you are interested in estimating. An estimator is a function that takes data as input and produces an estimate of the estimand. Different estimators correspond to different methods.

This section describes the two causal estimands that can appear in the Causal Treatment report when the treatment is binary. When the treatment is continuous, the Causal Treatment report shows mean potential outcome estimates. For more information about the continuous treatment scenario, see Statistical Details for Continuous Treatment Methods.
