## Findings resolved during source and manuscript review

The new audit inspects 21 technical bodies and one license notice across eight
packages at the inherited cutoff pins. A source file containing a symlink target
was excluded from technical-body counts. The actual grf binding, predictor
factory and native strategy were fetched and inspected before linking the R
operation to native semantics. The initial guessed native path's 404 is retained.
No GitHub API/OpenAlex retry loop or collector allowlist change occurred.

The review follows reachable code, rather than interpreting isolated formulas.
grf's early guard rejects clustered/sample-weighted TMLE even though later
branches contain cluster expressions. Low-level statsmodels HAC support is not
attributed to every treatment-effect wrapper. LiNGAM's target/source orientation
and row versus residual bootstrap paths are explicit. Delicatessen's contribution
unit is not silently inferred from row labels.

Two new source-level adoption concerns remain open for runtime reproduction:
pygformula handles a None bootstrap result inconsistently between filtered
results and bootests, and the inspected CausalGPS kernel path stores a
standardized-residual density without the Jacobian for the original exposure
measure. These are specific source observations. No observed failure frequency,
whole-package defect, downstream effect or external bug report is claimed.

The five project examples are independently specified calculations. The graph
example checks an asymmetric direct-plus-mediated response. The score example
separates individual and group cross-products without suggesting validity with
only two groups. The competing-event example declares within-period ordering
and does not interpret eliminated-event arithmetic as an identified intervention.
The density example checks heterogeneous scales and physical unit conversion.
The orthogonal-score identity conditions on an independent same-law pilot and
retains its identifying moment assumption. None is a package execution test.

The source-audit builder initially rejected an out-of-range y0 anchor (58,
then 57, versus 56 actual lines). The anchor was corrected before any audit
was written. This was an evidence-bookkeeping failure, not a source finding.
