# Runtime identity and preserved uncertainty

A supported panel service needs an exact interpreter and dependency profile. The selected R development source identifies itself as 4.7.0 under development, a separately pinned 4.6-branch source as 4.6.1 Patched, and the installed interpreter as 4.1.2. These are different evidence objects. Repository acquisition alone does not establish a buildable or installed lock. [@exec29_panel_runtime_sources; @exec29_panel_runtime_reference]

Covariance order provides a concrete integration test. In an authored object with original coefficient order (a,b), pivot order (b,a), triangular factor diag(2,1) and dispersion one, a score (1,0) gives quadratic form 1/4 if the pivot-order covariance is consumed positionally and one after alignment. The installed-R fixture reproduces this distinction. It does not demonstrate that the selected fastdid default solver reaches that pivot, or that native package uncertainty is defective. The proposed adapter aligns by coefficient identity and retains solver status, rank and aliases. [@exec29_panel_runtime_sources; @exec29_panel_runtime_reference]

Two additional contracts need explicit public trials. Positive-integer packed-bit signs differ from independent symmetric signs under an ideal-uniform reference law; the exact counting discrepancy at 31 bits is small and is not a measured coverage defect. Selected data-frame reconstruction restores attributes from the first input, which can leave mixed interval levels described by one table attribute under the default route. The service should preserve row-group uncertainty provenance and qualify the full native generator, header and reconstruction paths before stronger claims. These are executable proposal requirements, not assertions that the product already exists. [@exec29_panel_inference_sources; @exec29_panel_runtime_sources; @exec29_panel_runtime_reference]
