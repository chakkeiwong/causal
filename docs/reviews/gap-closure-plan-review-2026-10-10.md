# Review of the proposed V6.1 gap-closure program

10 October 2026 (Asia/Shanghai). Author plan review, not independent review
or evidence that the proposed capabilities have been implemented. The
[plan](../program/gap-closure-plan-2026-10-10.md) is a response to the user's
request to distinguish known closure routes from unresolved questions.

## Disposition

G1 has a direct, reproduced repair. G2 has a known conservative validity route
but an unresolved useful-precision outcome. G3-G5 have concrete routes in
declared model and information classes, with broader identification and
scalability outside the guarantee. G6 has known engineering mechanisms and
selected statistical routes; actual performance remains empirical. Preparation
of the plan is complete. No new scientific study, manuscript revision or public
implementation repair is claimed by this review.

## Challenges applied to the plan

| Challenge | Required treatment in the proposed execution |
|---|---|
| Calling a phase complete could again conceal an unsupported capability | Record scholarly completion separately from capability support and usefulness; negative results cannot become a passing capability claim. |
| Adding warning text could be mistaken for repairing undercoverage | G1 changes result meaning and propagation only; C03 separately diagnoses and evaluates the statistical procedure. |
| A new default might silently change existing users' targets/inference | Introduce an explicit method in a versioned request and document migration; no result-dependent method selection. |
| Ellipsoids might be described as universally tighter | Keep the rectangle challenger and register the procedure; covariance exploitation can help but neither region shape dominates everywhere. |
| Local optimization could remove a confidence-set tail | Require global outer enclosures or conservative fallback; retain zero-rank limits, disconnected components and numerical nonresolution. |
| Exact binomial audit intervals might be promoted to finite-sample validity of the whole procedure | Preserve the asymptotic response condition and the actual audit sampling law. |
| Persistent linkage could merely rename independent per-origin swaps | Hold the map fixed through each trajectory and derive uncertainty using independent pairs. A repeated date is not another independent map audit. |
| A new sampling design could silently inherit common-calendar inference | Explicitly identify the independent-pair target and reject combination with a common-calendar score without a joint sampling argument. |
| A nonlinear filter could be mistaken for identification | Specify the nonlinear transition, observation, logger and reward law, anchor the state with independent labelled audits, and derive full-rank identification first. |
| Removing transition nonlinearity alone could be called an exact Gaussian reference | Also remove private-state dependence from the logistic logger; otherwise conditioning on actions produces non-Gaussian information. |
| Audit or training uncertainty could disappear from policy intervals | Include the actual independent audit sample in parameter uncertainty; target the fixed pilot-trained policy conditionally on training. |
| A score check could be called a global optimum or certified numerical bound | Report local modes and failures; distinguish observed grid/particle convergence from a proved numerical enclosure. |
| A discovered graph could receive confidence after sample splitting alone | Project a simultaneous observed-law region through all retained structures/parameters; sample splitting does not validate the selected graph. |
| A finite Gaussian episode could be called unrestricted temporal discovery | State its finite observation window and sampling model; dependence, longer hidden history and selection require new arguments. |
| Hand-imposed parameter bounds might fabricate an informative effect | Bounds are substantive prespecified restrictions; otherwise return unboundedness or unresolved computation. |
| Source authority could be confused with semantic truth | Retain false-assertion and missing-candidate cases and request missing evidence; no assertion-authenticity check certifies its meaning. |
| The bounded sparse theorem could be pasted onto the Gaussian funding model | Reconcile the model, nuisance rates, gaps and covariance conditions before reusing an inference guarantee. |
| Scale claims might time only a convenient kernel | Measure complete equivalent work, memory and I/O with stage accounting; test restarts and retain slower parallel outcomes. |
| The plan might move the goalposts to universal theory or bank deployment | Qualify representative bounded extensions; treat general unresolved problems and external acceptance as separate obligations. |

## Feasibility gates that remain open

The plan does not establish useful ellipsoidal precision, a practical certified
projection optimizer, actual nonlinear coverage, a scalable latent graph
confidence algorithm, arbitrary dependent-learner validity or multi-host
performance. Those are outcomes of the proposed execution, not plan-review
passes. Each research branch first needs its precise assumptions and source
review, then an independent small reference, a preserved pilot and a registered
final design. If identification or numerical reliability fails, report the
counterexample or unresolved condition before committing to a large study.

No change to the 7 October literature cutoff or new current-literature search
is claimed. The existing source ledgers and inspected manuscript arguments
support selection of these investigation routes; new theorems and source-based
claims will need their own proof and primary-source audit during execution.
The accompanying [evidence record](gap-closure-plan-evidence-2026-10-10.json)
identifies the inputs and plan/review bytes without changing the frozen V6.1
delivery. No sibling edits, external communications or agent delegation are
part of this planning work.
