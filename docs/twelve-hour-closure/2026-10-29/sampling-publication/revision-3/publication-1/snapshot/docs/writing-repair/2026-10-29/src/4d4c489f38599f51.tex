\section{C++ temporal engines: row identity, shock meaning and uncertainty}
\label{sec:exec25-cxx-dynamic}

A funding desk asks how a one-unit tightening of its funding spread changes lending and liquidity over the next eight quarters. A matrix of forecasts answers that question only after the unit, ordering, information clock and intervention have been fixed. A posterior distribution over autoregressive coefficients does not itself identify the policy shock. A fast native kernel also cannot recover an entity or date that its wrapper has assigned to the wrong row. The useful comparison therefore begins with the complete request: entities and calendar, observed variables, target shock, identifying restrictions, forecast origin, horizon, output type and uncertainty law. C++ is an implementation language in this comparison; several candidates expose their supported workflows through R or Python.

Four authentic source collections provide distinct alternatives. BMR bundles BM++ kernels for Bayesian VAR and time-varying parameters. The inspected BMR description says version 0.11.0, dated 24 June 2018, while its selected repository revision is dated 20 November 2018. The bsvars revision of 29 September 2026 carries development version 4.0.0.9000 and a description dated 24 August 2026. The bssm revision of 24 September 2025 identifies version 2.0.3. Dazhong Wu's panelvar revision of 24 March 2023 has a Python version module reporting 5.2.0 and a CMake project reporting 0.1.0; those identifiers must not be silently equated. All selected revisions precede the client cutoff of 7 October 2026. The discussion concerns inspected paths in these revisions, not current release guarantees.~\citep{exec25_cdyn_bmr,exec25_cdyn_bsvars,exec25_cdyn_bssm,exec25_cdyn_panelvar}

\subsection{Panel identity precedes the GMM calculation}

For bank $i$ at calendar date $t$, consider
\[
 y_{it}=\rho y_{i,t-1}+x_{it}'\beta+a_i+u_{it}.
\]
Lagged-level and differenced instruments require explicit moment restrictions on $u_{it}$, the regressors and initial conditions. A pseudoinverse supplies a numerical choice for a singular matrix; it does not supply those restrictions. The selected panelvar core constructs first- and second-step GMM results. Its inverse helper unconditionally calls an Eigen complete-orthogonal-decomposition pseudoinverse. The requested coefficient and covariance step is separate from the inspected Hansen calculation, which uses the second-step weighting matrix and moment vector. These are separate fields that an adapter must preserve.~\citep{exec25_cdyn_panelvar}

The wrapper deserves equal scrutiny. It converts observed entity and time labels to categorical codes and uses the number of observed time categories as the panel width. It calls a sorting method without retaining the returned object, then assigns incoming values into a dense array selected by a membership mask. The mask selects destination rows in destination order; it does not itself join incoming values by key. An authored example makes the distinction explicit. Incoming row keys $(1,0,3,2)$ with values $(20,10,40,30)$ require key-ordered values $(10,20,30,40)$. Positional assignment into the selected dense rows instead preserves $(20,10,40,30)$. This is a source-path risk for unsorted inputs, not a reported execution failure of an installed package. Duplicate keys and missing entity/date combinations need separate tests.~\citep{exec25_cdyn_panelvar,exec25_cdyn_choice}

Calendar identity is another condition. With dates $(2000,2002,2003)$ and values $(10,20,30)$, a positional lag is $(\mathrm{NA},10,20)$, whereas a one-year lag is $(\mathrm{NA},\mathrm{NA},20)$. Creating the Cartesian product of observed labels does not invent the omitted year 2001. The native lag-table constructor also initializes output to missing and copies a lagged value only when the current value of the same variable is nonmissing. Thus instrument availability can depend on a current-value guard as well as the lagged observation. The proposal must specify whether the desired instrument can exist at a date whose current measurement is absent, then compare that rule with the selected implementation.~\citep{exec25_cdyn_panelvar,exec25_cdyn_choice}

A second exact witness uses the repeated-moment matrix
\[
 W=\begin{pmatrix}1&1\\1&1\end{pmatrix},\qquad
 W^+=\frac14\begin{pmatrix}1&1\\1&1\end{pmatrix},\qquad WW^+W=W.
\]
There are two raw columns but rank one. The identity verifies the authored pseudoinverse arithmetic, not a package-specific rank threshold or a distributional theorem. A public qualification fixture must report moment rank, effective parameter rank, requested covariance and diagnostic denominator together. In the inspected Hansen helper, the p-value uses the chi-square CDF, but the field named critical value is populated by a density evaluated at 0.95 rather than a quantile. That field must not be presented as a 95\% cutoff without repair and a native regression test. The surrounding wrapper's stability and p-value screening is a model-selection rule, not independent confirmation of exclusion restrictions.~\citep{exec25_cdyn_panelvar,exec25_cdyn_choice}

This candidate is useful as a direct C++/Python comparison and a potential narrowly repaired adapter target. Direct adoption is deferred until keyed alignment, calendar gaps, moment rank, requested-step diagnostics and complete output status have been qualified. Reimplementation of its equations would require an independent mathematical specification and numerical reference; copying a solver alone would preserve none of these contracts.

\subsection{BMR separates posterior draws, shocks and frozen-time responses}

Write a reduced-form VAR as
\[
 y_t=c+\sum_{\ell=1}^{p}A_\ell y_{t-\ell}+D x_t+\varepsilon_t,
 \qquad \operatorname{Var}(\varepsilon_t)=\Sigma.
\]
BMR's embedding helper stacks matrix row offsets. Its selected conjugate VAR path joins exogenous regressors separately. The impulse response uses a lower Cholesky factor of $\Sigma$, or a different construction when long-run restrictions are selected. For $C=I-\sum_\ell A_\ell$, that latter path constructs $C\operatorname{chol}(C^{-1}\Sigma C^{-T})$. Invertibility and the chosen ordering are numerical and substantive conditions that must be stated. Neither factorization independently proves that the first innovation is a bank funding intervention.~\citep{exec25_cdyn_bmr}

The optional stationary-draw rule rejects coefficient draws until the maximum modulus of the companion eigenvalues is less than one. The inspected loop has no explicit iteration cap. A service contract therefore needs an external work budget, cancellation and a retained attempted/accepted draw count. Those controls change operational behavior; a truncated sampler cannot be described as an unmodified posterior sample without further justification. Compiler, BLAS and random-number implementations remain part of the artifact contract.

Forecasting has two branches. One propagates coefficient draws and sampled future innovations; the other suppresses future innovations. Both advance the endogenous lag slots while leaving the supplied external entries fixed in the inspected routine. A request containing a changing future macroeconomic path cannot be treated as equivalent to the fixed external vector. The distinction also explains why a distribution of conditional means can be narrower than a predictive distribution for future observations. The adapter must label which object it returns.~\citep{exec25_cdyn_bmr}

In the time-varying-parameter IRF routine, one coefficient time slice is selected and then held across response horizons. A frozen local response is useful, but differs from a response propagated through a changing future coefficient path. In an authored scalar example, a current coefficient $1/2$ gives a frozen two-step response $1/4$; coefficients $1/2$ and $3/4$ along successive transitions give $3/8$. No native BMR run supplies these numbers: they are exact calculations showing why the proposed API needs a frozen-time versus evolving-path tag. BMR is retained as a reference and possible bounded integration candidate. A port should follow a separately reviewed specification of these choices, not expose every output under a generic causal-response name.~\citep{exec25_cdyn_bmr,exec25_cdyn_choice}

\subsection{bsvars: conditioning, recursive regressors and failure denominators}

The inspected bsvars structural convention can be represented as
\[
 B\left(y_t-Ax_t\right)=u_t,\qquad
 \operatorname{Var}(u_t)=\Lambda_t,
 \qquad \Sigma_t=B^{-1}\Lambda_tB^{-T}.
\]
Its response helper starts with $B^{-1}$, includes horizon zero and optionally scales each impact column by its own diagonal entry. Sign normalization separately searches sign combinations relative to a benchmark matrix. Scaling, sign normalization and substantive identification solve different problems. A zero diagonal impact makes that particular scaling unsuitable; a benchmark sign convention is not additional evidence about the true policy shock. Public fixtures should retain the unscaled response and the transformation applied to it.~\citep{exec25_cdyn_bsvars}

The conditional-forecast helper partitions fixed and free coordinates and uses the Gaussian conditional mean and Schur complement. With unit marginal variances, covariance $1/2$ and the first coordinate fixed at two, the second coordinate has conditional mean one and variance $3/4$. In an authored common-cause model with the same observational covariance and no causal arrow between the coordinates, intervening on the first coordinate leaves the second mean zero and variance one. The observational covariance alone cannot choose between these semantics. A funding stress scenario described as a conditioning event must not be relabeled an intervention by the CLI or an LLM agent.~\citep{exec25_cdyn_bsvars,exec25_cdyn_choice}

A concrete wrapper-to-kernel contract concerns recursive lag shifts. The R wrapper prepares a next-origin vector with the latest dependent values, previous lags, a constant and optional exogenous columns. The selected C++ update prepends the simulated next observation and appends the old vector beginning at index $N$, where $N$ is the number of dependent variables. For two variables and two lags, an authored old vector $(10,20,7,8,1)$ and new observation $(11,21)$ give $(11,21,7,8,1)$ under that expression; ordinary lag advancement requires $(11,21,10,20,1)$. The one-lag case does not expose this particular mismatch. This scoped source finding requires a native fixture with the exact wrapper and artifact before any claim about released runtime behavior.~\citep{exec25_cdyn_bsvars,exec25_cdyn_choice}

Output uncertainty also needs a precise name. The stored covariance slices are the per-step innovation matrices $B^{-1}\Lambda_tB^{-T}$ along a draw, while recursive sample paths can accumulate earlier innovations. Even with fixed parameters, an AR(1) coefficient $1/2$ and unit innovation variance have two-step forecast-error variance $5/4$, not one. A conditional-mean field calculated before imposing a fixed observation need not equal the conditional mean after that restriction. These distinctions must survive serialization.~\citep{exec25_cdyn_bsvars,exec25_cdyn_choice}

The inspected forecasting function catches selected sampling exceptions by breaking the horizon loop, then returns its output containers without an explicit failure mask. A wrapper cannot infer successful completion from the container shape alone. Qualification must inject a controlled failing draw, inspect every horizon and record attempted draws, complete draws, partial draws and refusals. The proposal retains bsvars as a strong structural-model comparison and a candidate for a version-specific adapter after these contracts are verified. It rejects a generic forecast-to-intervention conversion. No installed artifact or upstream test has been executed for this review.

\subsection{bssm: missing observations, singular covariance and prediction types}

For a scalar observation of a latent state, write
\[
 y_t=D_t+Z_t'\alpha_t+H_t e_t,\qquad
 \alpha_{t+1}=C_t+T_t\alpha_t+R_t\eta_t.
\]
In the inspected bssm univariate Gaussian filter, a nonfinite observation skips the measurement update, while the transition still adds $R_tR_t'$. With unit initial variance, identity transition and unit process variance, two missing observations leave predicted state variances two and three. Dropping the missing rows would change the model clock and the uncertainty. The same selected branch is taken when the innovation variance fails the default threshold $10^{-12}$. An adapter must distinguish an absent observation from a finite observation judged numerically degenerate.~\citep{exec25_cdyn_bssm,exec25_cdyn_choice}

A small positive variance is not always negligible evidence. For residual one and innovation variance $1/(2\cdot10^{12})$, the residual quadratic is $2\cdot10^{12}$, yet the inspected update predicate is false at the default threshold. This authored boundary example motivates an explicit exact-observation or numerical-refusal rule; it does not establish the behavior of every bssm model. The likelihood also has an initial noise-factor guard, which must be exercised separately. Tests should vary the observation scale and tolerance without silently replacing an impossible observation by missingness.~\citep{exec25_cdyn_bssm,exec25_cdyn_choice}

The helper named for positive-semidefinite Cholesky removes directions with effectively zero diagonal and Cholesky-factors the retained principal block. That handles a particular degeneracy. The rank-one matrix with all entries equal to one has positive diagonal, so it retains both directions and reaches an ordinary factorization of a singular block. This is a different case from a zero-variance coordinate. The inspected R initial-covariance validator checks numeric type and dimensions; it does not establish positive semidefiniteness. A qualified adapter needs a declared admissible covariance class, explicit failure behavior and a reference for singular positive-diagonal cases.~\citep{exec25_cdyn_bssm,exec25_cdyn_choice}

Prediction types are substantive. The selected kernel simulates state transitions for state and conditional-mean outputs; response output adds measurement noise. Thus a sampled conditional mean still varies through state uncertainty. A unit state variance and measurement variance four produce response variance five in the authored scalar witness. Reproducibility also spans two random-number systems: the R wrapper samples posterior indices and passes a separate seed to the C++ engine. Freezing only the latter does not freeze the whole request. bssm is retained as a state-space integration candidate within a frozen model family; it is not admitted as a general causal identification service.~\citep{exec25_cdyn_bssm,exec25_cdyn_choice}

\subsection{From source comparisons to an executable public qualification plan}

The practical choices are conditional. For panelvar, first qualify keyed preprocessing and diagnostic fields, then consider a narrow repaired C++/Python adapter. For BMR, preserve its posterior, recursive identification, exogenous-path and frozen-time conventions in a reference implementation before choosing integration or a port. For bsvars, qualify lag recursion, conditional semantics, normalization and failure accounting on the exact artifact before structural-workflow integration. For bssm, bind a declared state family, covariance class, missing-step rule and two-stage RNG identity. None of these routes is blanket approval of a package, all its dependencies or redistribution rights.~\citep{exec25_cdyn_choice}

The recorded source declarations are GPL version 2 or later for BMR and bssm, GPL version 3 or later for bsvars, and MIT for the inspected panelvar root. BMR and bssm use RcppArmadillo with selected debug checks disabled; bsvars specifies Armadillo and native linear-algebra settings; the panelvar build contains architecture-specific flags and fixed Python/Eigen paths. Those observations establish declared source and build conditions, not a complete legal or binary-equivalence review. A service boundary is an engineering choice and does not by itself settle distribution obligations.~\citep{exec25_cdyn_bmr,exec25_cdyn_bsvars,exec25_cdyn_bssm,exec25_cdyn_panelvar}

Before expensive bank experiments, freeze public known-law fixtures for sorted and unsorted panels, duplicate keys, missing dates, repeated instruments, VAR lag orders one and two, correlated shocks, normalized responses, missing-state steps and singular covariance. The proposal library, CLI and MCP must carry the same entity/date digest, origin, lag convention, shock scale, restriction set, prediction type, parameter/draw identity, failure status and cost denominator. A schema-valid response must not promote conditioning into intervention or source inspection into native qualification. Package wrappers, native kernels and a project-authored reference should be compared separately so that a discrepancy has a traceable location.~\citep{exec25_cdyn_choice}

The present rational witnesses run only project-authored code. They establish comparison targets and failure hypotheses, not native performance. As a hypothetical cost illustration, USD 24,000 divided by 800 attempted, 600 completed or 400 accepted requests is USD 30, USD 40 or USD 60 respectively. Real costs and accepted utility remain unmeasured. The source search also remains bounded: broad C++ panel queries contain many solar-panel projects, precise queries can return no hits, and relevant projects may be classified by their wrapper language. Retain those denominators and uninspected leads; a zero-result query is not an absence proof. Complete remaining delegates, native artifact qualification, dependence-sensitive uncertainty and actual banking restrictions before claiming full temporal coverage.~\citep{exec25_cdyn_choice}
