LLM as a representation assistant Given the unstructured data X, we aim to make use
of the rich knowledge of LLMs to assist in converting meaningful unstructured information
in a structured form. Formally speaking, we seek a mapping h : X 7→ W which serves as a
structured representation W = h(X). We present the following definition:
Definition 1 (Representation Assistant) An Representation Assistant for the un-
structured data X with domain X is defined by a set of high-level factors W ≜ {W1 , . . . , Wk }.
Each factor Wi is induced by a prompt instruction (e.g., a natural language query), which
specifies a deterministic mapping wi : X → Ci via an LLM Ψ. Here, Ci ⊆ R is a predefined
numerical set (discrete or continuous), and Wi = wi (X) is a random variable with range
Ci . The structured representation is the concatenation:
                                                             
                             h X = W = W1 , W2 , · · · , Wk .

    Each factor is defined by a specific prompt instruction so that an LLM can decide
a value based on a sample x (drawn from X). For example, given a customer review
on an apple x(j) , an LLM-proposed factor wi with C = {−1, 0, 1} could be described as:
wi (x(j) ) = 1 if the customer appreciates the sweetness of the apple; wi (x(j) ) = −1 if the
customer is disappointed about the sweetness; and wi (x(j) ) = 0 if the sweetness has not
been mentioned. In addition, a factor instruction can require LLM to utilize external tools
for further processing.
Active causal representation elicitation In this work, we propose Causal represen-
tatiOn AssistanT (COAT) framework to actively elicit representations consisting of factors
W to reveal causality in different settings.
   • Given a target variable Y ∈ U, COAT-MB (Section 3.2) finds factors W that serves a
     Markov Blanket of Y with respect to X, i.e., Y ⊥
                                                    ⊥ X | W. That is, W captures all
     relevant information about Y from X;
   • Furthermore, based on COAT-MB, COAT-PAG (Section 3.3) extends the structured
     input set to V ≜ W ∪ U so that the causal information, i.e., skeleton or arrow heads,
     among U can be maximally revealed in the partial ancestral graph PV with the node
     set V;
   • In causal inference setting, for a treatment-effect pair T, Y ∈ U , COAT-ADJ (Sec-
     tion 3.4) extends structured input set to V ≜ W ∪ U so that valid adjustment sets
     within U for the causal effect on T → Y can be found by graphical criterion on the
     partial ancestral graph PV with the node set V.
