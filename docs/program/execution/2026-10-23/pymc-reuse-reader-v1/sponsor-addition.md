# Keep model surgery and prediction separate in a Bayesian worker

PyMC supplies useful machinery for a bank-specific probability model, but a
causal proposal must state which mechanism is replaced and which variables are
generated afterward. Twelve authenticated source, documentation and test files
at the selected 7 October 2026 development revision support a reference-only
disposition. The version is dynamically derived; this is not a verified named
release. Its Python and PyTensor ranges, root Apache-2.0 terms and actual
dependency artifacts belong in a future locked worker environment.
\citep{exec23_pymc_sources}

Conditioning on a treatment differs from replacing its assignment mechanism.
In an exact authored model with hidden borrower type, the observed association
is four outcome units but the intervention effect is two. At a stipulated
USD 100 per unit and action cost USD 250, an association-based calculation
reports net USD 150 while the causal model gives USD -50. Two other structural
models produce exactly the same observed law while allowing effects one and
zero. Posterior computation can be numerically accurate while the model choice
remains unresolved by those observations. These are proposal witnesses, not
package benchmarks or observed bank returns.
\citep{exec23_pymc_reference}

Prediction needs an explicit trace contract. Output selection does not request
regeneration; stored random variables can remain frozen after upstream data
change. Replacing a deterministic square by a cube can also reuse stored values
unless regeneration is requested. The illustrative two-point means are 5/2
and 9/2. Potential factors need separate attention because they are not
generative rules, although posterior ancestors may already encode their effects.
Model and expression identity, frozen variables and regenerated variables must
therefore travel together across library, CLI and MCP.
\citep{exec23_pymc_sources,exec23_pymc_reference}

A prototype should pin the sampler and backend as well as the model. Conditional
default selection can change the numerical engine; external samplers reject
some trace and callback paths. Missing divergence or trajectory-depth statistics
produce no corresponding warning, so diagnostic absence must remain distinct
from an inspected satisfactory result. Register finite and conjugate oracles,
intervention/prediction checks, warnings, effective samples, compilation, memory
and persistence before claiming native qualification. Scientific owners still
need to justify causal assumptions and policy uncertainty. An LLM may draft a
model, but neither the generated graph nor a successful sampler certifies it.
\citep{exec23_pymc_sources}
