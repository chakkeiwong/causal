# C: discovery and decision-relevant ambiguity

Specification v1, 8 October 2026. Query: total effect of a feasible action
variable on a later financial outcome, over a declared class of structural
models consistent with observations and background knowledge.

C-G starts with independent Gaussian vectors and a finite candidate DAG
class. For a fixed dimension and full-rank covariance, construct a joint
confidence region for covariance entries (including covariance estimation
error). Map the entire region through every admissible DAG's structural
restrictions and effect formula. The resulting union covers all compatible
effects when the true covariance lies in the region. Do not discard a
candidate graph only because a CI null was not rejected. Exact finite-state
or low-dimensional enumeration supplies a reference to approximate search.

Use a three-variable chain, collider and hidden-confounder examples to
separate observational equivalence, sampling error and model misspecification.
Evaluate set coverage, size, decision sign ambiguity and computational
failure. Background time restrictions may remove candidates; they are
explicit supplied knowledge. An experiment on the action can remove an
ambiguity that arbitrarily precise observational covariance cannot.

C-T selects a stationary lagged graph model with a specified maximum lag,
contemporaneous structure, sufficiency/latent assumptions and observation
operator. Compare a qualified temporal conditional-independence route with
a functional-model alternative only on its justified subclass. Specify
dependence and test tuning; retain endpoint marks through effect queries.
Without inferential graph-set coverage, report exploratory graph alternatives
and effect sensitivity, not a nominal effect confidence band.

Adverse cases include near-unfaithfulness, latent confounding, insufficient
lag windows, rescaling and coarse-time sampling. Screening is part of the
statistical model when it can remove confounders. Scaling evidence must
include search, inference and unresolved query cost.

Existing primaries: kalisch2007, zhang2008, perkovic2018, runge2020,
gerhardus2020, peters2017 and id2006. Read the exact scope of graph recovery
and generalized adjustment before selecting software. Product output is a
graph class plus a common functional, effect set or explicit unresolved
question, not merely a preferred DAG.

Execution disposition: C-G uses nine exact Gaussian variance pivots and
conservative interval propagation over all 25 DAGs. Near-unfaithfulness,
supplied time order and a hidden-common-cause failure were run with 500
replications. Exact checks span all DAGs, including colliders. C-T selects
a supplied structural Gaussian VAR1 class and maps the simultaneous OLS
coefficient box to responses. Its independent-innovation martingale
argument supplies inference; omitted lag two is an adverse failure.
The theoretical comparison with PCMCI+, LPCMCI and non-Gaussian functional
models remains in the discovery chapter, without runtime qualification of
those broader packages. This is a bounded inferential method choice,
not a claim that generic temporal discovery was executed.
