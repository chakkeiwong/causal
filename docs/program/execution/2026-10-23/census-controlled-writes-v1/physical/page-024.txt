Proof of Corollary 1. Fix the cache before erasure. In the witness DAG, recovery fails iff a missing
leaf has a cache-free path to the root: tracing a failed uncached node backwards finds a failed
parent and eventually such a leaf; conversely, a missing leaf propagates failure along any uncached
path. This is the local failure-path argument of Xu (2026c, Lemma 3.1 and Theorem 3.1). Thus
recovery is precisely the event that every leaf in the fixed set Dexp (q; X) survives. Independence
gives (1−ε)|Dexp (q;X)| . Adding a cache segment cannot create an exposed leaf. Since 0 < 1−ε < 1,
the probability strictly increases iff that set shrinks.

Scope of the cache model. Corollary 1 models storage loss while the cache survives and source
support remains valid. Withdrawing source support invalidates dependent certificates under Theo-
rem 1, so recovery in that setting requires a separate model. Theorem 4 states the shared-module
and complexity results.
