2:     """Double machine learning data-backend.
3: 
4:     :class:`DoubleMLData` objects can be initialized from
5:     :class:`pandas.DataFrame`'s as well as :class:`numpy.ndarray`'s.
6: 
7:     Parameters
8:     ----------
9:     data : :class:`pandas.DataFrame`
10:         The data.
11: 
12:     y_col : str
13:         The outcome variable.
14: 
15:     d_cols : str or list
16:         The treatment variable(s).
17: 
18:     x_cols : None, str or list
19:         The covariates.
20:         If ``None``, all variables (columns of ``data``) which are neither specified as outcome variable ``y_col``, nor
21:         treatment variables ``d_cols``, nor instrumental variables ``z_cols``, nor cluster variables ``cluster_cols``
22:         are used as covariates.
23:         Default is ``None``.
24: 
25:     z_cols : None, str or list
26:         The instrumental variable(s).
27:         Default is ``None``.    cluster_cols : None, str or list
28:         The cluster variable(s).
29:         Default is ``None``.
30: 
31:     use_other_treat_as_covariate : bool
32:         Indicates whether in the multiple-treatment case the other treatment variables should be added as covariates.
33:         Default is ``True``.
34: 
35:     force_all_x_finite : bool or str
36:         Indicates whether to raise an error on infinite values and / or missings in the covariates ``x``.
37:         Possible values are: ``True`` (neither missings ``np.nan``, ``pd.NA`` nor infinite values ``np.inf`` are
38:         allowed), ``False`` (missings and infinite values are allowed), ``'allow-nan'`` (only missings are allowed).
39:         Note that the choice ``False`` and ``'allow-nan'`` are only reasonable if the machine learning methods used
40:         for the nuisance functions are capable to provide valid predictions with missings and / or infinite values
41:         in the covariates ``x``.
42:         Default is ``True``.
43: 
44:     force_all_d_finite : bool or str
45:         Indicates whether to raise an error on infinite values and / or missings in the treatment variables ``d``.
46:         Possible values are: ``True`` (neither missings ``np.nan``, ``pd.NA`` nor infinite values ``np.inf`` are
47:         allowed), ``False`` (missings and infinite values are allowed), ``'allow-nan'`` (only missings are allowed).
48:         Note that the choice ``False`` and ``'allow-nan'`` are only reasonable if the model used allows for missing
49:         and / or infinite values in the treatment variables ``d`` (e.g. panel data models).
50:         Default is ``True``.
51: 
52:     Examples
53:     --------
54:     >>> from doubleml import DoubleMLData
55:     >>> from doubleml.plm.datasets import make_plr_CCDDHNR2018
56:     >>> # initialization from pandas.DataFrame
57:     >>> df = make_plr_CCDDHNR2018(return_type='DataFrame')
58:     >>> obj_dml_data_from_df = DoubleMLData(df, 'y', 'd')
59:     >>> # initialization from np.ndarray
60:     >>> (x, y, d) = make_plr_CCDDHNR2018(return_type='array')
61:     >>> obj_dml_data_from_array = DoubleMLData.from_arrays(x, y, d)
62:     """
