4.5    Computational Complexity
In contrast with typical RL applications, we treat RL here as
a search strategy, aiming to find an ordering that achieves the
best score. CORL requires the evaluation of the rewards at
each episode with O(dm2 + d3 ) computational cost if linear
functions are adopted to model the causal relations, which
is same to RL-BIC2 [Zhu et al., 2020]. Fortunately, CORL
does not need to compute the matrix exponential term with
O(d3 ) cost due to the use of ordering search. We observe
that CORL performs fewer episodes than RL-BIC2 before the
episode reward converges (see Appendix C). The evaluation
