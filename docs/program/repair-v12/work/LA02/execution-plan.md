# LA02 execution and plan review

12 October 2026. LA01 has a recorded pass. IN02/IN04 are frozen dependencies.

1. Define separate problem and diagram schemas. Preserve alternative estimands,
   graph classes and evidence provenance; a selected question does not imply
   identification or true assumptions.
2. Implement local semantic checks for variable references, event/availability
   clocks, decision information sets, feasible interventions, endpoint marks,
   directed cycles, constraints and revision links. Keep unresolved scientific
   facts as review obligations rather than inventing values.
3. Construct four synthetic banking case families, with ambiguous questions,
   competing graphs, time-varying confounding and observation/selection issues.
   Give every proposed edge an evidence anchor, counterevidence status and
   reviewer disposition. Model scores have an explicitly uncalibrated meaning.
4. Test adverse cases that would change scientific meaning: future-information
   leakage, target substitution, direction or endpoint loss, collider/mediator
   adjustment, missing source anchors and infeasible actions. Independently
   enumerate small synthetic examples where two targets or graphs differ.
5. Review the argument and observed tests against C1–C3. Record only the design
   and reference-validator scope; LA05 owns business-to-tool execution.

The plan review rejects a single “confidence” field, an automatically selected
estimand, a model-generated fact promoted to an accepted assumption, and one DAG
chosen for appearance from an equivalence class. A valid schema proves neither
assumption truth nor identifiability. Synthetic analyst choices must be visibly
synthetic. No private bank data or external model access is required for this
package, and no completed interface file is changed.
