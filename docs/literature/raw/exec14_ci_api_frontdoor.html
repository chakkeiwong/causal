    Class FrontDoorCriterion

    Uses the 'Front-door Criterion' to identify any sets of valid front-door nodes, that if found can be used to estimate the causal effect using the FrontDoorInference.

    public sealed class FrontDoorCriterion : IIdentification, IValidation
    Remarks

    Although the estimation can also be performed using Bayes Server, this criterion can also be used to identify front-door node sets for use outside Bayes Server.
