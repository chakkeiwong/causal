# Four banking journeys: requirement reconciliation

The proposal needs four independently specified journeys. A shared response
format does not make funding, servicing, discovery and observation construction
the same scientific task. This review binds their existing frozen protocols,
complete local journals, negative outcomes, mathematical examples and integrated
manuscript passages to the currently inspected implementation.

First compare the current source/environment identity with all four recorded
environments and validate the registered protocol and journal bindings. Recompute
the full request denominators, saved-prefix hashes, original fixture verdicts
and library/CLI restart parity from the actual responses. Retain the four
servicing expectation errors and both funding harness amendments. Reproduce the
existing exact examples without rewriting their files or making new service
calls. Distinguish mathematical sets, expressions, syntax checks and clock
diagnostics from numeric causal estimates.

Next map each business decision through its population, information clock,
sampling law, assumptions, target, uncertainty, refusal and financial loss.
Record concrete generated/public prototype acceptance cases and the separate
authentic-owner inputs needed only for later bank qualification. Name the
remaining scientific obstructions where additional computation cannot identify
the target. Include common artifact and runtime limitations without turning
them into blanket blockers for independent proposal work.

Finally verify that the four journey discussions and the negative servicing
result are present in the current 773-page reader and that their cited source
records remain in its audit. Record a requirement-review outcome only after
reviewing both contracted criteria. No new manuscript pages are needed merely
to repeat already integrated results. No claim of actual MCP execution in these
four trials, sibling integration, live-model performance or bank acceptance is
permitted. Existing MCP evidence belongs to its separately scoped review.

Review of this plan found two material interpretation risks: counting correct
refusals as useful effect estimates, and treating a corrected test expectation
as a repaired original result. The reconciliation explicitly prevents both.
It also checks current code identity before reusing older executions and keeps
the public-first proposal route separate from conditional bank experiments.
The work is a source/data reconciliation and exact replay, not a new sampling
study; no fresh study registration or repeated service run is warranted.
