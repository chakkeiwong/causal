# Network decisions need exposure and failure contracts

The R network comparison extends the existing grouped-interference work across interference, latenetwork, BicliqueRT, NetworkTargeting, NetworkCausalTree, MisspecifiedInterference, autognet and clusteredinterference. They address different decisions: exposure-specific effects, instrumented responses, conditional tests, optimized allocations, heterogeneous effects, candidate-graph uncertainty and model-based simulation. Their outputs are comparable only after fixing assignment, exposure, population and uncertainty. [@exec25_rnet_exposure; @exec25_rnet_late; @exec25_rnet_biclique; @exec25_rnet_target; @exec25_rnet_tree; @exec25_rnet_nmr; @exec25_rnet_auto; @exec25_rnet_cluster]

Primary-source inspection produces concrete public test targets. A full-neighborhood label can represent not-all-treated rather than literal all-control; corrected simulation frequencies differ from exact design probabilities; selected exposure formulas need heterogeneous and adjacent-node tests; randomization failures use numerical sentinels; near-tie arithmetic requires range and validity checks; optimizer status, missing edges, quadrature failures and missing groups need explicit treatment. These are source-level qualification targets and exact authored comparisons, not installed-package benchmark results. [@exec25_rnet_choice]

The proposed spending sequence begins with tiny known-law assignment spaces, proceeds to matched public uncertainty and failure studies, and only then supports costly bank experiments. Each candidate has an independent admission decision. Native artifacts, complete dependencies, solver entitlement, rights, graph truth and target-population semantics remain gates. Public descriptions of a general method do not qualify an unrestricted bank use. [@exec25_rnet_choice]

A hypothetical USD30,000 study costs USD30 per 1,000 attempts, USD50 per 600 completions or USD75 per 400 accepted outputs. Those denominators are reproducible arithmetic, not measured return on investment. Search tails, complete native qualification, visual review and final proposal acceptance remain open.
