D    Expert model averaging pseudocode

Algorithm 1 provides pseudocode for our model averaging strategy, described earlier in Section
4.2. Our pseudocode makes use of several helper functions, notably: connectionCounts(G),
which counts the total number of direct edges of any kind between each pair of nodes in a set of
models G; edgeCounts(G, x, y), which counts the total number of edges x → y in a set of models
G; Ĝ.edgeCreatesCycle(x, y), which determines if adding a new edge x → y to the model
Ĝ would create a cycle; and e.acceptConnection(x, y) and e.determineOrientation(x, y),
which dynamically query an expert e for edge existence and orientation.


E    Selection of hyperparameters

We tune the hyperparameters of our method on randomly generated networks. Using the
random.graph() method of bnlearn [Scutari et al., 2019], we generate 15 network structures of
between 5-50 nodes: three each of sizes {5, 10, 20, 35, 50}. We use a maximum in-degree of 5 and a
generation method randomly chosen from among {ordered, ic-dag, melancon}. We generate
100000 clean samples from each network, and follow the strategy of Constantinou et al. [2021] to
obtain corresponding noisy data. We then select subsets of size n ∈ {100, 1000, 10000, 100000} to
form the clean and noisy training sets. The generated networks and training data are available with
the rest of our code at https://anonymous.4open.science/r/expert-cd-ensemble-3282/.
