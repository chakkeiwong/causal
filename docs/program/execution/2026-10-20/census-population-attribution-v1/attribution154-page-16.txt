3.7 Reverse Causal Discovery

The reverse causal discovery task is critical for evaluating the LLMs’ dependence on numeri-

cal data when inferring causality (see the detailed workflow in Figure 4). We achieve this by

manipulating the structure of the datasets while keeping their data content intact. Specif-

ically, we first establish the topological ordering of the variables within the original DAGs

(Pearl 2009b) representing the causal structures of the datasets. We then systematically

reverse this order using a transposed adjacency matrix, which maintains a one-to-one map-

ping with the original causal graph structure, creating a new set of inverted relationships

for the LLMs to analyze. Despite preserving the data values, this rearrangement challenges

the models by disrupting the directionality they have learned from previous exposures. As
