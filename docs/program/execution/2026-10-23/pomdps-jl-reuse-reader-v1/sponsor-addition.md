# Preserve the decision experiment across a Julia worker

POMDPs.jl 1.0.0 offers a useful root interface for models, solvers, policies,
belief updaters and simulators. Sixteen authenticated files at the selected
8 June 2026 revision support a reference-only disposition. The root license
explicitly separates other organization packages, so neither a solver nor
POMDPTools inherits approval. A concrete worker still needs a selected algorithm,
updater and simulator, their source and rights, and a locked Julia environment.
\citep{exec23_pomdpsjl_sources}

The proposed integration must preserve one joint decision event. In an exact
authored example, next-state distress and a matching alert share an event with
probability 1/4. Splitting generator outputs into independent calls preserves
the marginals but reduces state-alert agreement from 1 to 5/8 and alert-loss
probability from 1/4 to 1/16. A stipulated alert-triggered rescue worth USD 35
in distress and USD -15 otherwise then changes expected incremental value from
USD 35/4 to USD -5/8. This is a counterexample to an adapter strategy, not an
observed upstream failure or a measured bank return.
\citep{exec23_pomdpsjl_reference}

Other conversion contracts are equally substantive. A solver's observation
signature must support the model's dependence on the previous state. A narrower
reward signature must return a probability-weighted expectation: the example
gives USD -4, not the USD -16 uniform state average. Zero terminal continuation
does not erase a USD 12 settlement paid on entry. Generalized beliefs may be
lossy histories rather than normalized posteriors, and pass-through initialization
does not establish sufficiency or an isolated snapshot.
\citep{exec23_pomdpsjl_sources,exec23_pomdpsjl_reference}

The prototype route is to preserve model and event identities, clock, horizon,
reward units and random-stream protocol across library, CLI and MCP; register
finite-oracle conversion checks; and measure offline solve, online action,
compilation, serialization, accuracy, memory and recovery separately. An LLM
can draft a candidate model, but scientific review must justify its latent
state and intervention/observation laws. Neither the API nor the generated
description establishes identification or calibrated policy uncertainty.
\citep{exec23_pomdpsjl_sources}

The current paired reader has 1000 audited citations and 232 genuine scholarly
PDFs. The reuse register has 46 passing proposal dispositions, three inconclusive
and 66 open entries. Source review narrows a prototype choice while leaving
native qualification, wider proposal coverage, visual review and institutional
acceptance open.
\citep{sp23pomdpsjl_reader,sp23pomdpsjl_progress}
