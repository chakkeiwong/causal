# Successor feasibility and information review

This is project reasoning and exact illustrative arithmetic. No candidate below
is a newly qualified estimator. Existing failed studies remain unchanged. The
accompanying deterministic code uses no random draws and makes no live calls.

## R02S: persistent maps, calendars and estimated audit error

Observed obstruction: the previous interaction-adjusted procedure failed its
finite simultaneous screen under scarce pairs/dates, low audit information,
calendar persistence and long windows. More dates do not independently redraw
a persistent identity audit. An oracle variance calculation is diagnostic only.

Candidate route: define a confidence region C for the observable numerator m,
audit parameters q and calendar/pair parameters eta, then report the image
S={theta: m=r(q)theta for some (m,q,eta) in C}. If C contains the true vector with
probability at least 1-alpha, its image contains the true theta on that same
event. This statement follows directly by inserting the true vector; it does
not require independent component estimates. If component confidence sets have
error budgets summing to alpha, the union bound establishes their simultaneous
coverage regardless of dependence. This is a valid composition rule only after
each component set is proved valid for its own sampling law.

For numerator interval [1,2] and positive audit-rank interval [1/4,1/2], the
ratio set is [2,8]. If the rank interval crosses zero, e.g. [-1/2,1/2], the same
numerator yields (-infinity,-2] union [2,infinity). If zero numerator and zero
rank are jointly feasible, every theta may be feasible. Replacing this set with
a symmetric finite interval changes its meaning. Positive rank bounded away
from zero can improve precision, but is additional information, not a correction
that data-free code can supply.

Unresolved argument: construct a valid joint observed-law region when calendar
dependence and audit noise are estimated, with persistent identities, scarce
dimensions and finite information. Fixed known covariance gives a useful exact
Gaussian reference but does not establish the required feasible method. A
successor must either solve the estimated-parameter construction or explicitly
leave excluded regimes open. No final protocol is approved at present.

Next executable research: derive small Gaussian references with unknown
covariance nuisance included in the region, establish compact/noncompact
parameter behavior, then compare with genuinely independent calendar and gold
information designs. Stop the qualification branch if valid component regions
cannot be supplied or if useful precision requires unavailable information.

## R03S: estimated logging, selection and hidden-state optimality

Observed obstruction: the successful predecessor conditions on a supplied logger
and a fixed policy. A value estimator for a fixed policy is not an argument
for the value of a policy selected using those same outcomes, and observed
propensities do not establish sequential exchangeability for hidden states.

Exact counterexample: let U be a fair binary variable and A=U. Model one has
Y=A; model two has Y=U. Both produce exactly the same observed (A,Y) law. Under
do(A=a), model one has mean a while model two has mean 1/2. The effect is one in
the first and zero in the second. Estimating the marginal logger as 1/2 cannot
distinguish these models. Extra proxy/measurement or experimental information
and an identification argument are necessary.

Candidate route in an identified history-based class: freeze the state/observation
law and logging estimator on development data, require positivity over the
admitted actions, and derive nuisance-error propagation. Evaluate a selected
policy on independent units or a justified separated dependent sample. If each
of two equally valuable policies has an independent Rademacher evaluation error,
selecting the larger error gives expected apparent value 1/2. Fresh independent
evaluation of the selected policy has expected error zero. Exact enumeration
checks this distinction; it proves no general sequential coverage theorem.

Unresolved arguments: estimated logging under the declared nonlinear hidden-state
model, policy-class complexity, dependent selection/evaluation and a useful
uniform value guarantee. Stop unknown-optimum claims when identifying information
or support is absent. Next work must derive a restricted, observable-history
construction and an explicit comparison with the larger original ambition.

## R04S: temporal graph uncertainty and useful effects

Observed obstruction: predecessor graph retention was conservative, but latent
observational and weak-relevance cases produced whole-line effects; persistent
cases missed finite availability. False exclusions could produce apparent
coverage while excluding the true graph.

A direct continuous counterexample uses X=U and
Y=b X-b U+epsilon, with U and epsilon independent standard Gaussians. For every
b the observed joint law is X=U,Y=epsilon. The intervention slope is b. Hence
the observational identified set is the whole real line. A language model,
larger sample or sharper graph score cannot distinguish these equal-law worlds.

Candidate route: specify actual measurements, valid exclusions or randomized
encouragement that separate the relevant models. Form a confidence region for
the joint observed law and retain every compatible graph/parameter value.
Project it to the effect without dropping inconvenient components. Numerical
outer bounds must contain the exact small-class reference, including disconnected
and unbounded cases. Unknown continuous temporal parameters need their own
joint argument; a supplied lag grid is not that argument.

Unresolved: useful sets for weak relevance, unknown lag and richer latent laws,
and authentic evidence for exclusions. Stop a numerical campaign if equivalent
models imply different actions and no separating information is available.
Next work is an information-design comparison and a joint confidence/numerical
certificate, before fresh registration.

## R05S: dependent learners and orthogonal remainders

Observed obstruction: predecessor high dimension and larger support did not pass
the frozen screen; nonlinear misspecification failed dramatically. Repaired
training-only tuning and covariance bookkeeping did not remove these problems.

For a proposed orthogonal score, a typical conditional remainder bound has the
form |R_n| <= C ||mhat-m||_2 ||ghat-g||_2 plus dependence/approximation terms.
This display is a candidate condition to prove for the chosen score, not a
theorem for arbitrary learners. Root-n inference needs sqrt(n) R_n -> 0. If both
errors are merely O(n^(-1/4)), the scaled product is O(1), which is insufficient.
Restricted eigenvalues, sparsity, approximation error and actual tuning must
establish a stronger rate in the selected regime.

If independent-pilot reasoning is replaced by separated blocks and a coupling
bound of b C rho^g is justified, the number of blocks b and gap g must jointly
make that term negligible. Assuming a large gap without estimating or bounding
dependence does not supply the argument. For weak instruments, retain a test
inversion/set construction instead of dividing by a tiny estimated denominator.

Unresolved: feasible quantitative remainder and dependence bounds in the failing
dimension/support regimes, model misspecification treatment and useful weak-IV
precision. Next work must derive a learner-specific design and compare with a
matched fixed dictionary and independent-pilot reference. Stop a qualification
claim if the required rates or support cannot be defended.

## Monte Carlo qualification is a separate design problem

For n independent final replications and K covered requests, an exact one-sided
lower binomial bound can be written L=BetaQuantile(alpha/m; K,n-K+1), with L=0
for K=0, where m is the declared simultaneous family size. Passing requires
L >= .95. The program computes the smallest passing K and exact binomial pass
probabilities for n=512,2048,8192 and m=1,8,33. It also checks the equivalent
upper-tail rejection threshold independently. This is exact finite arithmetic
for the screen; it does not prove causal-estimator coverage.

At true coverage .95, per-cell pass probability is at most alpha/m. This is
expected behavior of a lower-bound certification test at its boundary. Increasing
n resolves alternatives above .95; it does not produce high power at the exact
boundary while retaining this error control. A method with a justified coverage
margin and adequate simulation precision may pass, but wider intervals must
still meet usefulness and availability criteria. Record per-cell and joint
claims separately; no across-cell independence is assumed for Bonferroni error
control. Old outcomes and final thresholds remain unchanged.
