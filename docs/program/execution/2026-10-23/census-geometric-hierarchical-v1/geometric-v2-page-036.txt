S ⊂ Ω there is an index transform ϕn ∈ G for which |ϕn (S) ∩ S| = 0. Thm. 1 of [Ayach et al., 2025]
says that this implies Pr(ϵ ∈ B) ∈ {0, 1}. Since this holds for any invariant set B, p(ϵ) is ergodic
(Definition 11).
    We now show GCMs are ergodic. First, since i.i.d. and invariant distributions are ergodic, the
joint distribution p(ϵV ) over noise variables is ergodic. Now, let FC : (E V )Ω → (X C )Ω denote the
mapping from exogenous noise variables to endogenous variables xC , defined by the GSCM. That
is, xC = FC (ϵC ). Since FC is a composition of equivariant functions, it must be equivariant. So the
distribution p(xC ) is the pushforward of an ergodic distribution through an equivariant map,

                                              C      C    V
                                            x = F (ϵ ),                                           (70)

This implies p(xC ) is ergodic, by Lemma A1.1 in Kallenberg [2005].

B.4    Proof of Proposition 4
Proof. We need to show that if the effect p(y; do(a = a⋆ )) is not identified by do-calculus, it cannot
be computed as a functional of p(xVobs ). That is, there does not exist a functional ψ(·) such that

                                     ψ(p(xVobs )) = p(y; do(a⋆ ))                                 (72)

for all p(xV ) ∈ PG,G , where PG,G denotes the set of all joint distribution that can be produced by a
GCM with causal graph G and group G.
    Let PG denote the set of all joint distributions that can be produced by a conventional causal
model with a causal graph G. This is the set of joint distributions produced by conditionally i.i.d.
causal mechanisms, that is in the notation of GCMs, distributions of the form,
                                                    Y
                                  p(xv | xpa(v) ) =    p(xvω | xpa(v)
                                                                 ω    ),                          (73)
                                                    ω∈Ω

for countably infinite Ω. This conditional distribution is equivariant under the group of permutations
of Ω. Since any index transform ϕ : Ω → Ω is a permutation, Equation (73) must also be equivariant
under any group G of index transforms. So PG ⊆ PG,G , i.e. the set of joint distributions produced
by conventional causal models is a subset of the set of joint distributions produced by GCMs, for
any group G that only contains index transforms.
    Thm. 6 of [Shpitser and Pearl, 2006] shows do-calculus is complete for conventional causal
models, meaning that if the effect is not identified by do-calculus, there does not exist a ψ such that
Equation (72) holds for all p(xV ) ∈ PG . Then, since there is no ψ such that Equation (72) holds
for all elements of PG , and PG ⊆ PG,G , there cannot be a ψ that holds for all elements of PG,G .
