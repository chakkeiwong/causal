\chapter{Keeping causal uncertainty through the calculation}
\label{v131:graph-uncertainty}

\section{A graph representation carries a scientific commitment}

A funding analyst may represent the offer rate, customer response and retained
balance by three columns in a matrix. The columns are measurements; the graph
and structural equations give those measurements causal meaning. An adapter
must preserve both. A correctly sized matrix can still encode every arrow in
the wrong direction, and a software object called a mixed graph can still
contain a directed cycle that is inadmissible for the requested identification
algorithm. These errors arise before questions of estimation accuracy.

The inspected LiNGAM base class stores a coefficient in
$B_{\text{target},\text{predictor}}$. It fits each variable against eligible
variables earlier in its selected causal order, optionally removing predictors
excluded by the prior-knowledge matrix. The adaptive-Lasso branch and ordinary
regression branch therefore share an orientation convention. A conversion to
an edge list must interpret a nonzero $B_{jk}$ as $k\to j$.
\citep{v131_sw_lingam}

For a stipulated banking example, let $F$ denote a funding change, $A$ an offer
adjustment and $Y$ the balance response, in declared normalized units:
\[
 A=0.4F+\varepsilon_A,\qquad
 Y=0.1F+2A+\varepsilon_Y.
\]
Holding the disturbance law fixed, a one-unit intervention on $F$ changes $A$
by $0.4$ and $Y$ by $0.1+2(0.4)=0.9$. The latter consists of the direct path
and the mediated path. Transposing this coefficient matrix produces a different
acyclic graph with no path from $F$ to $Y$; its corresponding total effect is
zero. Shape checks and acyclicity checks both pass. An asymmetric intervention
example, rather than a symmetric matrix fixture, detects the semantic error.
The arithmetic is an original project example, not a fit to a bank dataset.
\citep{v131_project_semantics}

LiNGAM's inspected \texttt{estimate\_total\_effect} method regresses the target
on the source and the source's estimated parents. If the requested target is
earlier than the source in the selected causal order, the method warns and
continues. The numerical coefficient remains an output; the warning records a
reason its causal interpretation may be inappropriate. A service that records
only the returned floating-point number would lose that distinction. It should
carry the order, adjustment variables, warning and fitted graph together, and
state whether the request falls within the admitted functional model.
\citep{v131_sw_lingam}

An alternative based on a CPDAG or PAG has different obligations. Its uncertain
arrowheads cannot be collapsed to LiNGAM's selected directed order solely to
make a common schema convenient. An output union or equivalence-class type is
necessary when the method retains several causal possibilities. The common
operation contract should make the statistical and scientific scope visible
without suggesting that one representation is intrinsically superior.

\section{Recursive identification and the reasons for refusal}

y0's inspected ID implementation first handles the absence of interventions,
restricts to outcome ancestors, adds irrelevant variables to the intervention
set and decomposes the graph remaining after treatment removal into districts.
Districts represent connected components of the graph's bidirected component.
The implementation multiplies and marginalizes expressions across the relevant
recursive subproblems. In the connected-district failure branch it raises
\texttt{Unidentifiable}; separate invariant failures raise \texttt{RuntimeError}.
These paths support different service responses. \citep{v131_sw_y0}

For a mixed graph with $A\to Y$ and a latent common cause represented by
$A\leftrightarrow Y$, observational data alone generally cannot distinguish
the intervention response from the common-cause association. The absence of an
identifying functional is a scientific conclusion within that model class.
It is distinct from a malformed graph, an unsupported query or a failed
computation. Treating all four as the same missing value would conceal whether
the analyst needs another measurement, another algorithm or a software repair.

The inspected IDC routine examines whether a conditioning variable can be
exchanged for an intervention using a rule-2 condition. Its helper removes
incoming edges to existing interventions and outgoing edges from the candidate
variable, then delegates a separation test. If the exchange is allowed, IDC
recurses; otherwise it identifies the unconditioned joint query and normalizes
the resulting expression. This establishes the inspected control flow. The
separation routine, expression normalization and all graph-mutilation behavior
require their own correctness evidence. Section~\ref{exec18:pyid-packages}
provides a separation counterexample and excludes this selected native
conditional route pending repair. The control flow described here does not
supersede that restriction. A claim about the whole algorithm cannot be based
solely on recognizing the names of its steps.
\citep{v131_sw_y0}

Graph construction deserves explicit validation at the library boundary.
y0's inspected constructor sets graph metadata, while directed-edge insertion
adds edges and corresponding nodes to both graph components. These methods do
not themselves enforce acyclicity. The identification wrapper should therefore
validate the admitted graph class, query membership, permissible overlap of
treatment/outcome/conditioning sets and any supplied ordering before invoking
the algorithm. The required checks depend on the query language; counterfactual
variables need more than the rules for ordinary intervention queries.
\citep{v131_sw_y0}

A useful qualification set should contain an adjustment example, a front-door
example, a genuinely nonidentified example and malformed inputs with known
failure types. Variable renaming should change names while preserving the
mathematical expression. Adding an irrelevant measured variable should preserve
the effect after valid marginalization. These are proposed behavioral checks;
they have not been run against the newly acquired source here. A symbolic
expression still needs a numerical estimator and a sampling argument before a
bank can use it to choose an offer.

\section{What an estimating-equation column means}

For contributions $\psi_i(\eta)\in\mathbb R^p$, an estimating-equation method
solves $\sum_i\psi_i(\widehat\eta)=0$. A usual independent-unit sandwich takes
\[
 \widehat A=-\frac1n\sum_i\frac{\partial\psi_i}{\partial\eta^\top},
 \qquad
 \widehat B=\frac1n\sum_i\psi_i\psi_i^\top,
 \qquad
 \widehat{\operatorname{Var}}(\widehat\eta)
 =\frac1n\widehat A^{-1}\widehat B\widehat A^{-\top}.
\]
This display states a construction under regular identification and an
appropriate independent-unit asymptotic law. It is not a universal uncertainty
formula for arbitrary records.

The inspected delicatessen \texttt{MEstimator} obtains the number of observations
from the supplied contribution array, solves the stacked equations, differentiates
their sum and scales both bread and meat by that number. It then divides the
assembled sandwich by the number again to obtain estimator variance.
\texttt{compute\_meat} forms the matrix product of the supplied contribution
array with its transpose. The function does not discover household clusters
or add serial lag products based on variable names. \citep{v131_sw_delicatessen}

Suppose two independent groups each contribute two perfectly aligned scores,
$(1,1)$ and $(-1,-1)$. The sum of individual squared contributions is four;
the sum of squared group totals is eight. With the same total-score derivative
of four, the uncorrected variance calculations are $4/16=0.25$ and $8/16=0.5$.
The discrepancy is structural. A finite-sample degrees-of-freedom adjustment
does not create the missing cross-products. This example illustrates covariance
bookkeeping, not consistency with only two groups. \citep{v131_project_semantics}

For $K$ independent groups of size $m$, equal marginal variance $\sigma^2$ and
within-group correlation $\rho$, direct summation of the covariance terms gives
\[
 \operatorname{Var}(\overline Y)
 =\frac{\sigma^2}{Km}\{1+(m-1)\rho\}.
\]
With $K=100$, $m=10$ and $\rho=0.3$, the multiplier is $3.7$. A thousand records
then have the same variance as about $270.27$ independent records with the same
marginal variance. A common calendar shock across the groups violates the
independence used in this calculation; merely labeling borrowers as clusters
does not resolve it. \citep{v131_project_semantics}

One possible integration lets the caller supply independent group totals as
columns. That choice needs a derivation of weighting, normalization and target
population, especially for unequal group sizes. Another constructs an explicit
long-run covariance from time-ordered scores. A third retains dependence within
independently sampled whole histories. These alternatives change the sampling
contract and must be compared on that basis.

Delicatessen permits a pseudoinverse by default when building the sandwich.
This is useful numerical behavior in some problems, but a finite matrix is not
evidence that the parameter is identified. If the derivative of the moment
condition loses rank, an ordinary inverse-based asymptotic argument may fail;
using a generalized inverse does not supply the missing information. Solver
residuals, Jacobian rank, scaling and the distinction between regular intervals
and weak-information set inversion belong in the result contract.
\citep{v131_sw_delicatessen}

\section{Final covariance settings must reach the final estimator}

The inspected statsmodels GMM path defaults to \texttt{weights\_method=cov},
using an outer-product moment covariance divided by the number of observations.
There is a separate HAC path with an explicit maximum lag and a kernel, defaulting
to Bartlett. The results object obtains the method from the GMM fit options and
uses it in the final covariance calculation. The low-level presence of HAC is
evidence of an available code path, not evidence that every treatment-effect
wrapper exposes or activates it. \citep{v131_sw_statsmodels}

The treatment-effect entry point explicitly distinguishes its preliminary
outcome-regression covariance setting from final GMM inference. An adapter must
therefore record both stages and trace the actual final call. A statement such
as ``robust errors requested'' is insufficient to distinguish independent
heteroskedastic, household-cluster and serially dependent constructions.
Calendar ordering, lag choice and the relation between estimation weights and
covariance weights also need to survive serialization. \citep{v13_sw_statsmodels,v131_sw_statsmodels}

The inspected GMM centering expression subtracts \texttt{moms.mean()}, a scalar
mean over the array, rather than an explicit vector of column means. This is
a concrete behavior to compare against an analytic moment reference, particularly
when numerical residuals or overidentification leave nonzero sample moments.
It is not sufficient by itself to conclude that the intended fitted estimator
is incorrect. The outcome depends on the full score, weighting and convergence
conditions. Section~\ref{exec20:pyfx-covariance} develops the exact difference
between scalar and column centering and a finite two-moment example. That
derivation supplies an independent numerical reference; the behavior of a
particular fitted native estimator still requires a matched trial.
\citep{v131_sw_statsmodels}

\section{Orthogonality isolates a rate obligation}

Let $Z$ be an instrument, $D$ an action, $Y$ an outcome and $X$ measured
pre-action information. Write $m(X)=E(Z\mid X)$, $r(X)=E(D\mid X)$ and
$\ell(X)=E(Y\mid X)$. Suppose the declared causal model identifies $\theta_0$
through
\[
 E[(Z-m(X))\{Y-\ell(X)-\theta_0(D-r(X))\}]=0.
\]
This is an assumption about an identified model; the existence of these
conditional means does not establish a valid instrument.

Condition on nuisance functions trained on an independent pilot with the same
target law. Denote their errors by $\delta_m,\delta_r,\delta_\ell$. Expanding
the fitted score and using the zero conditional means of the centered variables
gives the exact remainder
\[
 R(\theta_0)
 =E[\delta_m(X)\{\delta_\ell(X)-\theta_0\delta_r(X)\}],
 \qquad
 |R(\theta_0)|\leq
 \|\delta_m\|_2\bigl(\|\delta_\ell\|_2+|\theta_0|\|\delta_r\|_2\bigr).
\]
The inequality follows from Cauchy--Schwarz and the triangle inequality. It
exposes exactly what must be bounded for this score. In a two-stratum arithmetic
example with equal stratum probabilities, errors $(0.1,0.2,0.05)$ and
$(-0.1,0.1,-0.05)$, ordered as $(\delta_m,\delta_\ell,\delta_r)$, and
$\theta_0=2$, the remainder is $-0.005$. \citep{v131_project_semantics}

The identity provides no convergence rate for a particular learner. Reusing
dependent observations for training and evaluation also invalidates the simple
conditioning argument unless additional separation or dependence control is
proved. Support failures and misspecification can prevent the errors from
shrinking. For weak instrument relevance, even a well-controlled score may
yield an unbounded effect set under test inversion. This is why source-level
availability of flexible learners and sandwich calculations cannot settle
the unresolved research on dependent learning and useful precision.


The same requirement runs from graph storage to the final interval: retain
the scientific meaning of each intermediate object. Directed coefficients,
identified expressions, independent score contributions and rate bounds do
not become substitutes for one another when they share a software interface.
The estimation comparisons that follow use this distinction to examine which
population is averaged, which estimating equation is solved and which
variation the reported uncertainty actually includes.
