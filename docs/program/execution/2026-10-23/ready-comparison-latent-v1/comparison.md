# Preserve hidden-risk and selection ambiguity through discovery

Private borrower distress can affect both contact allocation and repayment.
Approval, channel entry or record availability can also select the observed
population. Discovery must distinguish those mechanisms from a direct action
effect. An ADMG can retain directed and bidirected relations from a latent
projection, including a directed relation alongside hidden confounding. A
MAG/PAG ancestry representation and a CPDAG for a causally sufficient model
have different semantics. A circle endpoint leaves an orientation unresolved;
it is not an invitation to choose the most profitable direction. With
selection allowed, a tail's ancestral meaning can involve selection variables.
\citep{exec13_latentr_primary,exec13_latentr_colombo2012,exec14_olatent_oracle}

## Graph-class methods and their computation choices

The inspected pcalg 2.7-12 FCI path adds Possible-D-SEP tests beyond its
initial adjacency search. RFCI trades some informativeness for fewer global
tests. Its adjacency statement is weaker and can encompass more than one
FCI equivalence class; storing both results in an fciAlgo object does not
make them equivalent. The oracle endpoint result assumes a faithful acyclic
underlying model and correct independence information. The cited consistency
result adds an IID selected Gaussian law, sparsity and partial-correlation
conditions with a tuning sequence. It does not supply finite-sample graph
coverage at an arbitrary alpha. \citep{exec13_latentr_primary,exec13_latentr_colombo2012}

The software controls must therefore remain visible. In the selected source,
m.max restricts conditioning-set order, while pdsep.max skips a candidate
edge's Possible-D-SEP search when that candidate set is too large. A missing
test can be mapped to independence or dependence according to NAdelete;
neither map establishes scientific evidence. FCI+ returns placeholder or
empty diagnostic fields on the inspected return path, and RFCI's initial
test counts omit later local tests. A resource limit, missing test or empty
field must not become a complete-search claim. Stable initial skeletons also
do not remove all later RFCI order dependence. \citep{exec13_latentr_primary,exec13_latentr_colombo2014}

Native aGrUM offers an explicit FCI-to-PAG boundary, with destination-endpoint
access and a missing-data restriction in the reviewed route. Its generic
PAG-to-mixed conversion collapses nine local endpoint pairs into four
generic outputs; it cannot be used as a lossless PAG serializer. rCausalMGM
offers R-hosted C++ FCI-Stable with mixed data, complete-case deletion,
collider-rule options and possible-D-Sep settings. MIIC carries orientation
scores, modes and consensus information whose interpretation needs its own
contract; the reviewed row/column score convention still requires an
asymmetric runtime check. None is admitted merely because C++ compiled or a
matrix arrived. \citep{exec14_native_agrum,exec14_native_rcmgm,exec14_native_miic,exec14_native_oracle}

Julia CausalInference.jl stores endpoint properties on opposing arcs. Those
arcs are not two causal directions. Its inspected path caps, keyword
propagation and plotting conversion need separate fixtures. The Rust
varlingam-rs RCD-labeled path has a different issue: it only refines pairs
whose existing coefficients are essentially zero. Multiplying those by a
factor cannot correct a substantive confounded coefficient, and its score
is not a calibrated p-value. It is therefore unsuitable as a default
qualified RCD backend without an algorithmic correspondence and new evidence.
These are source findings, not newly executed failure rates.
\citep{exec14_olatent_causalinference,exec14_olatent_varlingam,exec14_olatent_oracle}

## Exact hidden-risk and selection worlds

Consider a contact A and recovery Y with observed probabilities 2/5,1/10,
1/10,2/5 for (A,Y)=(0,0),(0,1),(1,0),(1,1). A randomized action with
P(Y=1|do(A=a))=1/5+3a/5 produces this table and effect 3/5. A second law
has hidden fair-bit U, with A and Y conditionally independent given U,
P(A=1|U=u)=1/10+4u/5 and P(Y=1|U=u)=1/8+3u/4. All eight joint cells are
positive; marginalization yields the identical table, but intervention on
A leaves both outcome means at 1/2 and the effect zero.
\citep{exec13_latentr_exact}

A third law has independent population A,Y with probabilities 2/5 and 1/3.
Inclusion probabilities 1/5,1/10,3/40,3/5 in the same cell order yield
P(S=1)=1/5 and the same selected table. Its population causal effect is
also zero. At USD 100 per recovery and USD 20 per contact, the three
population action margins are 40,-20,-20. Exact enumeration checks both
the observational equivalence and the monetary arithmetic. This finite
collection proves ambiguity in any model class containing these worlds;
it is not a sharp effect set over every latent model or a confidence region.
\citep{exec13_latentr_exact}

An inferred risk score cannot automatically repair the problem. For
independent unit-variance Gaussian U,e_A,e_Y, let A=U+e_A, Y=U+e_Y and
W=U+e_W with proxy-noise variance s. The causal effect is zero, while
the adjusted regression slope is v/(1+v), where v=s/(1+s). At s=1 it
falls from the unadjusted 1/2 to 1/3 and remains confounded. Appropriately
designed multiple proxies or a justified measurement model are substantive
alternatives, but their identifying premises must be supplied. Neither an
EM convergence flag nor an LLM-generated label authenticates those premises.
\citep{exec13_latent_examples}

## Commercial latent models answer additional, different questions

GeNIe's inspected parameter-learning path holds network structure fixed;
its continuous Gaussian EM route has a different missing-value restriction
from the general latent-variable discussion. Its selected structure-learning
interface also has data-type and missing-record constraints. BayesiaLab's
Data Clustering constructs a factor and uses a specified mixture structure,
with Multinet as a distinct alternative. Netica's counting/EM/gradient
methods fit conditional tables, while its TAN structure is motivated by
prediction. Stata latent classes, SAS CALIS and Mplus mixture models are
relevant supplied-model alternatives. A fitted class or parameter posterior
is not a PAG, and a predictive target-to-predictor arrow does not identify
the direction of a bank intervention.
\citep{exec13_latent_genie_parameters,exec13_latent_genie_structure,exec13_latent_bayesia_data,exec13_latent_netica_algorithms,exec13_latent_netica_structure,exec13_latent_stata_lca,exec13_latent_sas_calis,exec13_latent_mplus}

The inspected commercial manuals have stated editions or page histories,
but post-cutoff acquisition does not authenticate every page's bytes at
7 October 2026. They support the explicitly documented paths with that
limitation, not an exhaustive vendor inventory, current entitlement or
absence claim. Matched comparisons should pair the same supplied latent
model with its commercial alternative and the same discovery regime with
its graph-class alternative. No commercial executable was run here.

## Reuse and qualification decisions

Prefer narrow FCI/RFCI and native PAG interfaces that retain node identities,
both marks, graph semantics, test failures, restrictions and provenance.
pcalg's inspected pcalg2dagitty branches omit the two tail-circle pairs:
tracing the documented two-node matrix [[0,1],[3,0]] constructs pag{}.
The replay verifies that source branch omission, not a native parser result.
Direct endpoint serialization or an explicit refusal is required; choosing
one compatible MAG cannot restore erased information or identify all effects
over the original class. \citep{exec13_latentr_primary,exec13_latentr_exact}

The proposed trials start with independent graph/separation oracles and all
endpoint pairs, then examine hidden causes, selection, weak signals, missing
tests, search limits and column permutations under declared sampling laws.
Graph correctness, class informativeness, effect identification and statistical
coverage require separate criteria. Reference-only or deferred routes retain
their reasons; porting has no demonstrated advantage that would justify
duplicating the algorithms now. The full source census, dependency rights,
native qualification and institutional acceptance remain open. All monetary
laws above are authored examples, not measured bank or vendor outcomes.
