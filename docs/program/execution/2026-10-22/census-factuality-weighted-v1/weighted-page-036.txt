but stated for the subclass Λ0,n rather than the population class Λn . This suggests viewing the

robust CI rather than using the sample analogue Λ̂0,n of the target. For example, if the class

conditions of Assumption U5, so long as it satisfies containment condition (25) relative to Λn .

does satisfy the Slater condition; see the examples below.
