Intuitively, this implies there is nothing special about a particular point ω in the plane Ω. All that
matters for y is the surrounding context of x.
    Equation (2) is an instance of equivariance, where transforming a function’s input transforms the
output in the same way. In this case the transformation is a shift in location. In models of sequences,
we may have equivariance to permutations. In models of arrays, we may have equivariance to
permutations of the rows or the columns. GCMs postulate that the causal mechanisms underlying
data respect some equivariance.

Groups and actions. These ideas are made precise using group theory.
Definition 1 (Group). A group (G, ·) with elements ϕ ∈ G and binary operator ·, (a) is closed
under composition: ϕ · ϕ′ ∈ G for all ϕ, ϕ′ ∈ G, (b) is associative: ϕ · (ϕ′ · ϕ′′ ) = (ϕ · ϕ′ ) · ϕ′′ for all
ϕ, ϕ′ , ϕ′′ ∈ G (c) has an identity Id ∈ G such that ϕ · Id = Id · ϕ = ϕ for all ϕ ∈ G and (d) has a
unique inverse ϕ−1 ∈ G for every element ϕ ∈ G, satisfying ϕ−1 · ϕ = ϕ · ϕ−1 = Id.
We study groups of transformations. That is, the elements of the group can transform elements of
another set, such as indices ω ∈ Ω or variables x ∈ X Ω . The action of an element ϕ specifies this
transformation. For example, actions can change the location of points in space or of entries in a
table.
Definition 2 (Group action). The elements ϕ ∈ G of a group (G, ·) act on a set S, i.e. ϕ : S → S,
in a manner that follows the operations of the group: ϕ′ (ϕ(s)) = (ϕ′ · ϕ)(s) for all ϕ, ϕ′ ∈ G, s ∈ S,
and Id(s) = s for s ∈ S.
An example is the group of shifts, ϕτ (ω) = ω + τ , where ω, τ ∈ Rd . Shifts compose: (ϕτ · ϕτ ′ )(ω) =
ϕτ +τ ′ (ω) = ω + τ + τ ′ , associate: (ϕτ · (ϕτ ′ · ϕτ ′′ ))(ω) = ((ϕτ · ϕτ ′ ) · ϕτ ′′ )(ω) = ω + τ + τ ′ + τ ′′ , include
an identity: Id(ω) = ϕ0 (ω) = ω + 0, and have an inverse: (ϕτ · ϕ−τ )(ω) = ϕ0 (ω) = ω. We notate
this translation group as Td = {ϕτ : τ ∈ Rd }.
    Some other groups of transformations include,
    • Sequence permutations. For sequence data, consider the group of permutations S. Each
      element ϕπ ∈ S acts on ω ∈ N as ϕπ (ω) = πω , for a permutation π.
    • Array permutations. For array data, consider the group of transformations that separately
      permute the rows and columns, S2 . Each element ϕπ,π′ ∈ S2 acts on ω ∈ N2 as ϕπ,π′ (ω) =
      (πω1 , πω′ 2 ), for permutations π and π ′ .
   These examples illustrate how groups can act on indices ω ∈ Ω, but we can apply the same
groups to transform structured variables.
