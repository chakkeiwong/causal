35.4.2     Why conditioning on every neighbour is not a safe shortcut

Aitiotita exposes the correlation measure, arrow-finding component, graph constraints, maxi-
mum conditioning size, and stable, conservative and acyclicity settings separately. Its inspected
PC skeleton routine adds a consequential shortcut once the conditioning depth exceeds two.
For each remaining pair it tests conditioning on the union of their neighbours. If dependence
persists, it marks the link undeletable before enumerating the smaller subsets at that depth.
This rule would need the implication that failure of the largest conditioning set rules out
every smaller separator. Conditional independence does not have that monotonicity property.
(jdellert/aitiotita, 2023)
   An exact project example makes the issue visible in a banking setting. Let Z1 , Z2 , Z3 be
three independent baseline funding factors, X a rate concession, Y a balance response, and C
a later reconciliation score. For this diagnostic, deliberately stipulate no causal effect of X on
Y . Use independent, centered, unit-variance Gaussian inputs and

         X = Z 1 + Z 2 + Z 3 + εX ,        Y = Z 1 + Z 2 + Z 3 + εY ,      C = X + Y + εC .

The shared baselines confound the observational relation, and the later score is a collider.
Conditioning on all three baselines leaves independent residuals εX , εY , so

                                      cov(X, Y | Z1 , Z2 , Z3 ) = 0.

After those baselines are held fixed, conditioning additionally on C conditions on εX + εY + εC .

The variance for Y is also 2/3, hence the partial correlation is −1/2. Adding information

   This example is deliberately constructed to reach depth three. If k baseline factors remain
unconditioned, then the residual covariance of X, Y is k, each residual variance is k + 1, their

population calculation thus invalidates the general shortcut even before finite-sample testing

35.5     A classifier graph and a funding intervention

35.5.1    Weka’s useful role and its causal boundary

Weka’s Bayesian-network classifier provides a useful alternative precisely because its objective
is explicit in the source. The inspected BayesNet first removes records with missing class,
normalizes the data, builds a structure, and estimates conditional probability tables. The
normalization imports a supervised discretizer and a replacement filter for missing values. The
default search object is K2. The common search class initializes the maximum parent count to
one and the naive-Bayes option to true; that initialization adds arrows from the class variable
to every other attribute. (Waikato/weka-3.8, 2022a)
   Suppose the class is twelve-month deposit retention and the attributes include income
recorded before an offer. An arrow from retention to prior income can be an entirely legitimate
predictive factorization. It is not evidence that intervening on retention changes previously
recorded income. Discretizing continuous attributes with information from the class similarly
serves the classifier objective; it requires a separate argument before becoming an unsupervised
causal-discovery transformation. Rows removed because the class is missing also change the
analyzed population. The proposed system should retain Weka as a predictive comparator
with an explicit preparation pipeline, and reject automatic conversion of its default graph into
a causal diagram. (Waikato/weka-3.8, 2022a)
   Selecting an algorithm whose name includes conditional independence does not remove
these questions. In the inspected CISearchAlgorithm, the test compares the local score of
X with parents Z to the score with Y added as a parent. It declares independence if the
extra parent fails to improve the score. The reviewed local-score class defaults to a Bayesian
score, and the IC search’s maximum conditioning cardinality is initialized to two. These source
observations do not describe a Fisher-Z test with an interchangeable significance level. An
optional Markov-blanket classifier correction is another reason to retain the complete search
configuration. (Waikato/weka-3.8, 2022a)
   The inspected test class inherits a general classifier test and returns the default BayesNet.
This is useful evidence about the testing interface, but it is not a campaign measuring correct
causal orientation, identification or effect coverage. The current official Weka source must
also be acquired before extrapolating the old mirror’s defaults to a current proposal. The
mirror’s GPL text and Java 8 build profile are recorded facts about those bytes; neither proves
successful installation in the proposed Java runtime. (Waikato/weka-3.8, 2022a)

35.5.2    A matrix transpose can survive an acyclicity check

Consider a second project diagnostic with liquidity pressure L, rate concession R, retained
balances B, and net funding cost K. Use centered, independent disturbances and normalized
model units:

           R = 0.5L + εR ,       B = 0.3L + 0.8R + εB ,       K = 0.1R − 0.2B + εK .

The coefficients are stipulated examples. The direct rate cost is offset by the reduction in
alternative funding cost associated with retained balances. An intervention increasing R by
one model unit changes balances by 0.8 and changes cost by 0.1 − 0.2(0.8) = −0.06. This is
a total intervention response under the specified equations, not an observational regression
result. (Causal banking research project, 2026x)

For a surgical intervention, replace the treatment equation, remove its incoming coefficients

   There is a second independent failure. If absolute weights are treated as coefficients, the cost
response becomes 0.1 + 0.2(0.8) = 0.26, reversing the decision implied by the original example.
Tetrad’s inspected DAGMA conversion uses absolute weights to decide which unweighted
edges to retain; that is not a promise to return a signed linear model. The adapter must
preserve any available coefficient matrix separately and must not reconstruct coefficients from
the graph. Tetrad’s directed-edge constructor places a tail at the source and an arrowhead at
the target, while its endpoint type also distinguishes circles. Endpoint semantics and numerical
coefficients both require explicit interchange contracts. (Causal banking research project,
2026x; cmu-phil/tetrad, 2026a)
