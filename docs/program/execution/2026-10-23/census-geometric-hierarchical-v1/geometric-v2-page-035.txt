A     Marginalizing GCMs
An important property of GSCMs is that they satisfy the same rules for marginalizing out causal
variables as conventional SCMs.
    In particular, consider a causal variable y with a single child z,

                                    ϵy ∼ p(ϵy )             y = f y (xpa(v) , ϵy ),                    (58)
                                      z
                                    ϵ ∼ p(ϵ )    z                    z
                                                            z = f (y, ϵ )     z

We can marginalize out y and still obtain a valid GSCM. In particular, we obtain

                                 ϵ̃z ∼ p(ϵ̃z )           z ∼ f̃ z (xpa(v) , ϵ̃z )                      (60)
                                     where p(ϵ̃ ) ≜ p(ϵ )p(ϵ )
                                                     z            y       z
                                                                                                       (61)
                                    f̃ z (xpa(v) , ϵ̃z ) ≜ f z (f y (xpa(v) , ϵy ), ϵz )               (62)

Since the product of independent invariant distributions is i.i.d., p(ϵ̃z ) is i.i.d.. Since the composition
of equivariant functions is equivariant, f̃ z is equivariant. So in GSCMs, like in SCMs, we can
marginalize out causal variables with a single child.
    Also, as in SCMs, we cannot marginalize out confounders, i.e. causal variables with more than
one child, since this gives rise to correlation between the children that is not described by the model.
