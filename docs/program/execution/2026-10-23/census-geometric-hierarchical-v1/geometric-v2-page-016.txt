Simulation study. We illustrate with a simulation. The mechanisms generating u, x and y
are assumed to have the same linear plus latent form as for a. From this simulation, we obtain
an array dataset. We assume the variables are measured for 200 rows (e.g. students) and 50
columns (e.g. topics), giving D = (a1:200,1:50 , x1:200,1:50 , y1:200,1:50 ) (Figures 4a to 4c). To perform
inference we place weak priors on the coefficients. We place priors on the latents that are wider
than the data generating distribution, producing misspecification. We implement the model in
NumPyro, and perform automated approximate Bayesian inference using stochastic variational
inference, Automatic Differentiation Variational Inference (ADVI) [Phan et al., 2019, Bingham
et al., 2019, Kucukelbir et al., 2017]. This allows fast inference over hundreds of latent variables.
We estimate the effect of a⋆ = 1 by computing the posterior mean and credible intervals of β x γ
from the variational approximation. Details are in Section D.
    The GCM provides an estimate of the causal effect (Figure 4d). As one comparison, we used
a conventional causal model, a Bayesian linear regression, that ignores correlation across rows or
columns (CM). This corresponds to setting ϵxω1 ⋄ = ϵx⋄ω2 = ϵyω1 ⋄ = ϵy⋄ω2 = 0. As another compari-
son, we used a geometric causal model with the wrong causal graph, assuming x is a confounder
rather than a mediator (GM). The GCM with the correct causal structure provides the estimate
with the least error (Figure 4d). This performance advantage held on average across 20 simulation
configurations (Figure S2a). The GCM also had better calibrated frequentist uncertainty, though
calibration was poor in absolute terms, likely due to the mean-field posterior approximation (Fig-
ure S2b) [Wang and Blei, 2019]. In sum, GCMs can produce accurate causal effect estimates by
accounting for complex non-i.i.d. structure in array data.

Variations. GCMs can also describe many variations and extensions of this array data example.
For graph data, the row i and column j of an interaction matrix both correspond to the same node, so
a natural symmetry is the group of joint permutations of the rows and columns, ϕπ ∈ S : ϕπ (ω) =
(π(ω1 ), π(ω2 )). Distributions invariant to this symmetry are called jointly exchangeable [Orbanz
and Roy, 2015]. Other datasets are grouped or hierarchical, with datapoints collected from different
environments [Peters et al., 2016, Weinstein and Blei, 2026]. Here, environments are exchangeable,
and subunits are exchangeable within each environment, so the distribution is symmetric under the
transformation ϕπ,π1 π2 ... (ω) = π(ω1 )π ω1 (ω2 ), for any sequence of permutations π, π 1 π 2 . . .. All these
symmetries generalize to higher dimensions, to work with tensor data, indexing with Ω = (N ∪ ⋄)d
[Kallenberg, 2005]. In this example we used linear models for estimation, but models can also be
parameterized more flexibly, introducing richer matrix factorizations of the noise and incorporating
nonlinearities into the causal mechanisms.
