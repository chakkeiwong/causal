# LA04 author review

12 October 2026. This disposition concerns a source-grounded survey and design,
not a live-model study or an adopted framework.

The fourteen-stage map covers question formalization, retrieval, ontology and
observation construction, diagrams, discovery, identification, estimation,
longitudinal policies, uncertainty, refutation, code, reporting, monitoring and
operations. Every row supplies a nonagent baseline, evidence handoff, failure,
bounded remedy and remaining qualification. The chapter connects these stages
through funding and servicing targets, treatment-confounder feedback, target
measure changes, graph uncertainty and the cost of review.

The source review adds three pinned orchestration frameworks and fresh selected
anchors in the genuine local Hernán–Robins book. All seven acquired artifacts
per framework have acquisition receipts and verified hashes. Tree/commit
metadata establishes identity, not runtime capability. The 13 package decisions
reuse ten frozen causal-package identities and add these three frameworks.

Review findings resolved before disposition:

- A generic planner is insufficient: task-specific baselines and unresolved
  scientific states now appear at every handoff.
- A root license is not necessarily the code license: AutoGen documentation
  CC-BY-4.0 and AgentChat MIT code are recorded separately. Its maintenance
  declaration informs the deferral decision; its advertised successor is not
  credited with an audited capability.
- Checkpoint resumption is not exact-once publication: LangGraph node replay
  motivates application idempotency. AutoGen model-context persistence is not
  an external-effects journal.
- Usage limits are not unconditional priced bounds: absent pricing remains
  unknown, and token accounting may be post-response.
- Ordinary regression is not a solution to treatment-confounder feedback: the
  chapter states the two-decision g-formula and its sequential assumptions,
  while distinguishing event time from information availability. The equation
  is a project specialization of the inspected primary treatment.
- Retrieved instructions and model assertions cannot grant permissions or
  authenticate assumption approval. The design requires an application-owned
  capability set and exact declaration bindings. Bank authentication remains
  an external implementation requirement.
- Long bibliography hashes initially caused overfull lines; breakable revision
  formatting repairs this. No visual acceptance is inferred from compilation.
