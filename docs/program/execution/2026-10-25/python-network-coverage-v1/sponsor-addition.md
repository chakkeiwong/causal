# Python network candidates need assignment and uncertainty contracts

The Python survey extends the existing MossSpider comparison with ANI, GraphDML, targeted interference, CausalMotifs, CausalGraphCut and Causal-PIE. Their distinct roles include design-based exposure contrasts, graph-aware partially linear estimation, neural representations, learned exposure partitions, allocation design and policy evaluation. A bank must preserve the assignment law, exposure definition, target population and uncertainty when comparing them. These include order-dependent variance fallbacks, covariance aggregation that need not preserve positive semidefiniteness, explicit population/focal-set compatibility, isolated-node behavior, exposure-rule predicates, complete sample accounting, and policy probability calculations under unbalanced assignments. Exact authored examples separate these expression-level findings from installed-package results. The comparison does not execute acquired code or grant native admission. [@exec25_pnet_choice]

ANI and GraphDML are conditional adapter candidates; CausalMotifs is a conditional partition-learning reference. Direct adoption of the targeted neural, allocation-design and learned-policy repositories is deferred pending their distinct technical and rights gates. Tiny known-law experiments can test each candidate independently before costly bank experiments. Uninspected search tails, dependency and artifact provenance, native uncertainty, graph truth and independent acceptance remain open. [@exec25_pnet_choice]
