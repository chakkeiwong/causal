# LA02 author contract review

12 October 2026. The two schemas, four synthetic banking cases and reference
validator satisfy LA02-C1–C3 within the declaration-design scope. Thirty-one
adverse tests pass. Four case reviews retain two ambiguous questions and allow
two explicitly selected synthetic questions to proceed to formal analysis.
Three exact finite counterexamples independently distinguish equivalent-graph
effects, trimmed/overlap targets and Wald/population-ATE targets. These are
analytical constructions, not a registered empirical evaluation.

For C1, question resolution cannot silently contain a selected target when it
is marked ambiguous or refused. Selection binds an explicit population,
measure, outcome, horizon, policy/comparator and loss. The declaration digest
changes when these change. Funding and linkage questions deliberately remain
unresolved. Hypothetical actions cannot become accepted bank actions.

For C2, every edge retains two endpoint marks, an evidence anchor, a scoped
counterevidence record, a reviewer disposition and an optional explicitly
uncalibrated model score. JSON round trips preserve PAG circles. CPDAG marks
cannot be retyped as a DAG. Revision validation checks the supplied predecessor
digest. Model proposals alone cannot be promoted to accepted scientific
evidence, and synthetic reviews cannot be promoted to bank evidence.

For C3, the fixtures exercise delayed availability, derived-variable lineage,
policy history, intermediate confounding, mediators, selection colliders,
unmeasured ownership and infeasible actions. A selected total-effect target
with post-treatment controls or selected-population membership receives an
explicit review block. The graphical role checks are conditional directed-path
diagnostics, not a general adjustment or identification algorithm.

The review found and repaired two initial design omissions: a typed population
measure was needed to prevent target-name substitution, and a contradicted
bound assumption had to block the selected analysis rather than merely appear
in a note. Derived-variable cycles and same-time action leakage are also
rejected. The final tests cover those repairs. An initial pytest collection
failed because the repository uses a src layout; its report is preserved as
`test-collection-failure.xml`. Running with `-o pythonpath=src` resolved it.

Limitations are material. The validator checks declared identities and reference
syntax; it does not authenticate people, source custody or assumption truth.
It does not recognize every MAG/PAG/CPDAG, execute ID or establish complete
graph-class coverage. Its clocks cover finite recorded-value fixtures rather
than every real-time revision protocol. A prepared declaration is neither an
identified effect nor authorization for a bank intervention. LA05 must compose
these objects with the unchanged bounded operation interfaces and preserve
every unresolved state. No downloaded code, model API, sibling repository or
completed IN02/IN04 file was used or changed to produce this evidence.
