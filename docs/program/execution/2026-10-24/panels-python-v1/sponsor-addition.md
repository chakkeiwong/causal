## Python panel estimates need a common target and inference contract

The selected differences and csdid revisions add authenticated Python
comparison references to the existing PyFixest review. Their cohort, event
and calendar targets must be matched before numerical comparisons. Static
inspection identifies different cluster normalizations, an extra-cluster
option lost at one aggregation boundary, and a printed simultaneous label
that can survive a pointwise fallback. Exact authored examples make the
consequences testable; no upstream code or native coverage study was run.
\citep{exec24_panelpy_differences,exec24_panelpy_csdid,exec24_panelpy_contract}

The proposed public study freezes populations, controls, sampling weights,
dependence, actual resample counts and complete failure/refusal denominators.
The earlier linearmodels IV evidence does not qualify its panel engine.
Both new packages remain comparison references pending native, dependency,
rights and scientific qualification. Current software coverage remains
inconclusive; unknown counterfactuals and parallel-trend truth require
restrictions or new information. Illustrative total cost of 3,600 USD yields
20, 24 and 30 USD per requested, conformant and useful output under the
stated 180/150/120 denominators. These are planning values.
\citep{exec24_panelpy_contract}
