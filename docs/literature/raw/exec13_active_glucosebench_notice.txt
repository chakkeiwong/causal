# Third-party attribution

The numerical simulator under `src/glucosebench/_vendor/simglucose` is derived from **simglucose by Jinyu Xie**, https://github.com/jxx123/simglucose, commit `2e897f10f333c76ad383e44a5f98b2586e4aa9ac`.

Copyright (c) 2017 Jinyu Xie. MIT licensed; the full notice is preserved beside the vendored source. All patient, pump, sensor and questionnaire CSV data in that directory come from the same upstream revision. Per-file upstream and vendored SHA256 values are recorded in `PROVENANCE.json`.

Changes to the vendored subset are limited to internal import/resource namespaces, removing an unused matplotlib import, and package initialization without Gym registration. No physiological dynamics, initial-state data, sensor-noise algorithm or pump discretization was changed. The benchmark observation wrapper adds noisy insulin assays outside the physiological model.

The wrapper/protocol originated in Kevin Murphy's MDA repository. The root license covers those additions. This repository should be described as a small adaptation of simglucose, not as an independently developed physiological simulator.
