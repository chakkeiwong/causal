# V12 author plan review

11 October 2026. This is the author's governance review, not independent
scientific acceptance. The plan, machine contracts and controller are reviewed
as one change. Test execution, build identities, visual inspection and the exact
candidate installed are bound by work/P12/installation.json.

The requested repairs were missing as mandatory program outcomes. The existing
44-project software register and software chapter were useful baseline material,
but did not satisfy a systematic several-chapter commercial/open-source review.
The original treatment of language models did not supply the requested frontier
survey, business translation, diagram/discovery analysis or evaluated remedies.
The nine historical repository snapshots were not executed CLI/MCP integration.
The new contracts address each deficiency explicitly.

| Review question | Finding and repair |

The selected implementation uses one state with an additive, versioned control
extension because the original control files and V11 plan are already bound to
historical receipts. Rewriting them would invalidate retained evidence. The
successor checks all old integrity requirements plus the new gates; the old
entrypoint is retained for compatibility status/checks. All V12 mutations use
the successor. An old mutation that bypasses a new receipt requirement is
rejected by the next successor validation; files alone do not constitute review.

Residual limits are explicit. Search completeness is bounded by the recorded
sources and cutoff, not universal omniscience. Software/license/model access and
independent expert judgments may be unavailable. Static validation cannot judge
whether prose is substantive or signatures are authentic. Page allocation still
requires an author's inspected decision. The four separate author, capability,
external and investment gates remain necessary.

The plan is suitable for installation after its behavioral checks, preserved
baseline checks and rendered PDF inspection pass. Passing P12 installs the
program; it does not pass SW01, LA01, IN01 or any repair closure task.
