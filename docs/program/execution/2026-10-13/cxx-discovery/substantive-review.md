The comparison supplies a reviewable proposal decision, with incomplete coverage
kept explicit. It does not award native runtime, MR01, S2 depth, or proposal
acceptance. The author/coordinator performed this review; it is not independent
scientific review.

The recovered plan had two finite search routes and eleven pinned candidates.
The continuation added 26 bounded public reads for two direct upstream leads
and unresolved candidate trees/routines. Twenty-four succeeded; two license

Technical review found material distinctions that the manuscript now preserves:

- aGrUM's native output classes, missing-structure-data refusal and discrete CI
  configuration remain explicit. The existence of parameter EM does not erase
  the structure-learning restriction.
- OpenBNSL's parent-bit storage is indexed by child. Its graph methods distinguish
  directed from undirected edges. Optional CUDA build support does not establish
  GPU-PC, and the CI correction convention must be matched in comparisons.
- XGES has a separate native implementation. Its BIC penalty parameter is not a
  CI significance level, and the inspected intervention-index covariance overload
  ignores its argument. This is an observation about that function, not a claim
  that every XGES-related implementation lacks interventional methods.
- Breaking Bad has real native search code but its distributed scorer throws.
  The source supports deferral of an executable integration, not an assertion
  that the algorithm has no merit.
- rCausalMGM, ccdrAlgorithm and BNSL are R-hosted native paths with different
  data/score/graph contracts. pcalg remains one selected R engine rather than
  gaining duplicate credit for native internals.
- SVI-DAG's inspected model and the LGES upstream path are Python. Repository
  language classification and names of algorithms in a derivative do not prove
  native API identity or source equivalence.
- godai0519/BayesianNetwork contains structure-learning templates even though its
  README emphasizes inference. The review corrected the tempting but unsupported
  inference-only classification before publication.
- COJEC's selected expression differs from full conditional entropy. A separate
  exact counterexample shows that even true zero conditional entropy is not an
  intervention-effect identification argument. No downloaded COJEC execution is
  claimed.
- The old libDAI and OpenGM snapshots document discrete inference roles. Their
  old identity and maintenance limits remain visible without an ecosystem-wide
  absence claim.

The financial example keeps direct and mediated paths separate: -0.1 + 0.5*0.4
= 0.1 outcome units, or USD100,000. Gaussian elimination and direct topological
substitution agree. All six node permutations preserve this effect, and the unit
transformation W'=D^{-1}WD gives the same dollar result. A transposed convention
returns zero; omitting the negative direct coefficient yields USD200,000.

The graph-equivalence example reconstructs the same exact positive-variance
Gaussian covariance under three DAGs and retains the two effect values, rather

and the risk-coarsening example has positive treatment probabilities and a
zero conditional effect despite a 9/25 marginal association. These are exact
project constructions. They are not package trials, fitted public-data results,
empirical coverage evidence or bank estimates.
