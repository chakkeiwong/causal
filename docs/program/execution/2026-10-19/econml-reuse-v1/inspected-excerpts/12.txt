3: ===============================
4: Dynamic Double Machine Learning
5: ===============================
6: 
7: What is it?
8: ==================================
9: 
10: Dynamic Double Machine Learning is a method for estimating (heterogeneous) treatment effects when
11: treatments are offered over time via an adaptive dynamic policy. It applies to the case when
12: all potential dynamic confounders/controls (factors that simultaneously had a direct effect on the adaptive treatment
13: decision in the collected data and the observed outcome) are observed, but are either too many (high-dimensional) for
14: classical statistical approaches to be applicable or their effect on 
15: the treatment and outcome cannot be satisfactorily modeled by parametric functions (non-parametric).
16: Both of these latter problems can be addressed via machine learning techniques (see e.g. [Lewis2021]_).
17: 
18: 
19: What are the relevant estimator classes?
20: ========================================
21: 
22: This section describes the methodology implemented in the class
23: :class:`.DynamicDML`.
24: Click on each of these links for a detailed module documentation and input parameters of each class.
25: 
26: 
27: When should you use it?
28: ==================================
29: 
30: Suppose you have observational (or experimental from an A/B test) historical data, where multiple treatment(s)/intervention(s)/action(s) 
31: :math:`T` were offered over time to each of the units and some final outcome(s) :math:`Y` was observed and all the variables :math:`W` that could have
32: potentially gone into the choice of :math:`T`, and simultaneously could have had a direct effect on the outcome :math:`Y` (aka controls or confounders) are also recorder in the dataset.
33: 
34: If your goal is to understand what was the effect of the treatment on the outcome as a function of a set of observable
35: characteristics :math:`X` of the treated samples, then one can use this method. For instance call:
36: 
37: .. testsetup::
38: 
39:     # DynamicDML
40:     import numpy as np
41:     groups = np.repeat(a=np.arange(100), repeats=3, axis=0)
42:     W_dyn = np.random.normal(size=(300, 1))
43:     X_dyn = np.random.normal(size=(300, 1))
44:     T_dyn = np.random.normal(size=(300, 2))
45:     y_dyn = np.random.normal(size=(300, ))
46: 
47: .. testcode::
48: 
49:     from econml.panel.dml import DynamicDML
50:     est = DynamicDML()
51:     est.fit(y_dyn, T_dyn, X=X_dyn, W=W_dyn, groups=groups)

54: Class Hierarchy Structure
55: ==================================
56: 
57: In this library we implement variants of several of the approaches mentioned in the last section. The hierarchy
58: structure of the implemented CATE estimators is as follows.
59: 
60:     .. inheritance-diagram:: econml.panel.dml.DynamicDML
61:         :parts: 1
62:         :private-bases:
63:         :top-classes: econml._OrthoLearner, econml._cate_estimator.LinearModelFinalCateEstimatorMixin
64: 
65: Below we give a brief description of each of these classes:
66: 
67:     * **DynamicDML.** The class :class:`.DynamicDML` is an extension of the Double ML approach for treatments assigned sequentially over time periods.
68:       This estimator will adjust for treatments that can have causal effects on future outcomes. The data corresponds to a Markov decision process :math:`\{X_t, W_t, T_t, Y_t\}_{t=1}^m`,
69:       where :math:`X_t, W_t` corresponds to the state at time :math:`t`, :math:`T_t` is the treatment at time :math:`t` and :math:`Y_t` is the observed outcome at time :math:`t`.
70: 
71:       The model makes the following structural equation assumptions on the data generating process:
72: 
73:       .. math::
74: 
75:         XW_t =~& A \cdot T_{t-1} + B \cdot XW_{t-1} + \eta_t\\ 
76:         T_t =~& p(T_{t-1}, XW_t, \zeta_t) \\
77:         Y_t =~& \theta_0(X_0)'T_t + \mu'XW_t + \epsilon_t
78: 
79:       where :math:`XW` is the concatenation of the :math:`X` and :math:`W` variables.
80:       For more details about this model and underlying assumptions, see [Lewis2021]_.
81: 
82:       To learn the treatment effects of treatments in the different periods on the last period outcome, one can simply call:
83: 
84:       .. testcode::
85: 
86:         from econml.panel.dml import DynamicDML
87:         est = DynamicDML()
88:         est.fit(y_dyn, T_dyn, X=X_dyn, W=W_dyn, groups=groups)
