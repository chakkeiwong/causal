\section{Weka Bayesian networks as predictive references and causal comparators}
\label{sec:exec24-weka-reuse}

A bank can use a Bayesian-network classifier to predict a borrower's observed
repayment while still lacking an answer about what a servicing intervention
would change. Both tasks may display a directed graph and probability tables,
yet they condition on different information and impose different scientific
requirements. Weka is consequently useful to the proposal as a concrete
predictive comparator and software reference. Its selected classifier must not
inherit causal-discovery or intervention guarantees merely from the words
Bayesian network. The earlier Java and temporal surveys remain distinct
evidence, with their original limitations.~\citep{exec13_java_weka,exec15_javatemporal_weka,exec24_weka_source}

\paragraph{A historical source identity rather than an invented current release.}
The inspected GitHub mirror ends at a pinned 10 August 2022 revision. Its
README explicitly directs users to the official Waikato Git service and says
the mirror is no longer updated. The source resource says
\texttt{3-8-7-snapshot}, and the build descriptor says 3.8.7-SNAPSHOT. These
declarations agree on a development identity; they do not establish a published
2026 distribution. The official successor's cutoff identity is unresolved in
the present source collection. The build declares GPL terms and Java profiles
alongside numerical, parser and runtime dependencies. Actual binary identity,
complete notices, support and distribution arrangements need separate review;
neither a historical snapshot nor process isolation clears those obligations.
\citep{exec24_weka_source}

\paragraph{What the default classifier actually learns.}
The selected BayesNet source initializes K2 structure search and a simple
conditional-probability estimator. Its training path removes rows whose class
is missing, applies supervised discretization to non-nominal predictors and
fits a replacement filter for missing predictors. The structure-search base
class initializes a naive-Bayes graph by default, with arrows from the class
to every other variable and a one-parent limit. K2 puts the class first in
its ordering and searches only earlier candidate parents. With these defaults,
the initial class parent already fills the one-parent budget for each other
variable. This is a source-level description of a classifier configuration;
it cannot be interpreted as a finding that future default status causes a
borrower's previously measured characteristics.~\citep{exec24_weka_source}

Changing the initialization, parent bound, search family or class column
changes the procedure. The selected conditional-independence search compares
local scores with and without a parent; it is not the Fisher-Z test with a
declared significance level used by the earlier restricted Tetrad candidate.
An optional classifier correction can add arrows to connect variables to the
class's Markov blanket. The randomized K2 order also constructs a new random
generator in its selected path without a locally supplied seed argument.
Consequently an adapter needs an explicit algorithm, effective settings,
ordering, randomization and output-class contract. An algorithm label is
insufficient for either scientific comparison or reproducibility.
\citep{exec24_weka_source}

\paragraph{Conditioning does not perform an intervention.}
For a discrete network with parents $\operatorname{pa}(j)$, the selected
estimator forms a joint factorization
\[
 \widehat p(x)=\prod_j\widehat p_j(x_j\mid x_{\operatorname{pa}(j)}).
\]
Its class-probability routine evaluates that product for each candidate class
value and normalizes across classes. With observed predictors $X=x$, the
result represents a fitted $\widehat p(Y=y\mid X=x)$. It does not delete the
treatment-assignment factor or justify invariance of the remaining mechanisms.
For a causal DAG under appropriate structural assumptions, an intervention
would instead replace the action mechanism and use the corresponding truncated
factorization. Those assumptions and the identification step are additional
inputs, not consequences of conditional-probability normalization.
\citep{exec24_weka_source,exec24_weka_choice}

An exact authored example makes the distinction operational. Let an unobserved
binary borrower type $U$ have probability one half. Let success be $Y=U$,
and let action $A$ be assigned with probabilities $4/5$ when $U=1$ and $1/5$
when $U=0$. There is no arrow from action to outcome. Bayes' rule gives
\[
 P(Y=1\mid A=1)=4/5,\qquad P(Y=1\mid A=0)=1/5,
\]
whereas replacing the action assignment leaves
\[
 P(Y=1\mid\operatorname{do}(A=1))=
 P(Y=1\mid\operatorname{do}(A=0))=1/2.
\]
All treatment levels have positive probability in both type strata; the failure
is uncontrolled confounding, not zero exposure probability. If 1,000 accounts
are each worth 100 USD per incremental success and the action costs 10,000 USD,
misreading the conditional difference as a causal effect gives a net 50,000 USD.
The stipulated true causal value is minus 10,000 USD. A well-fitted classifier
can reproduce the observational conditionals perfectly and still give no
justification for the first investment calculation.~\citep{exec24_weka_choice}

\paragraph{Smoothing and weights change the statistical object.}
The selected estimator initializes each category count to $\alpha$, defaulting
to one half, and then adds instance weights. If a parent configuration $j$
has weighted counts $n_{jk}$ for $K$ categories, its fitted table is
\[
 \widehat p_{jk}=\frac{n_{jk}+\alpha}
 {\sum_{\ell=1}^{K}n_{j\ell}+K\alpha}.
\]
For binary counts $(0,1)$ the result is $(1/4,3/4)$. Multiplying the data
weights by ten while retaining the same prior gives $(1/22,21/22)$.
An unobserved binary row returns $(1/2,1/2)$ under the default positive prior.
Finite probabilities in such a row do not create observed treatment support
or validate a transport assumption. The worker must retain prior strength,
category dictionary, support counts and the meaning of weights.
\citep{exec24_weka_source,exec24_weka_choice}

The inspected plain local-score path increments integer counts once per row,
whereas the simple CPT estimator uses each instance's weight. Two category
observations with weights one and nine therefore contribute counts $(1,1)$
to that selected search-score path and $(1,9)$ to CPT estimation. With the
same half-count smoothing, the corresponding probability illustrations are
$(1/2,1/2)$ and $(3/22,19/22)$. The first is an illustration of the score's
row-count sufficient statistics, not a claim that this score outputs a
probability vector. The mismatch requires an explicit weight contract and a
native fixture; it is not resolved by the classifier declaring a weighted-data
interface. Other search and ADTree paths need separate qualification.
\citep{exec24_weka_source,exec24_weka_choice}

\paragraph{Preprocessing defines the target population and information clock.}
The supervised discretizer chooses cut points using class counts and entropy.
Fit it only within the permitted training split and retain its boundaries when
processing a held-out borrower. Choosing cut points with evaluation labels
would leak outcome information. Even when correctly split, a category produced
by this procedure is a data-dependent measurement transformation; its meaning
must be reconciled with any causal estimand stated for the original continuous
quantity. A predictive cut point does not supply a bank intervention rule.
\citep{exec24_weka_source}

Removal of missing-class rows can also change the population. In an authored
example, success has population probability one half, success labels are always
observed, and failure labels are observed with probability one quarter. Among
observed labels, success then has probability
\[
 \frac{(1/2)\cdot1}{(1/2)\cdot1+(1/2)\cdot(1/4)}=4/5.
\]
This is a selected sample, not a newly discovered improvement in borrower
quality. The source does not by itself correct the selection mechanism. A
proposal must state the label clock, selection probabilities or assumptions,
target population and necessary sensitivity analysis before extrapolation.
\citep{exec24_weka_choice}

The replacement delegate computes weighted modes and means from its fitted
batch, excludes the class from replacement, and reuses the fitted values on
later instances. In its standalone numeric branch, a column without observed
weight retains the initialized zero replacement; in a nominal column with
declared categories and no observations, all-zero counts select the first
category through the maximum-index helper. The full BayesNet pipeline
discretizes non-nominal predictors before this delegate, so these primitive
branches must not be conflated with every end-to-end outcome. Missing masks
and all-missing warnings remain necessary. Single replacement values neither
integrate missing-value uncertainty nor establish a missing-at-random law.
\citep{exec24_weka_source}

\paragraph{Graph import and output validation.}
The selected initial-BIF path matches a node by name but bounds its parent loop
using the original dataset index rather than that matched source index. For a
source ordering $[A,B]$ with $A\to B$ and a dataset ordering $[B,A]$, the first
node's requested parent count is zero although $B$ has one parent; the second
uses a count of one for a node with no parents. This is an exact index witness
for the selected source statements. It does not assert the exception type or
runtime outcome of a compiled import. Require permutation-equivariant node and
category mappings and compare the complete imported parent sets and tables.
The warning that an unknown parent is ignored must become an explicit rejected
or incomplete request when graph preservation is required.
\citep{exec24_weka_source,exec24_weka_choice}

The class-probability routine computes in log space and subtracts the largest
log score before exponentiating. This improves ordinary numerical scaling,
but it is not a guarantee that every input yields a valid probability vector.
Its normalization helper rejects a zero or NaN sum, and the selected caller
catches that exception and returns an all-zero vector as a missing prediction.
Such a vector sums to zero, not one. A downstream decision rule must not read
it as zero risk or a confident class. Validate dimensions, labels, finiteness,
nonnegativity and unit sum; retain the distinct failure state and its cost.
The generic inherited classifier test does not establish any causal calibration
or these complete integration conditions.~\citep{exec24_weka_source,exec24_weka_choice}

\paragraph{Disposition and a concrete public qualification.}
Retain the pinned classifier and source as a historical reference and a
conditional predictive comparator. Defer unrestricted adoption until a
permitted official successor identity, selected scientific task, full rights
and reproducible environment are established. An isolated Java integration
could be economical when it preserves typed inputs, preprocessing, ordering,
weights and complete failure semantics. Porting a Bayesian-network engine
creates new search, probability and maintenance obligations without a measured
benefit here. Reject using this classifier graph as an automatically identified
causal model; retain separately specified causal and predictive alternatives.
\citep{exec24_weka_choice}

The scientific owner defines prediction versus intervention, observed-label
selection, support and temporal split. The adapter owner validates imports,
preprocessing state, output simplex and failures. The platform and rights owner
resolves actual artifacts, notices and maintenance; the evaluation owner
predeclares generated confounding, selection, empty-row, weight-rescaling,
node-permutation and numerical-refusal fixtures. A 7,200 USD authored trial
with 360 submitted, 300 completed and 240 qualified tasks costs respectively
20, 24 and 30 USD per task. Include failed fits, analyst correction, upgrades
and review rather than reporting successful-call runtime as investment value.
\citep{exec24_weka_choice}

Known routes exist for official source access, artifact and license inspection,
typed native public fixtures and fair predictive comparison. Unknown bank
assignment, missing-label truth and causal sufficiency require new information
or defensible restrictions; a software wrapper cannot manufacture them. The
reference decision gives no native, causal or economic qualification.
Independent validation remains outstanding.
