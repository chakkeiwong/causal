Chapter 38

From a learned graph to a defensible
calculation

A graph becomes useful to a bank when its statistical meaning survives the next calculation.
Directed, partially directed and mixed graphs encode different information. The Tetrad bridge
comparison first follows variable identity, categories and endpoint marks across languages.
Weka and Banjo then show why a predictive factorization or a lagged search still needs
a separate intervention argument. The remaining studies examine calculations under a
supplied model: libDAI distinguishes conditioning from intervention and numerical stability
from accuracy; aGrUM connects identified formulas to support and counterfactual coupling;
OpenGM distinguishes marginal inference from joint optimization. Together these comparisons
ask which part of a banking request a numerical result actually answers.


38.1     Tetrad across language boundaries: preserving the scien-

38.4.3    Clamping evidence does not perform a causal intervention

The inspected factor-graph clamp multiplies neighboring factors by a single-state indicator.
This conditions the original distribution on an observation. In a causally justified Bayesian
network, an intervention instead replaces the factor governing the action by the specified
assignment mechanism, while retaining the other mechanisms. The factor graph alone does not
say which table was an action’s causal mechanism. That provenance must survive compilation
(libDAI authors and mirror contributors, 2012; Causal banking proposal project, 2026dm).
   An exact authored example makes the distinction observable. Let U be fair binary, let
P (A = U | U ) = 4/5, and let Y = U . Then P (Y = 1 | A = 1) = 4/5, while P (Y = 1 | do(A =
1)) = 1/2 and the intervention contrast is zero. The conditioning calculation retains p(A | U );
the intervention calculation replaces it. This example supplies the causal model explicitly. It
does not infer that model from the observed distribution (Causal banking proposal project,
2026dm).

38.4.4    Exact inference has numerical and resource conditions

The selected exact enumerator multiplies factors into a full joint table, computes its sum and
normalizes marginals. Its algorithmic exactness is conditional on the supplied finite model; it
does not imply exact arithmetic. For two singleton factors with entries (10−200 , 2 · 10−200 ), the
mathematically normalized product is (1/5, 4/5), but both binary64 products underflow to zero
in the independent witness. A log-scale calculation with maximum subtraction recovers the
intended normalized ratio. An exactly zero normalizer instead denotes an impossible or invalid
query and must be refused. Scaling factors and tracking their scales can preserve normalized
beliefs, but the scales must also be restored when reporting log Z. The inspected probability
primitive explicitly refuses a zero norm; finite, nonnegative inputs and finite outputs require
additional checks (libDAI authors and mirror contributors, 2012; Causal banking proposal
project, 2026dm).
  Resource use is another part of the result. A full joint table on thirty binary variables
has 230 entries: eight-byte entries alone require 8 GiB, before containers and intermediate
products. Junction-tree inference can exploit structure, but its clique tables may still be large.
The selected constructor chooses an elimination heuristic and applies a memory estimate with
a documented heuristic multiplier. An estimate is not an operating-system resource limit.
A proposed worker needs its own memory, time, cancellation and output limits, and must
report when a requested exact calculation was refused or replaced by an explicitly approved
approximation (libDAI authors and mirror contributors, 2012; Causal banking proposal project,
2026dm).


38.4.5    A zero convergence residual can coexist with a wrong marginal

Belief propagation iterates messages, with configured update order, damping, log-domain
arithmetic, tolerance and iteration/time bounds. The selected implementation returns the
largest change in beliefs; a nonconvergence warning is conditional on verbosity. It explicitly
omits NaN checks in the iteration loop. A worker must inspect residuals, iteration counts,
finite values and termination conditions independently of textual logs. Even a finite residual
below tolerance does not bound marginal error (libDAI authors and mirror contributors, 2012).
   Consider an authored triangle of binary variables with edge factor three when neighboring

marginals are one half in both calculations, so inspecting only those marginals would miss the

but that distinction is not preserved in this routine’s return code. Its arg method supports
the first stored labeling and returns UNKNOWN for a requested higher rank. These are concrete
source contracts, not a report from an installed worker (OpenGM contributors, 2019).
   For a two-variable authored energy table, let the enumeration order (0, 0), (1, 0), (0, 1), (1, 1)
have energies 5, 4, 3, 0. Stopping after two visits produces incumbent 4; complete enumeration
produces 0. The four-unit difference is known because this tiny example has an exact oracle.
In a larger case, NORMAL alone does not supply either an exhaustion certificate or a finite
optimality gap. The proposed response must therefore include the visited/requested state
counts where meaningful, visitor stop reason, incumbent, independently valid bound and
algorithm configuration (Causal banking proposal project, 2026dv).
   The inherited base inference interface further returns an inverse-neutral value for its default
bound when the accumulator has an ordering, and a not-a-number value when it does not. For
floating-point minimization, the selected inverse neutral is negative infinity. The brute-force
class does not override that bound in the inspected header. Exhaustion may justify an exact
result under valid arithmetic, but merely reading its default bound does not yield a useful
finite certificate. Unsupported marginals return UNKNOWN in the base interface. A uniform
response schema must preserve those distinctions instead of manufacturing a probability or
gap (OpenGM contributors, 2019).
