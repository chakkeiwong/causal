## BayesiaLab and Bayes Server as separate commercial references

Two named reference decisions compare BayesiaLab's desktop/Engine profiles
with Bayes Server's intervention and abduction workflow. Retained official
pages support these scoped comparisons; mutable documentation is not an exact
cutoff snapshot, an installed build or an accepted bank agreement. Bayesia's
documented REST inference profile is distinct from its Java learning/modeling
configurations. Bayes Server's factual-evidence, characteristic-variable and
intervention sequence motivates a separate counterfactual contract.
