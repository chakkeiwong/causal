4.3 On Adjustment Sets
We consider the Generalized adjustment criterion (Perković et al., 2018) defined as follow:

Definition 10 (Generalized adjustment criterion (Perković et al., 2018)) Let Z ⊆
V \ {T, Y } be a node set in PV . Z satisfies the generalized adjustment criterion if the fol-
lowing three conditions hold:
      (Amenability) PV is amenable relative to (T, Y ); and

      (Forbidden Set) Z ∩ Forb(T, Y, PV ) = ∅; and

      (Blocking) all proper definite status non-causal paths from T to Y are blocked by Z.
Note that Forb(T, Y, PV ) := ∪α∈S(T,Y,PV ) PossDe(α, PV ), and S(T, Y, PV ) is the set of all
nodes in a proper directed path from T to Y in PV (exclude T itself ).

   Its first key condition is the Amenability, defined as follow:

Definition 11 (Amenability (Perković et al., 2018)) For T, Y ∈ V, PV is amenable
relative to (T, Y ) if every proper possibly directed path from T to Y in PV starts with a visible
edge out of T .

    First, we show the Algorithm 3 can produce a PAG PV that is amenable to (T, Y ) when
PE is amenable to (T, Y ). If PE is not amenable, that means we cannot find an adjustment
set even if all possible factors from given unstructured data are given.

Proposition 12 Let W be the node set returned by Algorithm 3 on T and Y . If PE is
amenable relative to (T, Y ), then PV is amenable relative to (T, Y ).

    The next proposition will be used in later proof. It says that we can identify some special
arrow tails in the PAG PV produced by Algorithm 3.

Proposition 13 Let W be the node set returned by Algorithm 3 on T and Y . If α and γ
are two adjacent nodes in a possibly directed path from T to Y in PV , then the arrow tail in
PE are preserved in PV within {α, γ}.

    With the proposition 13, we can identify definite status paths between T and Y . A
definite status path is consists of colliders and definite non-colliders, where a definite non-
collider means there is at least one edge out of this node. Therefore, we need to identify
arrow tails by proposition 13.

Corollary 14 Let W be the node set returned by Algorithm 3 on T and Y . Let u be a path
from T to Y in PE . u is a definite status in PV if and only if it is definite status in PE .
