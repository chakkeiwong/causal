Adversarial (𝑑 = 3): Spurious correlation is explicitly embedded. The scenario
presents a strong statistical association between two variables that are not causally
related (or are causally related in a non-obvious way). Gold diagnosis requires iden-
tifying the confounding structure and explicitly stating that the apparent correlation
is not causal. There are 4 adversarial scenarios (one per domain).
    The adversarial difficulty level is particularly important because it directly tests
the correlation-causation distinction—arguably the most common and consequential
failure mode of causal reasoning, both in humans and in AI systems.

4.5 Task Types
Each scenario is evaluated under all four task types, yielding 12 × 4 = 48 unique
scenario-task combinations:

Definition 2 (Task Types). cause identify (𝜏1 ): Given a scenario description and an
observed effect, identify the primary cause. This tests Rung 1–2 reasoning: the model
must distinguish the true cause from correlates and confounders.
effect predict (𝜏2 ): Given a cause and context, predict the most likely downstream
effect. This tests Rung 2 reasoning: the model must reason about the consequences of
a known cause within a specific context.
counterfactual (𝜏3 ): Given an event that has occurred, reason about what would
have occurred under a specified counterfactual condition. This tests Rung 3 reason-
ing: the model must construct a coherent alternative scenario and reason about its
consequences.
causal chain (𝜏4 ): Given a multi-step scenario, trace the complete causal chain from
initial trigger to final outcome. This tests extended Rung 2 reasoning: the model must
identify and correctly order all intermediate causal links.

4.6 Prompting Strategies
Each scenario-task pair is evaluated under four prompting strategies, yielding 48 ×
4 = 192 unique evaluation configurations per model (with 2 replicates each = 384
instances):
Direct (di): The causal question is asked without any reasoning instruction. The
prompt contains only the scenario description and the task-specific question. This
serves as the baseline for measuring the effect of prompting strategies.
Chain-of-Thought (ct): The prompt appends “Let’s think step by step.” after the
question. This established prompting strategy [32] has been shown to improve
reasoning on many tasks.
Socratic (so): The prompt appends “Before answering, write three clarifying sub-
questions about the causal mechanism, then answer each sub-question, and finally
provide your answer to the original question.” This strategy is designed to elicit
deeper engagement with the causal structure by requiring the model to decompose
the problem [37].
