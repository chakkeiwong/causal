6: Targeted maximum likelihood estimation of parameters of a marginal structural model, and of marginal treatment effects of a binary point treatment on an outcome. In addition to the additive treatment effect, risk ratio and odds ratio estimates are reported for binary outcomes. The \code{tmle} function is generally called with arguments \code{(Y,A,W)}, where  \code{Y} is a continuous or binary outcome variable, \code{A} is a binary treatment variable, (\code{A=1} for treatment, \code{A=0} for control), and \code{W} is a matrix or dataframe of baseline covariates. The population mean outcome is calculated when there is no variation in \code{A}. If values of binary mediating variable \code{Z} are supplied, estimates are returned at each level of \code{Z}. Missingness in the outcome is accounted for in the estimation procedure if missingness indicator \code{Delta} is 0 for some observations.  Repeated measures can be identified using the \code{id} argument. Option to adjust for biased sampling using the \code{obsWeights} argument. Targeted bootstrap inference can be obtained in addition to IC-based inference by setting \code{B} to a value greater than 1 (10,000 recommended for analyses requiring high precision).}
7: \usage{
8: tmle(Y, A, W, Z=NULL, Delta = rep(1,length(Y)), Q = NULL, Q.Z1 = NULL, Qform = NULL, 
9:      Qbounds = NULL, Q.SL.library = c("SL.glm", "tmle.SL.dbarts2", "SL.glmnet"), 
10:      cvQinit = TRUE, g1W = NULL, gform = NULL, 
11:      gbound = NULL,  pZ1=NULL,
12:      g.Zform = NULL, pDelta1 = NULL, g.Deltaform = NULL, 
13:      g.SL.library = c("SL.glm", "tmle.SL.dbarts.k.5", "SL.gam"),
14:      g.Delta.SL.library =  c("SL.glm", "tmle.SL.dbarts.k.5", "SL.gam"),
15:      family = "gaussian", fluctuation = "logistic", alpha = 0.9995, id=1:length(Y), 
16:      V.Q = 10, V.g=10, V.Delta=10, V.Z = 10,
17:      verbose = FALSE, Q.discreteSL=FALSE, g.discreteSL=FALSE, g.Delta.discreteSL=FALSE,
18:      prescreenW.g=TRUE, min.retain = NULL, target.gwt = FALSE, automate=FALSE,
19:      obsWeights = NULL, alpha.sig = 0.05, B = 1, evalATT = TRUE)
20: }
21: \arguments{
22:  \item{Y}{continuous or binary outcome variable}
23:   \item{A}{binary treatment indicator, \code{1} - treatment, \code{0} - control}
24:   \item{W}{vector, matrix, or dataframe containing baseline covariates}
25:   \item{Z}{optional binary indicator for intermediate covariate for controlled direct effect estimation}
26:   \item{Delta}{indicator of missing outcome or treatment assignment.  \code{1} - observed, \code{0} - missing}
