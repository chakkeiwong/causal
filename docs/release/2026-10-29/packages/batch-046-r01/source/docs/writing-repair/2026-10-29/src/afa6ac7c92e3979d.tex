\section{LiNGAM reuse: model assumptions, matrix meaning and bootstrap summaries}
\label{sec:exec24-lingam-reuse}

A bank may ask whether a funding-price change affects retained balances
through service quality as well as directly. A learned directed matrix
can organize that question, but only a declared structural model gives
its entries intervention meaning. The selected LiNGAM source is a useful
reference for a bounded linear discovery prototype. Its many static,
latent and temporal interfaces must be qualified separately.
\citep{exec24_lingam_source,exec24_lingam_choice}

The inspected revision is dated 8 September 2026 and its initializer
reports version 1.13.0. The selected technical files and newly acquired
build, requirements and initializer text authenticate to the preserved
repository tree. A repository version string does not establish equality
with an installed wheel. The top-level MIT text is retained; transitive
distribution rights, binary dependencies and supported deployment remain
unverified. No downloaded package is imported or executed here.
\citep{exec24_lingam_source}

\subsection{A discovery model must match the banking information problem}
The inherited original LiNGAM model assumes linear acyclic equations,
mutually independent non-Gaussian disturbances and causal sufficiency,
with independent observations of the variable vector. Those restrictions
are substantial for a bank with common calendar shocks, endogenous
customer selection or missing operational causes. The original ICA-based
argument is not a proof for every current DirectLiNGAM option or for the
entire proposed banking workflow.~\citep{exec13_pydisc_shimizu2006}

An LLM may help elicit candidate variables, units, clocks and prohibited
directions, but those suggestions require scientific review. They cannot
establish independent shocks or the absence of hidden confounding. The
proposed interface must retain the human-approved assumption set and its
source, and return an unsupported or conditional result when that model
does not fit the question. A latent-variable or longitudinal class elsewhere
in the package is a separate candidate, not automatic repair of this model.
\citep{exec24_lingam_choice}

The selected DirectLiNGAM path validates the data shape and prior matrix,
iteratively selects a causal order, residualizes other variables and then
estimates adjacency. It exposes hard or soft prior knowledge, several
independence measures and optional adaptive-Lasso pruning. The inspected
dispatch has explicit kernel and GPU branches and an alternative branch
for the pairwise routine. A wrapper should whitelist intended options
rather than rely on an unrecognized string reaching that alternative.
The GPU branch requires an additional dependency and separate qualification.
\citep{exec24_lingam_source}

\subsection{Matrix orientation, path priors and total effects are distinct}
The coefficient convention is $B_{ij}$ for the effect of predictor $j$
in the equation for target $i$, so
\[
 X=BX+\varepsilon.
\]
For a strictly acyclic three-variable system, $B^3=0$ and
$(I-B)^{-1}=I+B+B^2$. An authored example uses
\[
 B=\begin{pmatrix}0&0&0\\2&0&0\\-1&3&0\end{pmatrix}.
\]
The direct first-to-third coefficient is $-1$, while the mediated path
contributes $2\cdot3=6$, giving total derivative $5$. If the third variable
is measured in thousand USD and the stipulated intervention changes the
first by $1/5$ unit, the assumed gross response is 1,000 USD. Subtracting
an assumed 800 USD cost gives 200 USD. These calculations condition on
the invariant equations; they are not learned graph evidence or observed
bank returns.~\citep{exec24_lingam_choice}

The inspected prior-knowledge utility writes a declared path from $i$ to
$j$ into matrix position $(j,i)$. Path restrictions are not simply a list
of direct edges. The model conversion must retain the node order and the
distinction between required paths, forbidden paths and unknown relations.
Round-trip fixtures should use an asymmetric chain and an indirect path,
so a transpose or a path-to-edge substitution cannot pass unnoticed.
\citep{exec24_lingam_source,exec24_lingam_choice}

The base estimation method fits a destination on the source and its
estimated parents. It warns when the fitted causal order places the
destination before the source, but still returns a regression coefficient.
A separate utility sums products over directed paths in a supplied matrix,
with a declared continuity restriction. These two numerical constructions
must remain named separately; agreement in an idealized model is not a
guarantee of equality after finite-sample pruning or model error.
\citep{exec24_lingam_source}

Adaptive-Lasso selection standardizes the data, derives weights from
ordinary regression and applies a BIC criterion. It then refits retained
predictors on original units. The returned coefficient is therefore not
merely the raw penalized coefficient on the standardized design. A faithful
port would need to preserve the selection rule, centering, scaling,
retained columns and final refit. An external worker can preserve that
behavior with less reimplementation, but still needs native fixtures and
versioned dependencies.~\citep{exec24_lingam_source,exec24_lingam_choice}

\subsection{Bootstrap frequencies and selected-effect summaries have different denominators}
The generic bootstrap resamples rows and refits the model, retaining
adjacency matrices, path-based total effects and resampled indices.
Its local resampling call does not receive the object's random-state
attribute explicitly. Reproducibility therefore needs an inspected RNG
contract, not an assumption based only on a constructor parameter.
The loop mutates the fitted object through successive fits; a worker must
declare whether the returned object represents the initial fit or the
last replicate.~\citep{exec24_lingam_source}

The bootstrap result's probability method counts coefficients above an
absolute threshold. Its total-effect summary calculates the corresponding
threshold frequency, then takes a median among nonzero effects using a
different filter. For authored replicate effects $(0,1/10,9/10)$ and
threshold $1/2$, the threshold frequency is $1/3$. The nonzero-effect
median is $1/2$, whereas the median restricted to values above threshold
is $9/10$. The two summary fields describe different selections.
Neither the frequency nor the conditional median is, by itself, a
posterior probability that an edge is true or a confidence interval for
the intervention effect.~\citep{exec24_lingam_source,exec24_lingam_choice}

The probability method also converts missing matrix entries before
thresholding. A proposed result contract should retain nonfinite entries
and their origins as explicit states rather than silently interpreting
them as evidence of edge absence. Failed fits, empty selections, zero
effects and unestimated directions need separate statuses. Every request
and replicate belongs in the availability denominator.
\citep{exec24_lingam_source,exec24_lingam_choice}

Independent row resampling does not automatically respect common shocks
or repeated servicing histories. Under a stipulated law of four independent
unit-variance shocks, their mean has variance $1/4$; under a single shared
unit-variance shock observed four times, its mean has variance $1$.
The sample count alone cannot select the correct resampling law.
These are authored probability calculations, not package coverage results.
\citep{exec24_lingam_choice}

The selected VAR bootstrap uses a separate residual-resampling and
sequence-reconstruction path. It disables the lag-selection criterion
before fitting and restores it after normal completion. That path does
not automatically include lag-selection uncertainty, and its local
restoration is not protected by a surrounding finally block. A bounded
worker needs exception cleanup, original-versus-resolved settings,
initialization history and a scientific argument for the innovation law.
Those source observations do not establish a native failed run.
\citep{exec24_lingam_source}

\subsection{A reference choice and a conditional worker route}
The selected build metadata requires Python at least 3.10, scikit-learn
at least 1.6 and SciPy at most 1.13.1, alongside declared numerical,
graphical, statistical and modeling dependencies. The requirements text
explains selected compatibility constraints and lists the GPU package as
optional. The initializer imports numerous model families. A narrow use
case still requires a reproducible environment and inspection of the
actual dependency and import path; a successful source audit does not
qualify an installation.~\citep{exec24_lingam_source}

The present choice is source reference. Conditional integration through
an isolated Python worker is preferable for a justified prototype once
scientific premises, environment, rights and fixtures are qualified.
Direct adoption of a general bank discovery service is deferred. A full
port is deferred until measured constraints justify maintaining equivalent
graph, pruning, solver, RNG and bootstrap behavior. Constraint-based or
score-based discovery can address different model assumptions; inherited
Tetrad and other-language comparisons remain separate candidates with
their own limits. An authored matrix oracle is useful for conversion
checks, not a replacement discovery algorithm.
\citep{exec24_lingam_choice}

The scientific owner must approve variables, clocks, assumptions and
intervention meaning. The adapter owner must preserve orientation, path
priors, matrix versus regression effects, thresholds and refusal states.
The platform and rights owner must qualify the full distribution and
resource envelope. The evaluation owner must preregister independent and
dependent known-law fixtures, adverse priors, non-Gaussianity departures,
hidden confounding, constant columns, failed fits and RNG replay.
An illustrative 4,200 USD workflow over 210 requested, 175 finite and
140 accepted results costs 20, 24 and 30 USD respectively; measured
all-request compute, engineering, validation and maintenance remain unknown.
\citep{exec24_lingam_choice}

Public fixtures can test the proposed worker before costly bank experiments.
They cannot certify an unknown business graph, create unobserved causes
or supply a universal dependence correction. Selected static, temporal,
latent and nonlinear families require their own qualification. Execution and independent validation remain outstanding.
\citep{exec24_lingam_choice}
