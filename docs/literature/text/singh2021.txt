                                                                                           Abstract
                                                      I construct and justify confidence intervals for longitudinal causal parameters es-
                                                      timated with machine learning. Longitudinal parameters include long term, dy-
                                                      namic, and mediated effects. I provide a nonasymptotic theorem for any longi-
                                                      tudinal causal parameter in a general class, estimated with any machine learning
                                                      algorithm that satisfies a few simple conditions. The main result encompasses lo-
                                                      cal parameters defined for specific demographics as well as proximal parameters
                                                      defined in the presence of unobserved confounding. I prove consistency, Gaussian
                                                      approximation, and semiparametric efficiency. The rate of Gaussian approxima-
                                                      tion is n−1/2 for global parameters, and it degrades gracefully for local parameters.
                                                      I articulate a simple set of conditions to translate mean square rates into statistical
                                                      inference, and verify that they hold for adversarial estimators over generic func-
                                                      tion spaces. A key feature of the main result is a new multiple robustness to ill
                                                      posedness for proximal causal inference in longitudinal settings. Of independent
                                                      interest, I provide what appears to be the first mean square rate for nested nonpara-
                                                      metric instrumental variable regression.


                                          1 Introduction
                                          The goal of this paper is to construct and justify confidence intervals for longitudinal causal param-
                                          eters estimated with machine learning. Longitudinal causal parameters include long term, dynamic,
                                          and mediated treatment effects. The additional difficulty of longitudinal causal inference, relative to
                                          static causal inference, is dealing with variables that are observed after the intervention but before
                                          the outcome. In long term studies, these are the short term surrogate outcomes; in dynamic studies,
                                          these are the covariates collected between doses; and in mediation studies, these are the mechanisms
                                          we wish to understand.
                                          Such variables must be integrated out according to their counterfactual distributions conditional
                                          on the intervention. As such, the counterfactual conditional distribution is an additional nuisance
                                          parameter that arises in longitudinal causal inference but does not arise in static causal inference.
                                          Explicitly or implicitly estimating the counterfactual distribution with a machine learning algorithm
                                          introduces bias that compounds and interacts with the usual bias that arises when using machine
                                          learning in static causal inference. This complex interplay makes traditional statistical inference
                                          challenging.
                                          I present a general theorem for statistical inference over a broad class of longitudinal causal parame-
                                          ters and a broad class of machine learning algorithms. I provide a simple set of conditions which can
                                          be verified using mean square rates provided by statistical learning theory. Unlike previous work,
                                          I provide a finite sample analysis for any global or local longitudinal causal parameter estimated
                                          using any machine learning algorithm, subject to these simple conditions. The machine learning

I make the following contributions.
Statistical. I provide a machine learning inference result for a general class of longitudinal causal
parameters, allowing analysts to use machine learning and obtain confidence intervals in several lon-
gitudinal settings where they previously could not: (i) long term effects where the treatment is only
observed in an experimental sample and the long term outcome is only observed in an observational
sample; (ii) heterogeneous dynamic and mediated effects; and (iii) proximal longitudinal parame-
ters. For global parameters of the full population, I prove consistency, Gaussian approximation, and
semiparametric efficiency. For local parameters of specific subpopulations, I prove consistency and
Gaussian approximation. The rate of convergence is n−1/2 for global parameters, and it degrades
gracefully to nonparametric rates for local parameters. The main result is nonasymptotic, explicitly
accounting for each source of error in any finite sample size. The result implies asymptotic uniform
validity over large classes of models, translating into honest confidence intervals. Along the way, I
provide a simple set of steps for constructing Neyman orthogonal moment functions of longitudinal
causal parameters beyond the leading examples.
Conceptual. This paper appears to be the first to provide machine learning inference for longitudinal
causal parameters in a general class with a common structure, so a conceptual contribution is to
define that class. The main result unifies, refines, and extends existing machine learning inference
theory that combines sample splitting with moment functions possessing the multiple robustness
property, hereafter called multiply robust moments functions. I unify existing asymptotic results that
are specific to particular global longitudinal parameters. General asymptotic theory with abstract
conditions exists for generic global parameters (longitudinal or otherwise), which I refine to finite
sample theory with simple conditions for a class of longitudinal causal parameters. The finite sample
main result handles longitudinal causal parameters that may be local or proximal. It also reveals a
new notion of multiple robustness to ill posedness for proximal causal inference in longitudinal
settings. This insight is important because every confounding bridge is a solution to a nested ill
posed inverse problem. The main result provides a single solution for longitudinal parameters that
arise in statistics, epidemiology, and economics, forging connections among disparate literatures.
Algorithmic. To showcase how the rate conditions are practical, I propose sequential adversarial es-
timators and verify that the estimators satisfy the proposed rate conditions. In particular, I prove fast
rates over generic function spaces that are popular in machine learning: sparse linear functions, re-
producing kernel Hilbert spaces, and neural networks. In order to verify the proximal rate conditions,
which involve nested confounding bridge functions, I prove a general mean square result for nested
nonparametric instrumental variable (NPIV) regression. The nested NPIV result is of independent
interest; this paper appears to be the first to propose an estimator for nested NPIV and the first to
prove a nested NPIV rate. The multiple robustness to ill posedness in the proposed rate conditions
partially ameliorates the compounded ill posedness of the nested NPIV estimation problem. These
algorithmic techniques may be more generally useful for nonparametric models in econometrics,
where NPIV frequently appears.
The structure of the paper is as follows. Section 2 describes related work. Section 3 articulates the
general inference problem and three leading examples: long term effect, heterogeneous dynamic
treatment effect, and proximal mediated effect. Section 4 introduces a general strategy to construct
Neyman orthogonal moment functions. Section 5 furnishes confidence intervals. Section 6 presents
the finite sample theorem as well as corollaries for each of the leading examples. Section 7 verifies
the rate conditions of the finite sample theorem using adversarial estimators over generic function
spaces. Section 8 concludes.

2 Related work
2.1 Semiparametric statistics

Classic semiparametric statistics studies functionals, i.e. scalar summaries, of nonparametric objects
such as densities or regressions [42, 73, 15, 60, 4, 71, 3, 61]. Early work focuses on settings where
the density or regression is defined over a low dimensional domain. In this work, I study a class of
functionals arising in longitudinal causal inference that depend on both a density and a regression (or
generalizations theoreof in the proximal setting). I study the setting where the density and regression
may be defined over a low, high, or infinite dimensional domain. In such case, an analyst may wish
to use machine learning to estimate the density and regression, which demands a more flexible
statistical theory.
In longitudinal causal inference, two balancing weights appear in the efficient influence functions
and therefore the asymptotic variances of semiparametric estimators. Multiply robust estimating
equations directly incorporate the density, regression, and balancing weights into estimation. The
multiply robust estimating equations confer many beneficial properties. As the name suggests, they
confer multiple robustness to mis-specification [72, 71]. They also confer Neyman orthogonality:
the learning problem for the functional becomes orthogonal to the learning problems for the density,
regression, and balancing weights [24, 23, 37]. Finally, they confer a mixed bias property, which
implies multiple rate robustness: the functional has bias equal to the product of certain learning
rates, so some learning rates may be slower than n−1/2 as long as others are faster than n−1/2 [76].
In this work, I prove that they confer yet another property: multiple robustness to ill posedness,
generalizing the double robustness to ill posedness known in static settings [29].
Multiply robust estimating equations are, by themselves, not enough to deliver confidence intervals
for functionals of machine learning estimators. In particular, if an analyst uses machine learning
to estimate the density and regression, then the nonparametric function spaces may not be Donsker.
Both the targeted maximum likelihood [95, 101, 54, 94, 68] and debiased machine learning [24, 23]
literatures provide a solution: combine multiply robust estimating equations with sample splitting
[14, 79, 52]. I prove new inferential guarantees for this meta algorithm when it is used in longitudinal
causal inference. In particular, I articulate sufficient conditions for valid confidence intervals in
terms of learning rates on machine learning estimators used to estimate the density, regression, and
balancing weights. I provide a simple and general nonasymptotic theorem that applies to many
longitudinal settings, with and without localization, with and without proxies.

2.2 Longitudinal causal inference and machine learning
A longitudinal causal inference problem is one in which a key variable takes place after the hypo-
thetical intervention but before the outcome. In such case, an analyst must account for not only
the hypothetical intervention but also its downstream effects; identification involves integrating out
the key variable according to its hypothetical distribution conditional on the intervention. One
example is long term effect: an analyst may wish to combine a short-term experimental data set
with a long-term observational data set in order to evaluate the long term effect of an intervention
[67, 10, 38, 21, 75, 6, 5, 74, 48]. The key variable is the surrogate short term outcome available in
both data sets. Another example is dynamic treatment effect: an analyst may wish to estimate the ef-
fect of a sequence of treatments [69, 70, 41, 43, 97, 92, 7, 100, 63]. The key variable is the covariate
observed between treatments, which may reflect prior treatment. Yet another example is mediation
analysis: an analyst may with to understand the mechanism through which some treatment affects
some outcome [47, 8, 64, 46, 65, 89, 96, 102]. The key variable is the mediator between treatment
and outcome.
In this work, I provide a general theorem for a broad class of longitudinal causal parameters, in-
cluding long term, dynamic, and mediated effects, with and without localization, with and without
proxies. Existing work for long term effect in the sense of [6] imposes restrictive separability and
linearity conditions that are not required for identification [9]. At the time this paper was initially
circulated in 2021 [84], it appears to have been the first to provide machine learning inference re-
sults for the unrestricted long term effect in the sense of [6], where treatment is only observed in the
experimental sample and outcome is only observed in the observational sample. For dynamic and
mediated effects, the theorem subsumes existing work on certain special cases while also providing
new results for additional cases. In particular, asymptotic results for unconfounded dynamic [16, 17]

                                                   3
and mediated [36] effects for the full population exist (albeit without variance estimation guarantees
for the latter). I provide a finite sample guarantee that encompasses semiparametric effects for the
full population as well as nonparametric, heterogeneous effects for subpopulations. In addition, I
study the additional complexity of proximal causal inference [57, 58, 32, 90, 99, 34], where unob-
served confounding contaminates causal inference but the analyst has access to negative controls
with special properties. At the time this paper was initially circulated in 2021 [84], it appears to
have been the first to provide machine learning inference results for longitudinal proximal causal
inference of any kind.

2.3 Localization and proxies

In summary, the innovations of the general result are machine learning inference for (i) long term
effects when treatment is only observed in the experimental sample and outcome is only observed
in the observational sample; (ii) heterogeneous dynamic and mediated effects; and (iii) proximal
longitudinal parameters of any kind. Previous work on localized and proximal effects focus on
the static setting. Despite the additional complexity of the longitudinal setting, I recover equally
strong results. In particular, [54, 51, 13, 28, 103, 35, 31, 50, 29, 2] study static local parameters
and [83, 49, 40, 29] study static proximal parameters. Like the latter, I arrive at mean square rates
and projected mean square rates of confounding bridges (also called nonparametric instrumental
variable regressions). Unlike previous work, I also arrive at projected mean square rates for nested
confounding bridges, reflecting the longitudinal structure.

2.4 Adversarial estimation in causal inference

As one way to verify the proposed rate conditions for inference, I prove that they are satisfied by
sequential adversarial estimators over generic function spaces. The analysis builds on foundational
technical lemmas for constrained M -estimators from [37], which in turn synthesize [55, 98] for
vector-valued contraction. I draw inspiration from [53, 11, 33, 56], who propose and analyze an
adversarial estimator for the static nonparametric instrumental variable regression problem. By con-
trast, I study a new estimator for the more challenging nested nonparametric instrumental variable
regression problem, which appears not to have been studied before. The results of [33] have been
previously adapted for static proximal causal inference by [49, 40]; by contrast, I study longitudinal
proximal causal inference. I contribute to the literature on adversarial estimation in both static [25]
and dynamic [26] causal inference.

3 Framework
3.1 Longitudinal causal parameters

The general inference problem is to find a confidence interval for some longitudinal causal parameter.
The causal parameter is a scalar θ0 ∈ R of the form
                              Z                                 
                      θ0 = E       m(W1 , w2 , γ0 )dQ(w2 |W1 ) , γ0 ∈ L2 ,

where m : W × L2 → R is an abstract formula that depends on the causal parameter of interest.
W ∈ W is a concatenation of random variables in the model excluding the outcome Y ∈ Y ⊂ R.
(W1 , W2 ) ⊂ W are subsets of random variables, which roughly correspond to some variables W1
observed before intervention and other variables W2 observed after intervention. L2 is the space of
functions of the form γ : W → R that are square integrable with respect to measure P. Below, I
instantiate this abstract formulation for the leading examples.
Note that γ0 may be the conditional expectation function γ0 (w) = E(Y | W = w) or some
other nonparametric quantity. For example, in proximal causal inference, γ0 is a function called
the confounding bridge defined as the solution to a nested ill posed inverse problem [57, 58, 32].
In econometrics, such a function is called a nested nonparametric instrumental variable regression
[62, 19]. I study the exactly identified case, which amounts to assuming completeness [22].
Functionals in this class have a two-stage structure: the formula m transforms the function γ0 , then
the conditional distribution Q reweights it. In particular, the reweighting is with respect to W2

conditional on W1 . The transformation m is interpretable as a counterfactual query based on some
intervention, and the distribution Q is interpretable as the downstream counterfactual distribution of
observables conditional on this intervention.

3.2 Example: Long term effect

The first example is long term effect. The goal is to combine a short-term experimental data set with
a long-term observational data set in order to evaluate the long term effect of an intervention.
For illustration, consider program evaluation of Project STAR, an experiment in which kindergarten-
ers were randomly assigned to small or large class sizes [30]. Let X ∈ Rp be baseline covariates
such as age, gender, ethnicity, and free lunch status. Let D ∈ {0, 1} indicate assignment to a small
class. Let M ∈ R be elementary school test scores and Y ∈ R be earnings in adulthood. An an-
alyst may wish to measure the effect of class size D on earnings Y (a long term outcome), yet the
experimental sample only includes elementary school test scores M (a short term outcome).
If the analyst has access to an additional observational sample that includes the long term outcome,
then long term causal inference is still possible [6]. Specifically, assume the analyst has access
to (i) an experimental sample, indicated by G = 0, where (D, M, X) are observed; and (ii) an
observational sample, indicated by G = 1, were (M, X, Y ) are observed. The observational sample
may also be interpreted as the selected sample for which the outcome Y is revealed. The key
identifying assumption is that the short term outcome is a statistical surrogate for the long term
outcome.

Previous machine learning inference guarantees for long term effects in the sense of [6], where treat-
ment is only observed in the experimental sample and outcome is only observed in the observational
sample, rely on strong linearity and separability assumptions that are not necessary for identification
[9]. Previous machine learning analysis is also asymptotic and excludes consistency of asymptotic
variance estimation (which is critical for justification of confidence intervals). By contrast, I impose
only causal assumptions rather than functional form assumptions; provide finite sample analysis
that allows for nonparametric localization; and elucidate which conditions are required for consis-
tent variance estimation (and hence valid confidence intervals).

3.3 Example: Heterogeneous dynamic treatment effect

The second example is dynamic treatment effect. The goal is to estimate the effect of a sequence
of treatments rather than the effect of a one-off treatment. I consider the additional complexity of
measuring heterogeneous effects with respect to an interpretable baseline characteristic.
For illustration, consider clinical evaluation of new drug administered in two injections. Let X1 ∈
Rp be baseline covariates such as demographics, health, and health-related behaviors. Let D1 ∈
{0, 1} indicate whether the first dose was administered. Let X2 ∈ Rp be covariates measured
between possible doses. Importantly, the health and health-related behaviors may change due to
D1 . For example, an individual who received D1 = 1 may partake in riskier behaviors than an
individual who received D1 = 0. Subsequently, let D2 ∈ {0, 1} indicate whether the second dose
was administered. Finally, let Y ∈ R be a downstream health outcome such as mortality.
An analyst may wish to measure the effect of the treatment sequence (d1 , d2 ) ∈ {0, 1}2 on the
health outcome Y . Moreover, the analyst may wish to measure how this effect varies with respect to
age V ⊂ X1 , which is a continuous baseline covariate. Identification of the heterogeneous dynamic
treatment effect is an extension of the classic g formula [69]. The key identifying assumption is a
dynamic generalization of selection on observables: conditional on baseline covariates X1 , assign-
ment of the first dose D1 is as good as random; conditional on baseline covariates X1 , initial dose
D1 , and subsequent covariates X2 that may reflect the initial dose, assignment of the second dose
D2 is as good as random.

3.4 Example: Proximal mediation analysis

The third example is mediation analysis. The goal of mediation analysis is to understand the mech-
anism through which some treatment affects some outcome. I consider the additional complexity of
unobserved confounding.
For illustration, consider program evaluation of the US Job Corps, a federal job training program
for disadvantaged youths [80]. Let X ∈ Rp be baseline covariates such as demographics, education,
and health. Let D ∈ {0, 1} indicate participation in job training. Let M ∈ R be employment in the
year after job training. Let Y ∈ R be arrests by the police a few years after job training. An analyst
may wish to measure the extent to which the effect of job training D on arrests Y is mediated by
the mechanism of employment M . However, the analyst may worry about unobserved confounding
that drives participation in job training D as well as subsequent employment M and arrests Y .
If an analyst has access to (i) negative control treatment Z ∈ R that does not cause employment
M nor arrests Y ; and (ii) negative control outcome V ∈ R that is not caused by job training D,
employment M , nor negative control treatment Z; then mediation analysis is still possible. If the
negative controls (Z, V ) can detect unobserved confounding, then they can also be used to adjust
for it [34].

4 Multiply robust moments
4.1 Moment function and orthogonality
In Section 3, I argue that long term, dynamic, and mediated effects—with and without localization,
with and without proxies—are causal parameters of the form
                               Z                              
                       θ0 = E       m(W1 , w2 , γ0 )dQ(w2 |W1 ) , γ0 ∈ L2 .

It turns out that all of these causal parameters have multiply robust moment functions with a common
structure, which I explore in this section. Indeed, one interpretation of this section is a simple set
of steps for constructing Neyman orthogonal moment functions of longitudinal causal parameters
beyond the leading examples. An analyst can use these steps systematically, rather than resorting to
guess-and-check.

6.1 Learning rates

I write this section at a high level of generality so it can be used by analysts working on a variety of
problems in longitudinal causal inference. I consider black box estimators (ν̂, δ̂, α̂, η̂). Under a few
simple conditions, I prove by finite sample arguments that θ̂ defined by Algorithm 5.1 is consistent,
and that its confidence interval is valid and semiparametrically efficient.
The result will be in terms of abstract mean square rates on the nuisances (ν̂, δ̂, α̂, η̂). I introduce
the following additional notation for the proximal setting. Let (A, B) partition W such that the

                                   ν0 (A1 ),    δ0 (A),        α0 (B),   η0 (B1 )

encoded in R(δ̂ℓ ). Multiple robustness to ill posedness is crucial for proximal causal inference in
longitudinal settings, where every single one of the nonparametric quantities (ν̂ℓ , δ̂ℓ , α̂ℓ , η̂ℓ ) is ill

7 Verifying rate conditions

7.1 Nested nonparametric instrumental variable regression

So far, I have refrained from instantiating specific estimators; the results hold for generic machine
learning estimators. In the unconfounded case, the rate condition for the partial mean estimator ν̂ is
non-standard in the statistical learning learning literature. In the proximal case, the rate conditions
for the nested confounding bride estimators (ν̂, α̂) appear to be open questions.
In this section, I argue that in both the unconfounded and proximal cases, all of the quantities
(ν0 , δ0 , α0 , η0 ) may be viewed as special cases of the same object: a nested nonparametric instru-
mental variable regression. As such, it suffices to propose and analyze a general estimator for nested
nonparametric instrumental variable regression.
The nested nonparametric instrumental variable regression problem can be stated as follows. The
goal is to estimate the function h0 that solves

                                      E[g0 (M̃ )|Z̃] = E[h0 (X̃)|Z̃].
where g0 is some preliminary function that must be estimated. The function g0 may or may not be a
nonparametric instrumental variable regression in its own right; in this sense the abstract formulation
is quite general. The classic nonparametric instrumental variable regression problem is recovered
by taking g0 (M̃ ) = Ỹ which is directly observed. Using operator notation, T g0 = T h0 where T is
a conditional expectation operator.

8 Conclusion
I propose a simple, general, and finite sample theorem to justify confidence intervals for longitudinal
causal parameters estimated with machine learning. The longitudinal causal parameters may be
local or proximal. As a contribution to the long term effect literature, I provide machine learning
inference for the setting where the treatment is only observed in an experimental sample and the
outcome is only observed in an observational sample. As a contribution to the dynamic treatment
effect and mediation analysis literatures, I provide machine learning inference with heterogeneity.
As a contribution to the proximal causal inference literature, I uncover a new multiple robustness to
ill posedness for longitudinal settings, which is crucial since every confounding bridge is a solution
to an ill posed inverse problem, and some confounding bridges are solutions to nested ill posed
inverse problems. I verify the rate conditions using adversarial estimators of nested nonparametric
instrumental variable regression, which may be of independent interest.
