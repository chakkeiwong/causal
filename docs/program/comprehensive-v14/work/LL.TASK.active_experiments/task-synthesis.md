# Active experiment selection: reviewed proposal synthesis

The banking question is whether a fee-waiver policy improves 90-day stable-balance value, net of deployment costs, relative to the existing policy. Specify the eligible population before contact; distinguish the offer from acceptance; and obtain an experiment's result before the deployment decision it is intended to inform. Transport to a later cohort is a separate assumption. A language-model answer, simulator observation and actual intervention require different observation laws.

The developed argument is integrated in [the active-experiment chapter](../../../execution/2026-10-13/active-experiments/chapter.tex) of `docs/causal_proposal_active_experiments_2026-10-13.pdf`. The full chapter, source audit, omissions and author review are preserved in `docs/program/execution/2026-10-13/active-experiments/`.

Five primary works are compared. Lampinen's passive demonstrations teach strategies that still use evaluation-time interventions. Verma's noisy-prior method allocates model questions under a fixed budget, with graph metrics and unresolved calibration/intervention questions. Murphy's model-discovery method combines proposed mechanisms with numerical design; its favorable findings retain their evaluable-case denominator and sample-versus-compute limitation, and its source-location appendix includes adverse/null design findings. DISCERN tests separately instantiated scientific-judgment levels; its rubric percentages are not experimental success rates. Discovery Foundation Models supplies a revisable-state architecture, while its structured therapeutic case does not establish general-purpose discovery. No uninspected biomedical original is treated as independently verified.

The exact four-world planning example separates learning about the whole world from learning what changes a decision. Deployment pays a stipulated USD 100 in the good state and USD -120 in the bad state; abstention pays zero. Both states have prior probability one-half. An independent nuisance variable creates two additional equally likely worlds. One acquisition costs a hypothetical USD 5 per normalized deployment decision.

| Policy or condition | Exact net planning value |
|---|---:|
| Learn the irrelevant variable perfectly, one bit | -5 |
| Acquire a decision-relevant signal with assumed accuracy 4/5 | 23 |
| Uniformly choose between those two acquisitions | 9 |
| Abstain without acquisition | 0 |
| Useful signal, one-quarter unavailable attempts, every attempt charged | 16 |
| Always purchase two conditionally independent useful signals | 98/5 |

An independent posterior calculation checks the second-query stopping decision: its maximum conditional gross increment is 16/5, below cost 5. For the declared menu and horizon at most two, one useful query is optimal. This is not a general myopic optimality theorem. Five perfectly correlated positive answers retain posterior 4/5; false independence produces 1024/1025. A pool that omits the bad world can predict +100 and realize -120. Every value is an exact stipulated construction, with byte-identical replay, not an LLM accuracy measurement or measured bank ROI.

The concrete software comparison inspects pinned README, license, API and source text. GlucoseBench supplies a useful acquisition/freeze/evaluation pattern and explicit failure denominators, while its physiological law is not a bank model. NeuronBench supplies an injected-client baseline whose parse failures substitute the first available experiment or a mean/zero forecast; any reuse must report those substitutions and compare the fallback itself. DFM-Plans is an overview repository, not a complete executable Zetema implementation. Root licenses do not establish all dependency/data rights or rights in linked projects. No downloaded package was installed or executed, and no integration capability was granted.

The next empirical step is a separately frozen generated/public study comparing fixed, random, numerical information, numerical decision-value and optional agent-assisted policies under matched observations and acquisition budgets. Include irrelevant information, timing, correlated answers, acquisition failures, omitted mechanisms, equivalence and malformed responses; retain clean controls and count every attempt. Measure decision loss and whether limitations change actions. A live-model performance claim requires actual model execution and accounting; an architecture/literature proposal does not.

The review passes the three scoped task criteria: primary comparisons with remaining research, a worked banking target/clock with formal and numerical baselines, and clear evidence boundaries. It does not close MR02, the frontier census, Q1–Q5, independent review or visual acceptance. Five mapped originals remain uninspected/unavailable, along with full agent/harness implementation identities and linked projects. The omissions register gives specific revisit actions. None makes an expensive bank study a prerequisite for this proposal.
