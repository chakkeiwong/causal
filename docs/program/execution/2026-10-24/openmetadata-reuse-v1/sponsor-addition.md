The OpenMetadata decision is reference use with native integration disabled.
Pinned source separates catalog entities, lineage, data contracts, permissions
and transport from scientific acceptance. Authored local fixtures show that
minimal lineage requests and unregistered causal fields can pass selected
declarative schemas; that does not establish server retention, acyclicity or
causal truth. Source-level filtering of column mappings makes explicit read-back
reconciliation a proposed requirement. A Java-regex incompatibility in an unused
basic-schema definition remains recorded rather than silently rewritten.
\citep{exec24_openmetadata_source,exec24_openmetadata_reference}

The proposed path connects to a bank's chosen catalog through original APIs or
a qualified OpenLineage mapping and preserves immutable snapshots, clocks,
estimands, uncertainty and refusal evidence separately. Whole-catalog ports and
a mandatory duplicate catalog lack a demonstrated justification. In an authored
USD 60 example, costs are USD 15 per submission, USD 20 per assumed persisted
edge and USD 60 per assumed accepted artifact. Actual server environments,
rights, complete delivery semantics, consumer adoption and prices remain open.
