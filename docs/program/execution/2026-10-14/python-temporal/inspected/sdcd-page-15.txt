A.4. Proof of Theorem 4
We recall Theorem 3.7.
Theorem 3.7. hρ is stable.

Proof. We prove each stability criterion.

   • E-stable: For any s > 0 and matrix A, hρ (sA) = |s|hρ (A) = Os→+∞ (s).

   • V-stable:For any ε > 0 and matrix A such that hρ (A) > 0, hρ (εA) = |ε|hρ (A) = Ωε→0+ (ε).

   • D-stable: Every matrix has eigenvalues (C is algebraically closed), so hρ is well defined everywhere. In addition,
     Theorem 3.6 proved that hρ was differentiable almost everywhere.

Hence, hρ is a stable constraint.
