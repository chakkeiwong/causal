Algorithm 1 Conditional association relationship extraction
Require: Causal graph G = ⟨V, E⟩, and target variable pair X, Y ∈ V
 1: if X and Y are adjacent in G then
 2:    Return: X and Y are always correlated.
 3: else
 4:    P ← all collider-free paths between X and Y .
 5:    if P = ∅ then
 6:       Return: X and Y are mutually independent.
 7:    else
 8:       SepSet ← ∅.
 9:       D ← {V′ ⊆ V \ {X, Y } | ∀P ∈ P, P contains at least one variable in V′ }.
10:       for Z ∈ D do
11:         if ∄Z′ ⊂ Z such that Z′ ∈ D then
12:            SepSet.append(Z)
13:         end if
14:       end for
15:       Return: [X and Y are mutually independent conditioned on Z for Z in SepSet]
16:    end if
17: end if
