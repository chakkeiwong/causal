# Temporal class retention with stationary innovations

Define X_t=(Z_t,A_t,Y_t)' by X_t=r X_(t-1)+epsilon_t, where r belongs to the finite supplied set {0,.4,.8}. The independent Gaussian innovation epsilon has the ordered structural equations z=e_z, a=k z+l_a u+e_a, y=tau a+c z+l_y u+e_y, with independent Gaussian root u and errors. The invariant initialization has covariance Sigma/(1-r^2); the simulator draws exactly from it. The contemporaneous intervention is do(A_t=a) holding past variables fixed, so its response coefficient is tau. In structural form the lag matrix is r(I-B); this restriction is substantive, not a generic VAR assumption. Long-run intervention queries and unknown continuous lag coefficients are excluded.

For each candidate r, form E_t(r)=X_t-r X_(t-1). At the true candidate only, these are iid Gaussian. Do not select a lag and then assert an iid theorem at the selected lag. For each candidate build the inherited simultaneous covariance box from the three coordinate variances and six signed-pair variances. Each (n-1) sample variance divided by its population variance is chi-square; Bonferroni across nine gives joint covariance inclusion at least 1-alpha. This calculation is required only at the true candidate. Take the union of all candidate lag/graph effect sets; no multiplicity penalty across lag candidates is needed for this superset event. We retain all lag candidates and discard a graph only when a necessary restriction cannot intersect its covariance region. On covariance inclusion the true graph and effect remain. Wrong-candidate observations need not be iid for this union argument.

The finite structural graph family is exactly the inherited 40 broad latent members, 8 encouragement members or 8 observed-sufficiency members at each lag. Encouragement permits latent A/Y confounding while excluding Z/Y direct and latent Z links. Relevance k can be arbitrarily small; interval ratio inversion retains disconnected or whole-line sets when its denominator contains zero. Broad latent models contain equal-observed-covariance arbitrary-tau witnesses. Thus observational data need not contract the set at all. The graph effect maps use interval outer relaxations, not a point fit. On the exact covariance oracle, symbolic covariance expansion recovers Cov(Z,Y)/Cov(Z,A)=tau under exclusion. Whole-line and disconnected endpoints have explicit JSON null semantics; serialization does not change the scientific set. Floating-point interval endpoints are diagnostic approximations to analytical outer bounds, not a general machine-verifiable real-arithmetic certificate.
