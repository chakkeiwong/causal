Data Availability The text-as-outcome application uses data from wave 76 of the German Internet Panel
(GIP). The text data used are only available through the on-site data access at the University of Mannheim.
Labelled data can be made available upon request to researchers which have access to the GIP data.
The data pertaining to the text-as-treatment application can befound here: https://doi.org/10.7910/DVN/
SEV0SZ. All code is available on Github: https://github.com/rubac/text_treat.
