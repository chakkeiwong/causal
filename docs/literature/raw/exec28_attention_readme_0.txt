# Replication Package: Causal Transformer (CT)

**Paper**: Causal Transformer: Scaling Gradient-Based Causal Discovery with Self-Attention
**Journal target**: Current Science
**Author**: Shuaidong Gao (ORCID 0009-0004-5641-3581)

---

## What this package reproduces

The **figures** of the manuscript and the Electronic Supplementary Material
(ESM), generated from the recorded benchmark results. It is self-contained:
no absolute / machine-specific paths, and no network access. This package
ships **code and data only** (no LaTeX sources).

| Artifact | File | Regenerated by |
|:--|:--|:--|
| Fig 2 (2x2 results) | `figures/fig2_results.pdf` | `scripts/gen_fig2.py` |
| Fig 3 (1x3 ablation) | `figures/fig3_ablation.pdf` | `scripts/gen_fig3.py` |
| ESM Fig 1 (scaling law) | `figures/esm_fig1_scaling_law.pdf` | `scripts/gen_esm_fig2.py` |
| ESM Fig 2 (TCGA validation) | `figures/esm_fig2_tcga_validation.pdf` | `scripts/gen_esm_fig3.py` |
| Benchmark results | 35 `results/*.json`, 300 `results_synth/*.json` | recorded experiments |

## One command to reproduce everything

```bash
# 1) (recommended) create an isolated environment
python -m venv .venv
# Windows: .venv\Scripts\activate     Linux/macOS: source .venv/bin/activate

# 2) install dependencies
pip install -r requirements.txt

# 3) regenerate all figures
python run_all.py
```

`run_all.py`:
1. regenerates all 4 figures (PDF + PNG) into `figures/`;
2. verifies every expected figure and data file is present.

Requirements:
- **Python 3.12+** with `numpy`, `matplotlib`, `scipy`, `pandas` (`requirements.txt`).
- **No GPU required**: every figure is generated from pre-recorded benchmark
  results (`data/ct_results.json`). The original model-training benchmarks used
  an RTX 5060 (8 GB) but are **not rerun** by this package — the recorded
  results are included, which is what makes the package lightweight and
  CPU-reproducible.

## Manual reproduction (equivalent to `run_all.py`)

```bash
# regenerate figures
cd scripts
python gen_fig2.py        # Fig 2  -> ../figures/fig2_results.pdf
python gen_fig3.py        # Fig 3  -> ../figures/fig3_ablation.pdf
python gen_esm_fig2.py    # ESM 1  -> ../figures/esm_fig1_scaling_law.pdf
python gen_esm_fig3.py    # ESM 2  -> ../figures/esm_fig2_tcga_validation.pdf
cd ..
```

All figure scripts read their input from `../data/ct_results.json` and write to
`../figures/`, resolved **relative to the script location** — so the package
works from any directory on any machine after unzip.

## Data provenance

- **Synthetic DAGs** (`make_dag(seed=42)`) and the 80-configuration sweep:
  `data/ct_results.json`. Each configuration was run over **10 seeds**
  (seed 42--51, data/oracle fixed, model initialization varied); the
  `ct_edges_mean`/`ct_edges_std` fields report the 10-seed aggregate used by the
  manuscript's synthetic tables and by `fig2_results`/`fig3_ablation`. The legacy
  single-run `ct_edges` field is retained for the low-dimensional rows
  (`d=30,50,100`).
- **TCGA** (UCSC Xena HiSeqV2, 20,531 genes): per-cancer benchmark results under
  `results/` (`tcga_d250/d300/d350_*`); the `d=200` 10-cancer summary used by
  `esm_fig2` is recorded in the ESM Table S3.
- **Multi-omics / MLP baseline** (TCGA-BRCA expression, CNV, methylation):
  `results/omics_expression_*`, `omics_cnv_*`, `omics_methylation_*`,
  `results/mlp_baseline_*`.
- All experiments are deterministic (`seed=42` defaults); per-seed reproducibility
  is preserved by the fixed seeds recorded in each result file.

---

## Hardware notes (for the *original* benchmarks, not this package)

- GPU with >= 8 GB VRAM (tested: NVIDIA RTX 5060 8 GB).
- Largest original run: `d=350`, ~8.8 h/seed; `d=300` ~6.2 h/seed.
- **This package does not rerun training**; it reproduces figures and documents
  from the recorded results, so it is fast and CPU-only.
