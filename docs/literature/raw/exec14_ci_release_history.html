Release history | Bayes Server

Please note that the release history presented here only goes back as far as version 5.

Version 11.4.0.0 - Friday, April 17, 2026

  • Desktop installer version available for macOS. Signed and notarized for easy install
  • Improved robustness of distribution editors.
  • Fix 'No Records to display' error when switching Gaussians in the distribution editor.
  • User Interface updated to .NET 10

Version 11.3.0.0 - Wednesday, March 25, 2026

  • Fixed bug in Dbn parameter learning with missing data, that was raising an InvalidOperationException incorrectly.
  • Fixed dbn visualization bug (User Interface only), caused when mixed temporal and non temporal nodes are present.
  • Error now clearer in User Interface when sampling from a network with terminal nodes but no temporal nodes and the min and max sequence lengths are not specified.
  • Fix for exception raised when user cancels Save or SaveAs
  • Improved hover over help for Rolling and Pinned modes used by Dbn parameter learning

Version 11.2.0.0 - Friday, November 7, 2025

  • Improved error handling in the distribution editor when an invalid number is entered.
  • Improved switching between distributions (by key or kind) in the distribution editor.

Version 11.1.0.0 - Friday, July 4, 2025

  • Fixed obscured text displayed in network viewer and query viewer. Only applied to the Safari browser, which is not recommended for performance reasons.

Version 11.0.0.0 - Tuesday, January 7, 2025

  • Scenario support added to User Interface.
  • Junction Tree viewer and API.
  • Elimination Order viewer and API.
  • Log-Likelihood empirical density User Interface support.
  • Jensen Shannon calculator added to the User Interface.
  • Mutual Information calculator added to the User Interface.
  • KL Diveregence calculator added to the User Interface.
  • Entropy calculator added to the User Interface.
  • New tutorials.
  • Bug fix. Auto insight when approximate reported JSD in NATS not BITS. Now reports in BITS so consistent with non-approximate version.

Version 10.10.0.0 - Thursday, May 9, 2024

  • Fix for discretization editor in 'Add Nodes From Data' in User Interface.
  • Fix AllEvidence log-likelihood test in RelevanceTree inference engine.
  • New tutorials.

Version 10.9.0.0 - Tuesday, February 21, 2023

  • Fixed certificate issue with Windows Desktop App Installer.
  • Fixed 'Attempting to JIT compile methods... in aot-only mode' on macOS M1 chips.
  • Expressions now support accessing Links, LinksIn and LinksOut from nodes.

Version 10.8.0.0 - Thursday, December 8, 2022

  • Fixed corrupt file on save in native desktop versions.

  • Fixed optimization error message when no design variables available, when function nodes are present.

  • Fixed blank query explorer on startup and theme change
  • Fixed 'Overflowing multi select controls' in User Interface
