## Agent frameworks must preserve scientific and operational outcomes

The broader comparison covers modern LangChain with its LangGraph dependency,
AutoGen, Semantic Kernel, DSPy, LlamaIndex with its delegated workflows runtime,
and Haystack. Exact source profiles and component boundaries govern each
conditional integration choice. Framework orchestration does not establish
causal identification, qualified uncertainty or current commercial entitlement.
\citep{exec24_framework_contracts}

The practical differentiators include graph replay, state concurrency,
failure messages, retry identities, extraction after partial work, evaluation
denominators, active-time versus wall-time clocks, and hooks that can alter
scientific output. Authored witnesses show a 1,000 USD repeated-action
difference, a 40 USD overspend from non-atomic reservations, and 75 percent
qualification among returns versus 60 percent among all requests. These
are public test specifications, not measured framework performance.
\citep{exec24_framework_contracts}

The proposal calls for a shared public task and failure suite across the
candidate frameworks, followed by expensive bank work only when justified.
Hypothetical expenditure of 24,000 USD over 1,000 submitted, 800 returned
and 600 qualified requests gives 24, 30 and 40 USD respectively. Hosted/local
backend coverage, native tests and actual prices remain open.
\citep{exec24_framework_contracts}
