\chapter{Using assistance where its value can be tested}
\label{scisyn:assistance}

\section{From a business request to a study}
A request to improve retention is not yet an intervention. An economist needs
to distinguish an invitation, acceptance of an offer, a price change and a
repeated contact policy; specify who is eligible; and choose the outcome and
information date. The retained language-model literature motivates assistance
with such formulation and graph critique, while retaining the role of formal
analysis. Its demonstrations do not establish bank-specific assumptions.
\citep{v12_la_2305_00050,v12_la_2606_23608}

The first prototype should produce competing questions when the request is
ambiguous. For example, the effect of offering a fee waiver among all eligible
customers differs from the effect among customers who accept it. Acceptance
can depend on unobserved intentions. A structured questionnaire is a strong
baseline: if it obtains the same defensible question more cheaply, it should
be preferred. Assistance earns its cost when it discovers a material omission,
finds relevant evidence or reduces correction time.

\section{A diagram is an argument about mechanisms}
Require each proposed edge to state its economic interpretation, timing and
evidence. An assistant can suggest competing explanations and retrieve primary
sources. It should retain uncertainty when the sources disagree or do not
describe the bank's process. The LACR paper reports both improved and worsened
retrieval-assisted graph results across its examples. This supports a comparison
of retrieval choices, not a blanket claim that more retrieved text improves
discovery.
\citep{v12_la_2402_15301}

Evaluate diagram assistance against three alternatives: an unaided economist,
a questionnaire plus ordinary search, and numerical discovery under declared
assumptions. Match the permitted information. Count unsupported orientations,
missed common causes and changes in the resulting intervention conclusions.
Edge accuracy alone can obscure a serious error if one wrong edge changes
whether an action is beneficial. Conversely, an unresolved graph can be useful
when all credible members support the same decision.

\section{Formal reasoning, tools and honest refusal}
CLadder studies formal causal questions under constructed mechanisms. Its
reported historical benchmark results are evidence about that task, not a
measure of how well an assistant elicits a causal model from an unfamiliar
bank. The causal-learn+ discussion separately describes assistance around data
inspection, assumptions, algorithms and interpretation.
\citep{v12_la_2312_04350,v12_la_2606_23608}

For identification, the assistant should call a defined method and preserve
the method's conclusion and scope. For estimation, it should retain the target,
sample, observation dates and uncertainty. For reporting, it should explain
which conclusions depend on which assumptions. For a repeated policy, it must
preserve information available at each action rather than treat all later
measurements as adjustment variables. A failed or unsupported calculation
should prompt a revised question or an explanation of the missing information.

There is no live language-model evaluation in this new evidence. A defensible
next comparison needs a fixed model and version, permitted inputs, held-out
questions, human adjudication independent of the tested system and a budget.
The evaluation should include correction time and the financial importance of
errors as well as answer accuracy. Missing those inputs limits a claim of
measured benefit; it does not prevent developing the scientific comparison or
using a simple baseline now.
