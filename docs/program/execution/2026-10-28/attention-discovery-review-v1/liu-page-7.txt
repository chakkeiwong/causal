                                τ = sorted(Hij )[k]                             (9)
We select the threshold τ following the approach in [10]. If the causal strength

a causal relationship from i to j and includes it in the set of potential causes P:

                                 P = {(i → j) | Hij ≥ τ }                                                                               (10)




4.3            Causal Verification

Our methodology uses Permutation Importance (PI) [12] to validate causal re-
lationships. PI quantifies the effect of variable reordering on prediction error by
shuffling the values of a candidate cause variable, disrupting potential causal
pathways and assessing the significance of the temporal structure.
    Given a neural network Nj trained on the complete dataset to predict the
target time series Xj , we denote the baseline loss on the original data as LG . For
each potential causal factor Xi ∈ P, we create a permuted dataset by randomly
rearranging the values of Xi while keeping the rest of the data unchanged. This
permutation preserves the original data distribution, allowing us to re-evaluate
