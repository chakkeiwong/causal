Description for estat
    estat ptrends tests that all pretreatment periods are equal to zero.
    estat atetplot plots the coefficients of ATET for each cohort across different periods.
    estat aggregation aggregates the cohort-period ATETs to characterize the heterogeneity of treat-
 ment effects. Aggregation may be within cohorts, time periods, time exposed to treatment, or within
 cohort and time periods. You may display the output of estat aggregation simultaneously as a table
 and a graph. The default is the tabular output.
    estat moderation is part of StataNow. It reports moderating effects of covariates in two-way fixed-
 effects models. These effects can be interpreted as the marginal effects of each covariate on the ATETs
 reported by hdidregress and xthdidregress. Factor variables may be specified but interaction terms
 are not allowed.
     estat sci provides the simultaneous confidence intervals for ATETs using the multiplier bootstrap
 method proposed in Callaway and Sant’Anna (2021). It may not be used after estimation using the TWFE
 estimator.

Test for all pretreatment period ATETs being zero
    estat ptrends tests that all pretreatment period ATETs are zero. This should be satisfied if both
 parallel trends and no anticipation of treatment hold for the pretreatment period.
    For the RA, IPW, and AIPW estimators, estat ptrends is equivalent to a Wald test of all the pre-
 treatment ATET estimates equaling zero. For methods and formulas on the Wald test, see Methods and
 formulas in [R] test.
    Below, we will use the notation from Methods and formulas in [CAUSAL] xthdidregress. For the
 TWFE estimator, we fit the augmented model:

Aggregations for the RA, IPW, and AIPW estimators
    We denote ATET(𝑔, 𝑡) as 𝜃(𝑔, 𝑡). These are the parameters computed during estimation. Instead of
 looking at all of these parameters, we can aggregate them to explore heterogeneity in different dimen-
 sions. We denote aggregations of ATETs as 𝜃. Regardless of whether we use cohort, time, dynamic, or
 overall aggregation, we can always write 𝜃 as a weighted sum of 𝜃(𝑔, 𝑡) as follows,
                                                     T
                                          𝜃 = ∑ ∑ 𝑤(𝑔, 𝑡)𝜃(𝑔, 𝑡)
                                               𝑔∈G 𝑡=𝑡1

 where G denotes the set of cohort values except the never-treated group and T denotes the maximum
 number of the time periods. 𝑡1 is the first period when the treatment starts. 𝑤(𝑔, 𝑡) is the weight attached
 to each 𝜃(𝑔, 𝑡).
    𝑤(𝑔, 𝑡) depends on the aggregation type and the weight type used in computation. These are the types
 of aggregations:
    1. Overall aggregation: aggregate all the treatment effects across cohorts and posttreatment periods.
    2. Dynamic aggregation: aggregate the treatment effects given a fixed length of exposure to the
       treatment. Commonly referred to as event studies.
       hdidregress postestimation — Postestimation tools for hdidregress and xthdidregress+ 10


   3. Cohort aggregation: aggregate the treatment effects within a specific cohort across the posttreat-
      ment periods.
   4. Time aggregation: aggregate the treatment effects at a specific time across the cohorts.

   For each type of aggregation, there are two different weight types:

  (a) Weights 𝑤(𝑔, 𝑡) that differ by cohort and time. The weights are determined by the data used to
      compute each 𝜃(𝑔, 𝑡), which varies by cohort and time. Therefore, cohorts with more observations
      at a given point in time will receive more weight. This accommodates situations in which the
      relative size of cohorts or the number of observations for a given cohort changes over time. The
      weights(timecohort) option specifies this weighting type. For notational simplicity, we denote
      this framework as weighting type (a).
  (b) Weights 𝑤(𝑔, 𝑡) that differ only by cohort. Weights that vary by cohort but not over time are
      reasonable if the groups sampled at each point in time have similar sizes. These weights are also
      reasonable if the sizes of the groups sampled over time change but the relative proportions of the
      groups are roughly the same. The weights 𝑤(𝑔, 𝑡) in this case are computed using observations in
      a cohort over all time periods as a proportion of all other observations. Callaway and Sant’Anna
      (2021) propose this weighting type. The weights(cohort) option specifies this weighting type.
      For notational simplicity, we denote this framework as weighting type (b).

In the common case where the groups sampled over time are of similar sizes, both weighting types give
equivalent results.

to explain some notations for later use.

      𝑔 − 1), which equals 1 if the 𝑖th observation is observed in time 𝑡 or time 𝑔 − 1 and 0 otherwise.

Aggregations for the TWFE estimator
    Aggregation after TWFE uses margins after the Mundlak estimation of the model. Let treat de-
 note the observation-level treatment, cohort denote the variable that contains treat-time cohorts, and
 exposure denote a variable that indicates the time exposed to treatment.
    For estat aggregation, overall:
       . margins r.treat, subpop(if treat==1) vce(unconditional)

    For estat aggregation, cohort:
       . margins, subpop(if treat==1) dydx(treat) over(cohort) vce(unconditional)

    For estat aggregation, time:
       . margins, subpop(if treat==1) dydx(treat) over(time) vce(unconditional)

    For estat aggregation, dynamic:
       . margins, subpop(if treat==1) dydx(treat) over(exposure) vce(unconditional)



Moderating effects (StataNow)
    After using the TWFE estimator to model the outcome using a set of covariates, estat moderation
 reports estimates of moderating effects, which can be interpreted as the marginal changes in the ATET
 with respect to each covariate. For factor variables, the marginal effect is the difference between the
 margin for the specified level and the margin for the base level.
    Estimation of moderating effects uses margins after the Mundlak estimation of the model. Let treat
 denote the observation-level treatment, cohort denote the variable that contains treat-time cohorts, time
 denote the time variable, and x1 and x2 denote covariates that appear in the model.
    When hettype(timecohort) and over(cohort) are specified, the moderating effects are com-
 puted as follows:
       . margins r.treat, dydx(x1 x2) over(cohort) at(time=q ... time=T)
       vce(unconditional)

    When hettype(timecohort) and over(timecohort) are specified:
       . margins r.treat, dydx(x1 x2) over(cohort time) vce(unconditional)

    When hettype(cohort) is specified:
       . margins r.treat, dydx(x1 x2) over(cohort) vce(unconditional)

    When hettype(time) is specified:
       . margins r.treat, dydx(x1 x2) over(time) vce(unconditional)

    By default, estimates are returned for each covariate that appears in the model. If varlist is specified
 with estat moderation, effects are returned only for the specified covariates. Note that if a covariate
 x1 appears as both a factor variable and a continuous variable in the model, moderating effects for x1
 cannot be computed. estat moderation is not allowed after estimation with the noxinteract option.
