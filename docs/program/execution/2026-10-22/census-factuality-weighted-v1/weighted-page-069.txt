B     Optimal Quantile-Unbiased Estimation
If one restricts attention to the class of quantile-unbiased estimators that depend on θ̂ through
θ̂′ Qθ̂, then the optimality statement for η̂1−β in Proposition 3 can be strengthened. To see this,
first recall that since θ̂ ∼ N (θ,Σ),

                        θ̂′ Qθ̂ = (Σ−1/2 θ̂)′ A(Σ−1/2 θ̂) ∼ χ2K−1 (H(θ)), ∀θ.

The family {χ2K−1 (η) : η ≥ 0} of noncentral chi-squared distributions has monotone likelihood
ratios in θ̂′ Qθ̂. These distributions are continuous, so their CDFs satisfy (5.3.10) from Pfanzagl
(1994). Consequently, the estimator η̂1−β satisfies properties 5.4.1(i)-(ii) of Pfanzagl (1994) over
the parameter space η ∈ H = (0,∞). By Pfanzagl (1994, Theorem 5.4.3), η̂1−β is maximally con-
centrated around H(θ) when θ is heterogeneous. That is, for any other potentially randomized
estimator η̃1−β that satisfies (14) and depends on θ̂ through θ̂′ Qθ̂,
          n             o     n              o
        Pθ η ≤ η̂1−β ≤ η̄ ≥ Pθ η ≤ η̃1−β ≤ η̄ , ∀(η,η̄,θ) : 0 ≤ η ≤ H(θ) ≤ η̄ ≤ ∞,H(θ) > 0.

Considering η = 0 and η̄ = H(θ)+ε yields the statement that η̂1−β is uniformly most accurate
in the class of quantile-unbiased estimators that depend on θ̂ through θ̂′ Qθ̂.
    By Pfanzagl (1994, Proposition 2.5.3), the above maximal concentration is equivalent to
minimum-risk optimality for every loss function L(a,θ) that attains its minimum at a = H(θ)
and that is quasiconvex in a for all heterogeneous θ:

                         Eθ [L(η̂1−β ,θ)] ≤ Eθ [L(η̃1−β ,θ)], ∀θ : H(θ) > 0.

The above loss functions formalize the notion that losses get larger as a moves away from H(θ).
For example, taking L(a,θ) = (H(θ)−a)2 to be squared error loss, the above result shows that
when θ is heterogeneous, η̂1−β is optimal under mean squared error for estimating H(θ) in the
class of quantile-unbiased estimators that depend on θ̂ through θ̂′ Qθ̂.
