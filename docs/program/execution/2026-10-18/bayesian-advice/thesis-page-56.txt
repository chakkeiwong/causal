     4.5.3    Updating beliefs
        With the expert feedback in hands, the next step is to update our distribution 𝑝𝜃 (𝒢 ).
     The expert-induced posterior, 𝑝(𝑓𝑟 ∣ 𝜔𝑟 ) is used to characterize a distribution over the
     edges of an AG, which we define as:


                                         𝑞(𝑒|f𝐾 ) ≔ 𝑝(𝜔𝑟 |𝑓𝑟 ) ⋅ 𝑢(𝑟),                                (4.9)
     where 𝑢𝑟 is an uniform distribution over the AGs’ unlabeled edges.

           Likewise, an AGFN’s policy 𝑝(𝑒) ≔ 𝜋𝐹 (⋅|𝑠) is also a distribution over the edges of the
     AG 𝑠. Using a mixture-of-experts strategy (Hinton, 2002), we define the updated policy
            (𝐾 )
     as 𝜋𝐹 (𝑠 ′ |𝑠, f𝐾 ) ∝ 𝑝(𝑒) ⋅ 𝑞(𝑒|f𝐾 ), where 𝑒 is the specific edge added to move from 𝑠 to
     𝑠 ′ . This guides the AGFN to prefer graphs that satisfy both the score function and the
     expert’s feedback. Moreover, the structural ancestrality constraints are already encoded
     by design to 𝑝(𝑒) (refer to Figure 4.1).



     4.6     Experiments
     4.6.1    Distributional Assessment of AGFN Without Feedback
        For this experiment, we generate 20 5-node random graphs using a directed config-
     uration model (Newman, 2010). We sample uniformly from {0, … , 4} for the in- and out-
     degrees. We draw 500 samples from each graph, which is defined as an LG SCM with
     random parameters.

         Firstly, we train a separate AGFN for each random graph using its corresponding sam-
     ples. Then, we generate samples from the AGFN to estimate the empirical distributions
     of the following metrics:

        1. pairwise edge features (i.e., 𝑝𝜃 (𝑉𝑖 → 𝑉𝑗 ) and 𝑝𝜃 (𝑉𝑖 ↔ 𝑉𝑗 ) for each pair (𝑉𝑖 , 𝑉𝑗 )),

        2. path features (i.e., 𝑝𝜃 (𝑉𝑖 ⇝ 𝑉𝑗 )),

        3. the BIC, and

        4. the Structural Hamming Distance (SHD) relative to the true causal graph.

        Figure 4.2 shows that the AGFN approximates well the theoretical distribution from
     Equation (4.4). Additionally, the distributions it produces for BIC and SHD align closely
     with the expected values from 𝑝(𝒢 ) ∝ 𝑅(𝒢 ).
