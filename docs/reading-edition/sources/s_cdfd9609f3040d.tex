\section[Python dynamic panels and shocks]{Python dynamic panels, structural shocks and state-space forecasts}
\label{sec:exec25-python-dynamic}

A treasury team asking how a funding intervention changes future deposits needs more than a well-fitting forecast. A panel of branches raises a different sampling problem from one long aggregate time series, and a filtered latent state is not automatically an intervention variable. The existing pydynpd review already develops dynamic-panel moments, instrument proliferation, calendar alignment, selection and conditional uncertainty. Its genuine paper and retained source review remain the starting point here. The added comparison examines statsmodels VAR/SVAR paths, two further dynamic-panel candidates, a structural-shock package and a dynamic linear-model implementation. Each candidate is evaluated by its target, information clock, restrictions, numerical return and failure contract. A discovery result or an estimator name supplies none of these guarantees by itself.\citep{exec24_pydynpd_paper,exec24_pydynpd_source,exec25_pydyn_choice}

\subsection{The calendar is part of a dynamic-panel moment condition}

For a schematic panel relation $y_{it}=\alpha y_{i,t-1}+x_{it}'\beta+a_i+u_{it}$, the interpretation of a lag is part of the model. Conditions on a two-period-old value and a differenced disturbance refer to declared calendar periods, not automatically to the second most recent observed record. This is consequential for branches with missing reporting months. In an authored table with times $(2000,2002,2003)$ and values $(10,20,30)$, the previous-observation lag is $(\mathrm{NA},10,20)$, whereas a one-calendar-period lag is $(\mathrm{NA},\mathrm{NA},20)$. Treating the middle row as if its lag were observed changes the usable moment rows before any GMM solver runs. This arithmetic illustrates a contract difference; it is not a native benchmark.\citep{exec24_pydynpd_source,exec25_pydyn_choice}

At the inspected dynapanel revision, the data object documents and implements positional lags, and its instrument assembly independently indexes positions when constructing regressors and instrument columns. The assembly also stores calendar times, but calendar labels do not change the positional arithmetic. Its input validation checks duplicate identifiers before a noninteger time column may be cast to an integer type; the selected path has no second duplicate check after that cast. Exact installed-library conversion semantics require a native fixture. The proposal should demand a declared calendar grid or a restricted consecutive-period use, with refusals for unsupported gaps, rather than infer calendar-valid moments from a sorted table. The package's experimental status and version metadata are retained as provenance, not as an automatic rejection of every calculation.\citep{exec25_pydyn_dynapanel}

The inspected PyXtabond2 helper makes a materially different choice: it forms absolute time offsets and uses an exact offset match for gapped groups. A contiguous group has a positional fast path justified by the offset condition. Its instrument builder scatters values onto a dense calendar grid before selecting lagged columns. The selected constructor still requires separate input qualification: time offsets are converted to integers, while complete duplicate, fractional-time and caller validation remains open. A source helper supporting calendar lags is a useful comparison; it is not proof that every model option, covariance correction or exported result is equivalent to Stata. The README's parity claims remain unverified claims in this review.\citep{exec25_pydyn_xtabond}

Numerical diagnostics should remain separate from moment validity. Dynapanel warns when instrument counts are large relative to the number of units, and its inverse helper falls back to a pseudoinverse only after a numerical exception. Its square-root helper clips negative inputs to zero. PyXtabond2's inspected rank path operates on the instrument Gram matrix; when that check is disabled, it substitutes the instrument count. The selected estimation paths also use pseudoinverses. None of these source choices establishes that the instruments are excluded, strong or valid under shared calendar shocks. The adapter must retain the rank rule and scale, fallback route, requested instrument count, effective rows, covariance law and any clipped variance state. A finite standard error is not an exogeneity certificate.\citep{exec25_pydyn_dynapanel,exec25_pydyn_xtabond,exec25_pydyn_choice}

\subsection{A reduced-form covariance does not name a policy shock}

Write an aggregate reduced form as $y_t=\sum_{\ell=1}^p\Phi_\ell y_{t-\ell}+u_t$, with innovation covariance $\Sigma_u$. A structural impact matrix $P$ obeys $PP'=\Sigma_u$ under the chosen normalization. This equation alone does not select the intervention. For the authored case $\Sigma_u=I_2$, both $P=I_2$ and
\[
 Q=\begin{pmatrix}3/5&-4/5\\4/5&3/5\end{pmatrix}
\]
have the same reduced-form covariance, while the first shock moves different combinations of the two variables. The equality $QQ'=I_2$ is checked exactly. A bank must justify the contemporaneous, long-run, sign or instrument restrictions that attach an economic interpretation to a column; predictive fit cannot choose that interpretation.\citep{exec25_pydyn_choice}

The inspected statsmodels SVAR constructor encodes unknown entries through masks in matrices $A$ and $B$. Its solve path can check an order/rank matrix at the supplied starting values, but an explicit override bypasses those checks. It extracts the optimizer's parameter array and returns solved matrices rather than that optimizer result's full diagnostic object. Its structural moving-average path uses $P=A^{-1}B$. The ordinary VAR orthogonalization instead uses a Cholesky factor by default. These are declared computational choices; neither path supplies the business justification for a restriction or proves global identification from a local numerical rank check.\citep{exec25_pydyn_statsmodels}

One selected likelihood expression also warrants qualification before allowing unrestricted dense $B$. It computes a signed log determinant of the elementwise square of $B$. For the authored symmetric matrix with unit diagonal and off-diagonal entries $1/2$, $\det(B)^2=9/16$ whereas $\det(B\circ B)=15/16$. The ratio is $5/3$. These expressions coincide in some restricted cases but are not generally interchangeable. This exact mathematical witness identifies a restricted-use question for the source path; it does not claim that every fitted model is affected or that an installed version was tested. A native qualification should declare the permitted $A/B$ mask families, verify the likelihood independently, and retain optimization and identification diagnostics.\citep{exec25_pydyn_statsmodels,exec25_pydyn_choice}

\subsection{Proxy alignment, shock normalization and attempted resamples}

The retained macroshock revision offers short-run, long-run, sign and proxy-IV branches. The source contains substantive identification calculations, but a callable branch still needs an observation-identity contract. In its proxy helper, missing instrument entries are filtered and the resulting instrument vector is paired with a suffix of residual observations of the same length. An interior missing instrument can therefore change row correspondence. In an authored three-row example, instrument values $(1,\mathrm{NA},2)$ aligned to residuals $(10,20,30)$ produce the matched inner product $1\cdot10+2\cdot30=70$. Pairing retained instruments with the last two residuals instead gives $1\cdot20+2\cdot30=80$. The inspected public model path passes the arrays to this helper. This witness isolates alignment; it does not assert a package run or validate exclusion.\citep{exec25_pydyn_macroshock,exec25_pydyn_choice}

The same helper resets the full impact matrix inside the loop over instruments, then populates the current column. A corresponding reset appears in the selected bootstrap proxy branch. The authored two-column reset trace ends with only the second identity column retained. Thus a multi-instrument use needs explicit native qualification before earlier columns are advertised as jointly fitted. The impulse-response helper additionally scales the requested shock by the reciprocal of its own-variable impact coefficient. If that coefficient is two, a requested own-variable movement of one uses structural-shock amplitude one-half. The response is not automatically a one-standard-deviation shock, and a zero diagonal is a distinct refusal case.\citep{exec25_pydyn_macroshock,exec25_pydyn_choice}

The resampling paths have different stopping and state contracts. The normal bootstrap samples residual rows; the wild path aliases the model residual array and changes its entries in place. Its loop counts accepted output draws and the inspected loop has no separate attempt cap. A progress expression uses an integer step derived from one tenth of the requested replications, creating a small-request boundary to test. The sign-restriction routine is separate: it does have a rejection-count cap and can return zero-filled summary arrays on that stopping path. A zero-filled unavailable response must not be reported as an estimated zero policy effect. The proposal should preserve requested attempts, accepted draws, abort reason, seed and input-state hashes. No general dependent-time-series calibration follows from implementing either resampling mechanism.\citep{exec25_pydyn_macroshock}

\subsection{A state forecast is conditional on its innovation law}

PyDLM provides a Bayesian dynamic linear-model computation whose retained setup describes an alpha-stage package. In the inspected filtering path, the first prediction after an observation adds innovation according to the discount rule. Consecutive missing observations advance a different prediction branch without another innovation addition. That is a model convention with an uncertainty consequence, not an automatic causal remedy for missing bank observations. With an authored scalar identity transition, initial variance one and discount one-half, the first prediction has variance two. The inspected branch convention retains variance two at the next missing step, whereas a separately stipulated fixed process innovation of one would give variance three. The two numbers answer different model specifications. A banking request must state the missingness and innovation convention and must not label either variance as uncertainty about an intervention without a causal model.\citep{exec25_pydyn_pydlm,exec25_pydyn_choice}

The local discount guard compares values with zero and one, while initialization forms reciprocal square roots of the discounts. Its inclusive endpoints and nonfinite inputs therefore deserve explicit tests; documentation phrasing alone is not a runtime validation contract. Forecasting features supplied to a dynamic component likewise need an availability clock. A future feature can be a forecast input under a scenario without being an identified intervention variable.\citep{exec25_pydyn_pydlm}

\subsection{Conditional reuse and a public qualification program}

Retain the pydynpd comparison and evaluate PyXtabond2 and dynapanel as additional panel references, with calendar conventions made explicit. Use statsmodels VAR as a reduced-form baseline and admit a structural path only for a declared restriction family whose numerical objective and diagnostics have been checked. Macroshock is a candidate for further source repair and matched public trials; the selected proxy alignment, multi-column reset, normalization and bootstrap-state concerns should precede integration. PyDLM is an adjacent forecast/state engine under a declared innovation law. None should be promoted to a general causal service by a common Python API. Source licenses and build declarations are retained, while wheel equivalence, dependencies, support and redistribution terms remain separate qualifications.\citep{exec25_pydyn_choice}

Known-law public experiments can test these contracts before an expensive bank prototype evaluation. Freeze calendar gaps and ordering, valid and invalid moment regimes, known structural rotations and restrictions, weak and missing proxies, multiple instruments, solver failures, repeated calls after resampling and consecutive missing-state horizons. Keep all requested tasks and failures in the evaluation denominator. Match an independent arithmetic reference to each permitted target; then separately assess coverage, width, stability and refusal under the declared sampling law. Authentic bank assignment truth and useful precision remain later inputs.

For a hypothetical 24,000 USD trial, 600 requests imply 40 USD per request, 400 completed fits imply 60 USD per fit, and 300 scientifically accepted results imply 80 USD per accepted result. These exact authored ratios are not measured performance or investment returns. Search tails, remaining delegates and public native trials stay open; source review can supply a decision and a route without declaring capability. The packages have not been validated by execution in this comparison.\citep{exec25_pydyn_choice}
