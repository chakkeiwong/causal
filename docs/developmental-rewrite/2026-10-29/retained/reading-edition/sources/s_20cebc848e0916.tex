\section{Carrying uncertainty through a panel comparison}
\label{sec:exec29-panel-inference-contracts}

A common panel schema must preserve the meaning of uncertainty as well as the numbers it displays. Consider a bank comparing a servicing intervention across branches of different sizes. One output row can represent an average customer effect, another an equally weighted branch effect, and a third a placebo comparison. A common time, estimate and interval table helps the analyst compare them only if the target, clock, uncertainty construction and source labels survive conversion. Otherwise an apparently uniform plot can hide a change of estimand. The selected nonabsdid constructor and tests, together with selected BMisc, parglm and leaps delegates, make these obligations concrete. The dependency versions examined are cutoff candidates, not an observed installed lockfile: BMisc 1.4.10, parglm 0.2.0 and leaps 3.2. Their exact repository identities and inspected ranges support the following comparison; neither compilation nor native execution is inferred.~\citep{exec29_panel_inference_sources}

\subsection{An interval is a claim, not a pair of interchangeable columns}

The selected nonabsdid constructor first requires time and estimate vectors of the same length. Uncertainty vectors can be absent, scalar or of full length; other lengths are rejected. Its interval branch marks a row for derivation when either bound is missing and a standard error is present. It then replaces both bounds with
\[
 [\widehat\theta-z_{1-(1-c)/2}s,\ \widehat\theta+z_{1-(1-c)/2}s],
\]
where $c$ is the supplied confidence level. Thus a supplied lower bound is not necessarily retained when the upper bound is missing. With estimate 10, standard error 2, lower bound 9 and missing upper bound, the selected branch gives approximately $[6.0801,13.9199]$ at $c=0.95$. This is a numerical witness to a conversion rule, not a coverage experiment. A complete native interval $[9,12]$ is retained, even when a different supplied confidence level becomes metadata. Passing an already tidied object through the selected method ignores a new confidence-level request. These are distinct behaviors that a wrapper must expose rather than interpret as successful confidence-level recalibration.~\citep{exec29_panel_inference_sources,exec29_panel_inference_reference}

For a bank, one endpoint might encode a method-specific bound while the other is unavailable because of a failed optimization. Replacing that object with a symmetric normal interval changes the scientific claim. The proposed result contract therefore records the native bounds, native confidence level when known, derivation rule, requested level and a derivation flag. A request to change confidence level requires an identified recalculation path. A partially observed interval should remain partial or be returned alongside a separately labelled derived interval; a successful file conversion is insufficient authority to overwrite its provenance. At the inspected constructor boundary, negative standard errors and reversed bounds are not explicitly rejected. The corresponding negative-standard-error witness reverses a generated interval. This does not assert that every upstream producer permits such input: it identifies validation the common interface cannot assume that this boundary supplies.~\citep{exec29_panel_inference_sources,exec29_panel_inference_reference}

The selected tests exercise ordinary normal intervals, a 90\% request, missing required columns, unknown classes, length mismatches and method relabelling. Other selected files test ordinary aliases and DTA conversions, with DTA cases conditional on haven being installed. They also explicitly expect an unknown fect label to fall back to IFE. Reading these tests establishes their asserted cases; it does not establish that they ran here. The inspected alias file contains no fractional-alias case and the inspected DTA file contains no 32-character naming-collision fixture. Additional admission fixtures must cover partial intervals, invalid uncertainty, mixed metadata and serialization failures. Missing coverage in these selected files is not a claim about the entire upstream test suite.~\citep{exec29_panel_inference_sources}

\subsection{Clocks and labels must remain row-specific}

The constructor converts the displayed clock with integer coercion but derives the pre/post label from the original time. Consequently input time $-1/2$ can become displayed time zero with a pre-period label. Distinct fractional inputs can also become the same integer; this boundary does not reject duplicate converted clocks. For event-study admission, a bank must declare whether time is a calendar period, a relative integer horizon or a continuous duration. The interface should reject a fractional value when an integer horizon is required, while retaining any separately justified continuous clock. Silently truncating it is not a valid mapping between those meanings.~\citep{exec29_panel_inference_sources,exec29_panel_inference_reference}

For an ordinary data frame, the selected coercion takes the first method and outcome labels and recycles them. A two-row input labelled methods A and B and outcomes arrears and loss can therefore emerge with A and arrears on both rows. The proposed CLI/MCP contract must partition by homogeneous method and outcome or reject the ambiguous table before conversion. A list follows a separate per-object conversion and row-binding route. The selected row-binding code does not itself reconcile differing confidence-level attributes; the exact dplyr/tibble behavior remains a dependency question. We therefore do not claim either safe preservation or demonstrated loss of those attributes. Row-level uncertainty provenance removes reliance on a single table attribute and makes the unresolved dependency test explicit.~\citep{exec29_panel_inference_sources,exec29_panel_inference_reference}

\subsection{A bootstrap normalization must follow the estimand}

Let $\phi_i$ be the influence contribution for customer $i$, let $N$ be the number of customers, and let $C_g$ be the customers in branch $g$, with size $n_g$. For a declared unit-average linearization, an independent symmetric-sign reference perturbation is
\[
 T_U^*=\sum_{g=1}^{G}U_g\frac{\sum_{i\in C_g}\phi_i}{N}.
\]
The selected fastdid cluster branch instead forms the within-cluster mean. The selected BMisc multiplier function takes a signed sum of its input rows and divides by their number. Composing these two selected transformations yields
\[
 T_C^*=\sum_{g=1}^{G}U_g\frac{\sum_{i\in C_g}\phi_i}{G n_g}.
\]
For equal cluster sizes these expressions coincide. With unequal sizes they need not. This algebra concerns the supplied influence representation: a complete native derivation could require additional weighting upstream, and that path must be checked before attributing an estimator-wide defect.~\citep{exec28_panel_delegates,exec29_panel_inference_sources}

An exact counterexample makes the target distinction visible. Take two branches with sizes one and three and influence rows $(3,-1,-1,-1)$. Their sum is zero. For the unit-average target the sign coefficients are $(3/4,-3/4)$ and, under the explicitly assumed independent symmetric signs, the variance is $9/8$. For the composition based on branch means the coefficients are $(3/2,-1/2)$ and the variance is $5/2$. Enumerating the four sign assignments reproduces both quantities; an equal-size fixture makes the two laws agree. The exercise demonstrates a normalization mismatch relative to the declared customer-average reference. It does not establish that an equally weighted branch target is invalid or that native confidence intervals have a particular coverage rate.~\citep{exec29_panel_inference_reference}

The selected fastdid uncertainty path estimates scale from the empirical type-1 interquartile range divided by the normal interquartile range, maps near-zero scales to missing, filters nonfinite simultaneous maxima, and floors or replaces the critical value with a pointwise normal quantile. The variance witness is therefore not a calculation of the package's reported standard error. The proposed public trial records cluster sizes, influence normalization, all attempted draws, missing scales, filtered maxima and the reason for any critical-value fallback. It includes unequal-size and equal-size cases separately. BMisc's inspected implementation divides by the input row count; an adjacent helper's explanatory comment mentions an additional square-root factor that its code does not apply. The packed-bit multiplier generator also needs its exact Rcpp sampling path qualified before an independent-sign law is attributed to it. The reference enumeration deliberately makes no such attribution.~\citep{exec28_panel_delegates,exec29_panel_inference_sources,exec29_panel_inference_reference}

\subsection{Numerical delegation and model selection need explicit contracts}

The inspected parglm interface exposes LINPACK, LAPACK and FAST methods, defaults to tolerance $10^{-8}$ and 25 iterations, rejects more columns than rows at its fit boundary, and returns convergence, rank and pivot information. Its own summary and covariance methods contain pivot-aware covariance handling. The selected fastdid caller suppresses warnings from the fit, changes its class to glm and then requests covariance through stats. That combination is a concrete dispatch risk: diagnostic warnings and method-specific covariance behavior may not reach the consumer. It is not yet a demonstrated numerical covariance error. The required comparison pins R stats summary and covariance methods and their QR path, then uses full-rank, rank-deficient and nontrivial-pivot fixtures to compare coefficients, aliases, covariance order and convergence. A port must preserve these statuses as data, including failed fits, before a successful coefficient vector is admitted.~\citep{exec28_panel_estimator_sources,exec29_panel_inference_sources}

The selected pampe call delegates subset search to regsubsets, explicitly sets really.big to true, and then chooses the model minimizing the requested information criterion before fitting OLS on pretreatment data. The selected leaps R implementation defaults to exhaustive search and normally guards large predictor or nbest settings unless that override is supplied. The inspected Fortran XHAUST routine uses residual-sum-of-squares bounds to prune its search; selected singularity and tolerance routines show that rank handling is part of the algorithm, not only of the final regression. These observations justify a concrete resource contract: cap donor count, subset size, search method and elapsed work; preserve forced-in/out constraints, rank changes, original variable order and all search failures. An adapter may offer a separately named forward-search alternative, but cannot silently describe it as the same exhaustive procedure. Model selection on pretreatment fit also does not by itself justify causal post-treatment uncertainty.~\citep{exec28_panel_delegates,exec29_panel_inference_sources}

Conditional reuse follows from these distinctions. nonabsdid is a useful conversion candidate if a validating layer preserves native intervals, integer clocks and row labels. BMisc is a candidate computational primitive after the influence target, normalization and RNG law are pinned. parglm is a candidate numerical delegate when solver status and method dispatch survive the wrapper. leaps is a candidate bounded subset engine with an explicit search budget and selection-aware interpretation. DESCRIPTION declarations identify GPL-3, GPL-2 and GPL-at-least-2 respectively for the selected BMisc, parglm and leaps candidates; they do not close transitive rights or redistribution review. Neither a Java nor a C++ port can be accepted merely because it reproduces table shapes. The next public fixtures must establish the same target and failure semantics through the complete native dependency path. Unknown counterfactual trends and unqualified dependent-data uncertainty remain scientific limits that these adapter repairs cannot remove.~\citep{exec29_panel_inference_sources}
