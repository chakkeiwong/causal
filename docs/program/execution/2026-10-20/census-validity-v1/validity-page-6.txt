Note. ✔ = Required. Recommended = Recommended but not always essential. Conditional = Required
only if the specific design calls for it. N/A = Not Applicable.
¹Required for tools intended for repeated use or scaled application (e.g., text classifiers), not for one-off
   tasks such as generating a specific set of experimental stimuli.
²Required only if the research tool uses a multi-item scale to measure a single construct.
³Causal interventions—such as ablation studies, activation patching, or model editing—that test whether
   the model’s behavior is produced by the hypothesized mechanism; this goes beyond the behavioral
   response-process evidence required for evaluation targets.
⁴Required when validating a tool against a pre-existing standard (e.g., convergent validity with human
   coders or established instruments).
⁵Mandatory when the simulation is deployed in high-stakes contexts (e.g., clinical or educational
   applications).
⁶Required only if the study experiments on the tool itself (e.g., effects of prompting strategies on
   classification accuracy).
⁷Required only if an experiment tests whether a manipulation causally changes the model’s behavioral
   patterns (e.g., its “personality” or other psychological tendencies).
⁸For simulators, external validity refers specifically to demonstrating that the model’s aggregate outputs
   correspond to a well-defined human population’s data.
⁹Required for any research tool that produces quantitative data intended for subsequent statistical
   analysis.
¹⁰For single-model evaluation-target studies, measurement invariance is not applicable. When scores
   from multiple models, model versions, or systematically varied prompt populations are compared,
   measurement invariance across those groups may need to be established before score differences are
   interpreted as construct differences.
¹¹Required before interpreting direct human–LLM score comparisons. At minimum, the instrument must
   exhibit scalar invariance (for continuous indicators) or threshold invariance (for ordinal indicators)
