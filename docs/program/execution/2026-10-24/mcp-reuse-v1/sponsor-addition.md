
### Cross-language MCP integration preserves the scientific contract

The comparison resolves the protocol/SDK, FastMCP, R, Java and C++ reuse
questions into eight pinned implementation profiles and five proposal
reference decisions. Protocol revision, software artifact, transport and
application schema remain separate. The selected Python SDK migration,
TypeScript cache behavior, Java validation configuration, R structured-result
conversion and three C++ callback paths require explicit adapters. A returned
protocol message does not establish that a causal result is identified or
that a remote side effect has stopped. The pinned source comparison supports
conditional public prototypes, with native qualification still open.

The proposed public suite checks exact scientific equivalence through the
library, CLI and each declared MCP adapter, using generated graphs,
identification/refusal oracles, units, uncertainty sets and information clocks.
It also checks missing versus zero, schema configuration, pagination,
cancellation, late results and duplicate economic actions. In an authored
100-request example, 90 returned, 80 tool-success and 60 qualified results
give a 60% all-request qualified yield. Hypothetical cost of 18,000 USD is
180 USD per submitted request, 200 per return and 300 per qualified result.
No native benchmark, measured price or bank ROI is claimed.
