4. Evaluation
4.1. Datasets and Experiment Settings
We evaluate our approach in (A) biomedical domain, focusing on 3 types of causality: gene-
gene (GENEC [22]), drug-side effect (DDI [27]), and gene-disease (COMAGC [28]), and (B)
open-domain causality dataset SEMEVAL [29]. We used GPT model using OpenAI API with
gpt-3.5-turbo and text-davinci-003 engines. For experiments with BERT model, we
applied BioBERT [30], PubMedBERT [31] for biomedical dataset and BERT (large, uncased) for
open-domain dataset. Code, dataset and hyper-parameters settings are provided in our Github.
4.2. Results and Discussion
Table 1 summarizes the evaluation results for the biomedical and open-domain datasets. We
report the Precision (P), Recall (R), and F1 scores. We apply 5-fold cross-validation and the
scores are averaged. We report the standard deviation values of the F1 scores over the 5-folds
as shown in parenthesis in Table 1.
