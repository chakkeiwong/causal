19: #'  If not set, all observations have same weight. When weights are
20: #'  time-invariant (constant within each unit across periods), all
21: #'  \code{fix_weights} options produce identical results and no special
22: #'  handling is needed.
23: #'
24: #'  When weights vary across time (e.g., time-varying population sizes),
25: #'  the default behavior differs by panel type:
26: #'  \describe{
27: #'    \item{Balanced panel}{Each 2x2 DiD comparison uses the weight from the
28: #'      earlier of the two time periods involved. For post-treatment cells,
29: #'      this is the base period (g-1). For pre-treatment cells with
30: #'      \code{base_period="varying"}, this is the pre-treatment period itself.
31: #'      The panel DRDID estimators are used.}
32: #'    \item{Repeated cross sections and unbalanced panels}{Both periods'
33: #'      per-observation weights are passed directly to the RC DRDID estimators,
34: #'      so each observation carries its own period-specific weight.}
35: #'  }
36: #'  Use the \code{fix_weights} argument to override the default behavior.
37: #' @param fix_weights Controls how time-varying sampling weights are resolved.
38: #'  Only relevant when weights vary across time; with time-invariant weights on
39: #'  a balanced panel, all options produce identical results.  On an unbalanced
40: #'  panel, \code{"base_period"} and \code{"first_period"} additionally restrict
41: #'  the sample to units observed in the anchor period (a warning is issued), so
42: #'  they can differ from the other options even with time-invariant weights.
43: #'  Options:
44: #'  \describe{
45: #'    \item{\code{NULL} (default)}{For balanced panel: uses the weight from
46: #'      the earlier of the two time periods in each 2x2 comparison. For
47: #'      post-treatment cells, this is the base period (g-1). For
48: #'      pre-treatment cells, this depends on the \code{base_period} setting.
49: #'      For RC/unbalanced panel: uses per-observation weights from both
50: #'      periods.}
51: #'    \item{\code{"varying"}}{Uses per-observation, period-specific weights
52: #'      for all panel types. For balanced panel data, this switches to the
53: #'      repeated cross-section DRDID estimators so that pre-period and
54: #'      post-period observations each carry their own weight. Covariates
55: #'      are held fixed at their pre-period values (same as the default
56: #'      panel estimator). This is the most flexible option for weights but
57: #'      sacrifices the efficiency of the panel estimator. For RC/unbalanced
58: #'      panel, this is identical to the default. Not supported with custom
59: #'      \code{est_method} functions.}
60: #'    \item{\code{"base_period"}}{Fixes weights at the base period (g-1) for
61: #'      all (g,t) cells within a group, for both pre-treatment and
62: #'      post-treatment comparisons. Ensures all cells within a group use the

64: #'      period are dropped with a warning. Not supported for repeated cross
