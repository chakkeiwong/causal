# LLM-assisted experiment selection

Continue LL.TASK.active_experiments. The proposed use is to translate a bank
decision into a constrained menu of information acquisitions, propose competing
mechanisms, and explain a numerical design calculation. A model query, a
simulator action and a real bank intervention have different observation laws
and costs. The proposal must not interchange them.

Re-inspect the three mapped primary PDFs (Lampinen 2023, Verma 2025 version 2,
Murphy 2026 version 5), including adverse results, assumptions and evaluation
denominators. Reassess the saved search/candidate omissions; inspect concrete
package leads and record rights/version/source limits. No live model or bank
experiment is needed for this literature-and-design operation.

Develop a finite exact banking example: the information-rich experiment can
be irrelevant to the deployment decision, while a less informative experiment
can have positive decision value. Compare random, information-gain and expected
decision-value policies with the same one-acquisition budget. Add fixed costs,
failed acquisitions, repeated correlated expert answers and model-support
misspecification. Enumerate exact probabilities before discussing Monte Carlo.

Review the utility clock, information access, units, design constraints,
prespecified loss and stopping rule; separate a stipulated planning calculation
from a sampled performance claim. Write a connected chapter and integrate it
into a preserving reader. Record pass only for actually reviewed task criteria;
retain unavailable package and scientific claims as explicit limitations.
