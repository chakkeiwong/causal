## Stata integration must preserve the command-specific scientific target

The reference decision compares documented Stata capabilities across treatment
effects, panels, survival, dynamic models, missingness and state inference.
A conditional licensed worker must name its exact command, artifact, target,
sample, weights and uncertainty. Single-user or network license descriptions
do not by themselves settle an agent-facing server entitlement. Separately
maintained Stata packages retain their own source and rights obligations.
\citep{exec24_stata_choice}

Exact authored examples show why those contracts matter. Different weights
on the same heterogeneous effects give 70,000 or minus 20,000 USD for a
10,000-account target. A repeated-branch-shock example understates standard
error tenfold if accounts are treated as independent. Omitting between-
imputation variation halves an illustrative standard error. Retrospective
smoothing can also use information unavailable at the original decision.
These are mathematical witnesses, not observed native Stata failures.
\citep{exec24_stata_choice}

Public fixtures should test targets, clustering, cohort aggregation, pooling,
information time and failure-preserving execution. The proposal retains
reference use and conditional integration while leaving current service
rights, artifact support and native performance unresolved. Hypothetical
30,000 USD over 1,000 submitted, 750 completed and 500 qualified requests
gives 30, 40 and 60 USD respectively. Actual bank value remains unmeasured.
\citep{exec24_stata_choice}
