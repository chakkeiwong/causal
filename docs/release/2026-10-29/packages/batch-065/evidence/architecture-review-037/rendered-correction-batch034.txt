   A final output keyed by unit identifier can recover four unique units, provided the values
belong to the same semantic request and the final commit is atomic or otherwise conflict
checked. The history still contains six write attempts. Deduplicating the result must not erase
the partial attempt, its cost or its failure. Conversely, overwriting a key with a result from a
different target or data vintage is not valid idempotency. Identifier equality alone does not
establish scientific equality. The proposed adapter must distinguish a repeated delivery of the
same result from a conflicting new result.


83.1.2    Job status and request status answer different questions

The current Databricks monitoring manual distinguishes “Succeeded with failures” from
ordinary success and explains job outcomes in terms of leaf tasks. A final task that tolerates
an upstream failure can complete without establishing that every requested customer cohort
or sensitivity scenario was evaluated. A causal batch therefore needs a request-level ledger
alongside the scheduler’s result: completed, refused, failed, skipped and reused requests remain
distinguishable. (Databricks, 2026c)
   The same manual describes a 48-hour finished-run graph and a 60-day run-history window. It
also explains that one-time API submissions have no saved job name, so searching by that name
does not find them. A durable scientific record should bind the actual run identifier and export
the relevant lineage before its operating display expires. Retention and search convenience
are useful platform features; neither determines the validity of the causal assumptions or the
completeness of the requested workload. (Databricks, 2026c)
   For a declared request set Q, report the requested count together with each disposition
count. Accuracy among returned results and the fraction of requests receiving an admissible
result are different quantities. Retry success must not silently remove difficult requests from
the denominator. A request outside the method’s supported intervention domain needs an
unsupported scientific disposition; a transient storage failure is an operating failure. A refusal
because declared premises conflict is distinct from both. Treating them identically would hide
the appropriate remedy and distort the comparison with another route.
