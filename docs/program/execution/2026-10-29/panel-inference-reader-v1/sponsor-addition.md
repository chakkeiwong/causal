# Panel uncertainty, branch weights and interface fidelity

A common panel table helps a bank compare methods only when it retains the causal target and uncertainty provenance. The selected nonabsdid constructor can replace both interval endpoints when only one is missing, truncate a fractional event time while labelling it from the original value, and recycle the first method and outcome labels across an ordinary data frame. These are specific conversion behaviors, not evidence that every upstream estimator produces invalid data. The proposed interface should validate integer horizons, split heterogeneous results, and preserve native and derived intervals separately. Selected upstream test files were inspected, not executed. For a customer-average target, cluster normalization matters. A branch with one customer and influence contribution 3 and another with three contributions of -1 give sign coefficients (3/4,-3/4) when divided by all four customers. Averaging within each branch and then across two branches gives (3/2,-1/2). Under an authored independent symmetric-sign reference law, their variances are 9/8 and 5/2 respectively. Equal-size branches agree. This exact example identifies a target-dependent discrepancy in the composition of the selected fastdid and BMisc transformations; it is not a native coverage estimate or a universal rejection of branch-average targets. The public qualification trial must inspect the upstream influence normalization, exact dependency versions, random-number path and every missing or filtered result. Two further choices affect integration cost. The selected fastdid fit changes a parglm result to a glm and suppresses warnings, so the exact covariance dispatch and convergence handling need paired fixtures before adoption. The selected pampe call enables large exhaustive subset searches through leaps; a supported service needs an explicit donor/search budget and honest failure responses. The proposed route is conditional integration with tested semantic adapters, followed by bounded public trials.
