# C++ temporal engines and the cost of preserving meaning

The C++ comparison adds four distinct routes: BMR/BM++ posterior VAR kernels, bsvars structural temporal kernels, bssm state-space kernels, and Dazhong Wu's panelvar C++/Python implementation. The inspected pre-cutoff versions expose different contracts for calendar and row identity, recursive versus frozen-time responses, conditional forecasts, state uncertainty and failure status. A native implementation language does not make these contracts interchangeable. [@exec25_cdyn_bmr; @exec25_cdyn_bsvars; @exec25_cdyn_bssm; @exec25_cdyn_panelvar]

For panelvar, the first public trial should test unsorted and duplicate entity/date keys before coefficient accuracy: inspected mask assignment relies on input order, and observed calendar categories do not restore wholly absent dates. Its generalized inverse and stored diagnostic fields require separate rank and interpretation checks. For bsvars, the inspected higher-order lag update and horizon-loop exception handling motivate explicit native fixtures; its Gaussian conditional forecast remains distinct from an intervention. BMR's selected time-varying response freezes one coefficient slice, while bssm's missing-observation transitions preserve process noise and its prediction types separate state and measurement uncertainty. These are scoped source findings and authored boundary examples, not observed failures of installed products. [@exec25_cdyn_panelvar; @exec25_cdyn_bsvars; @exec25_cdyn_bmr; @exec25_cdyn_bssm]

The investment sequence is to freeze a small public known-law portfolio, compare wrappers, kernels and an independent reference, then qualify exact artifacts and rights before expensive bank experiments. Every library/CLI/MCP request must retain entity/date identity, lag convention, origin, shock restrictions, forecast type, random-number state, complete horizon status and all cost denominators. Direct adoption or a port is conditional on those outcomes. The source declarations and compiler settings remain evidence for a rights/artifact review, not blanket clearance. [@exec25_cdyn_choice]

The exact authored illustrations show why a single output count is inadequate. A hypothetical USD24,000 workflow costs USD30 per 800 attempts, USD40 per 600 completions or USD60 per 400 accepted results. None is measured bank ROI. Native performance, remaining search tails, scientific identification, general dependence, visual review and final acceptance remain open. [@exec25_cdyn_choice]
