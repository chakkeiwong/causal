# Dataframe speed must preserve the banking question

Polars receives a source-qualified reference disposition from twenty-one
authenticated files at a revision before the 7 October 2026 cutoff. The
Python source declares 2.0.0 and its matching runtime; the Rust workspace
declares 0.55.1. Distributed releases and native conformance are not
authenticated by those declarations. The proposed worker preserves
customer membership, join cardinality, missing values, information time,
ordering and the selected execution plan. \citep{exec23_polars_sources}

Exact authored examples expose why those contracts affect a decision.
Event duplication changes a supplied customer contrast from 5 to 7.5;
against a stipulated USD 6 threshold, descriptive margins change from
minus USD 1 to USD 1.50. Neither contrast is established as causal.
Observed outcomes 2 and 4 with one missing value permit full-population
means 2 and 14/3. A historical event that arrived after the decision is
ineligible even when a backward event-time join selects it. Overlapping
windows have variance 3/8 where an independence calculation gives 1/4.
These are supplied examples, not package failures or bank measurements.
\citep{exec23_polars_reference}

Following the Python documentation into Rust resolves a narrower
execution question: checked join cardinality bypasses a specialized
streaming path and can create an accumulating in-memory join. Selecting
streaming therefore cannot by itself establish bounded memory. Removing
validation to improve speed changes the accepted-input contract. A
future matched trial must include validation, input scans, fallback,
conversion, output checks and recovery in its costs.
\citep{exec23_polars_sources}

Retain a pinned Python worker and direct Rust integration as candidate
routes; reject a wholesale cross-language port for the present scope
without demonstrated benefit. Explicit artifacts can connect other
languages through the common CLI/MCP contract after conformance work.

inconclusive and 63 open entries. The paired reader has 1010 audited
