## Review and Statistical Limits

The plan review required matched targets, naive and useful established baselines, frozen designs, all-request denominators, separated evaluator truth, and adverse cases. Scientific progress means a checked result changes or substantiates a recommendation. Acquisition counts, interface parity and builds are supporting work only.

The independent numerical implementations agree: explicit dummy-variable regressions check the panel formulas; exhaustive small cases check linkage corrections; directly resampled trajectories check sufficient-statistic refits; 69 new summary cells are recomputed from per-replication records. Source hashes and protected-file hashes pass. These are author-run checks, not independent scientific acceptance.
