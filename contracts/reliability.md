# Selected V8 reference-operation contract

These references accept supplied scientific premises. Validation checks input
compatibility, not whether those premises hold in a bank.

| Operation | Input information and sampling | Output/refusal |
|---|---|---|
| `joint_audited.joint_effect` | signed randomized actions; aligned two-candidate histories; persistent binary pair audit/label; known positive inclusion; iid pair attributes independent of stationary mixing calendar; nondegenerate first-order projections; supplied symmetric error or independent gold labels | Currency effect/interval, pair/calendar/validation variances and inference qualifications; unknown/dependent sampling refused; gold uncertainty reaching .5 yields unqualified rank |
| `gaussian_effect_pivots.effect_confidence` | independent Gaussian ordered Z,A,Y episodes; supplied observed sufficiency, valid randomized encouragement/exclusion or broad latent class | Effect set retaining bounded/two-ray/whole-line topology and qualifications; unsupported dependence/rank refused; false restrictions cannot be detected from API shape |
| `nonlinear_variance.fit` | complete independent main and representative accurate state-audited trajectories; both action transition groups; fixed independently trained observable policy; selected16 model | Currency policy-value interval and per-fit refinement; boundary/information/numerical failures remain unqualified; optimizer is local |
| `chunked_learning.fit_chunked` | bounded mixing calendar; gap compatible with rate/windows; fixed correctly specified (1,X,X0X1); positive Gram and IV slope; mapped or array controls and Y,D,Z targets | Slope/interval and held-out scores/inference; QR fitting avoids full expanded matrix; O(n) residuals/scores remain; arbitrary learner/rate claims refused |

Copy every inference field when constructing or consuming a result. Preserve
refusals, unsupported sampling, confidence-set topology, units and declared
information. Report larger-window follow-up uncertainty only from its separately
registered rule; the default original windows retain adverse finite-sample
evidence. None of these operations is automatically composable with another
sampling law or inference procedure. No bank acceptance is implied.
