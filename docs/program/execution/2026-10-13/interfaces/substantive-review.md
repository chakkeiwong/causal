# I2 author review

Scope: development of the library, CLI, MCP and client-design chapter. This is
author review of a proposal draft and bounded generated examples; it is not
independent review, current MCP requalification or bank acceptance.

## Scientific and implementation review

The chapter follows one generated servicing question from declaration through
conditional identification, uncertainty, transport, artifact custody and job
handling. The full printed request matches the frozen demonstration request.
Its printed library and CLI paths reproduce the observed canonical expression.
The example has no bank observations, and graph truth remains unverified.

The adjustment argument states potential outcomes, consistency, conditional
exchangeability, positivity, risk integration, sign, USD units and horizon.
The source returns only a supplied-DAG back-door expression. Unsupported
dependent sampling and a contradicted premise receive distinct dispositions;
a failed adjustment attempt is not promoted to general nonidentification.
The explanation correctly separates identification from fitting an estimator.

All four quadratic shapes have elementary algebra independent of the solver:
b²≤4, b²+1>0, −b²−1<0, and b²≥4. Observed arrays preserve finite, empty,
whole-line and disconnected/unbounded topology and nonprobabilistic meaning.
The Gaussian residual inequality was checked against `moment_test_sets`: the
critical value in the squared inequality is the **square** of the normal
quantile, with Bonferroni coordinate adjustment when simultaneous. This was
clarified before publication. The weak-moment result has two unbounded rays;
there is no coverage or arbitrary-bank-estimator performance claim.

Source review follows the actual exception paths, not just the CLI help text.
The table correctly reserves exit three for exceptions reaching the adapter;
runtime-caught artifact errors can instead yield failed canonical envelopes
and exit four. New fixtures confirm exit zero for computed, unsupported and
refused scientific outcomes, and exit four for changed-context input. The
client interpretation includes result kind, disposition and qualification.

The context digest is explicitly declaration identity, not semantic truth or
authentication. Artifact role/schema/custody labels remain operator supplied.
Read restrictions and raw-role exclusion do not imply that summaries contain
no sensitive content. The clock example checks timezone-aware event≤available
<decision, correctly rejecting equality at decision and missing availability.

The official protocol sources and source-level adapter inspection support the
initialize/initialized sequence, returned-version check, structured/text
content, protocol versus tool errors and resource handling. Historical real
MCP trial results are separated from thirteen new library/CLI fixtures.
Neither modern 2026-07-28 protocol nor HTTP, new external clients or a live
model backend is declared implemented. The inherited managed-sandbox SDK
wakeup failure is disclosed rather than hidden by a new library-only pass.

Replay identity was reviewed against its precise contents: it binds the
request apart from correlation/key, source and selected Python/numerical/schema
versions, not every host or installed-package property. Job-query completion
and report-payload state remain distinct. The report example preserves three
scientific declarations and explicitly says schema-only verification. The
same report identity returns a handle on resubmission; cancelling after
completion does not roll back. The text distinguishes protocol cancellation,
local job cancellation and the separate unimplemented MCP task API.

Memory and wall limits are stated as worker bounds, with coordinator/SDK and
startup/transport excluded from any service-level guarantee. Bounded local
leases/checkpoints do not imply distributed exactly-once side effects. CLI,
library, MCP, language wrappers, foreign-function and HTTP alternatives have
concrete tradeoffs; future bank-facing needs are identified without imposing
authentic-bank prerequisites on proposal authoring.
