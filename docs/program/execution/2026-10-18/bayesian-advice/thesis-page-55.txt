4.5.2     Querying the LLM
    The elicitation algorithm is the same as the previous work (described in Section 3.2).
The prompt, however, has a few differences. We do not prompt the LLM directly, instead,
we use DSPy (Khattab, Santhanam, et al., 2022; Khattab, Singhvi, et al., 2024), a library
to build modular AI software. Through this library, we define the input and output’s con-
text. The exact code is in Appendix B.
    The LLM prompt is the following:
    ‘You are an expert on the human immune system cell. You are investigating the cause-
and-effect relationships between a specific set of observed variables representing proteins
and phospholipids: ”Raf”, ”Mek”, ”Plcg”, ”PIP2”, ”PIP3”, ”Erk”, ”Akt”, ”PKA”, ”PKC”, ”P38”,
”Jnk”. Your task is to determine the causal relationship between the given variables. If there
are both indirect and direct relationships between the variables, you should describe only
the direct one.’
