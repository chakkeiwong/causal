# What the proposed studies can establish

These are prospective, bounded prototype studies. Each records an engine source pin and a reviewed request contract; none records an installed environment or executed trial. A future registration must bind source archives, dependency versions and hashes, compiled artifacts, compiler/runtime versions and flags, OS/architecture, BLAS, threading, locale, numeric representation, adapter and harness commits, and complete rights review for the actual use. Those fields cannot be replaced by a package name or a development version. The generator, evaluator and environment must be frozen before generating fresh trial data or observing final results.

R and Java ask the same small observational graph question under declared IID Gaussian laws. Their finite-sample algorithms have different orientation policies, so parity means matching the scientific object and reporting errors under the same law, not forcing identical samples to produce identical graphs. R's separate IDA check uses a supplied valid population CPDAG and covariance. Python asks whether a symbolic intervention functional has the correct semantics. The C++ lane asks whether the grf native core reached through the maintained R path preserves all-population AIPW estimation and uncertainty. Timing across these four tasks is not a meaningful language ranking.

## Exact conformance before statistical screening

All named deterministic valid cases must return the specified object. Invalid and out-of-scope cases must return their specified typed disposition without a fabricated scientific result. A single wrong endpoint, lost isolated node, changed target, unit error, concealed failure, missing provenance or unsupported interval label fails that conformance profile. Exact rational oracle values are compared by exact arithmetic when the representation permits it. For floating values use absolute error at most 1e-10 plus relative error at most 1e-8 in the reported coordinate, with the bound rescaled under a declared unit change. Also require the independently transported error in a USD 1,000-per-success or declared dollar-effect illustration to be at most USD 0.01. The stricter condition applies. These are prototype engineering tolerances, not statistical precision claims or bank-approved losses.

Graph endpoint/object identities and set topology have no numeric tolerance. A two-element local IDA multiset and a three-element global multiset keep their actual multiplicities. No hull, arbitrary DAG, clipped probability or finite placeholder repairs an unsupported object. A typed unavailable answer on a valid supported deterministic request fails availability; the same answer on a prescribed numerical failure can be correct. Every result preserves request, input, configuration and engine/environment digests.

R and Java regular graph studies use two explicitly defined four-variable SEMs at n=500 and n=2,000, with 2,000 independent datasets per cell. The chain is X0=E0, X1=(3/5)X0+E1, X2=(4/5)X1+E2, X3=E3. The collider is X0=E0, X2=E2, X1=(3/5)X0+(4/5)X2+E1, X3=E3. All E coordinates are independent standard normal. Truth is the entire population CPDAG, including X3. PC alpha is fixed at 0.01, full conditioning search within p=4, with each engine's reviewed explicit orientation and failure settings. Column and row permutations are paired conformance checks; they do not create new independent observations for the statistical denominator.

For each graph cell record two Bernoulli events over all requested datasets: (a) failure to return exactly the true CPDAG, including malformed, refused, incomplete and unavailable results; (b) no valid completed graph. The acceptable prototype ceilings are respectively 0.10 and 0.05. A 10% graph error ceiling is a deliberately bounded progression criterion for these easy laws; it is not an edge error guarantee, graph confidence level or universal causal discovery standard. Report adjacency and endpoint errors separately as descriptive diagnostics, with no undeclared selection of a favorable metric. The same request identifiers and generated data are paired across the two engines; failures stay in both denominators. Pairing does not require independent engines, and Bonferroni does not require independent screens.

The grf study has three regular cells, each with n=2,000 independent customer rows and 2,000 independent datasets. Let X0 be Bernoulli(1/2), X1,X2,X3 independent standard normals, and E another independent standard normal. Set Y=50+10X0+tau(X0)W+20E in USD of net receipts over a fixed horizon. Cell F0 has tau=0 and e=P(W=1|X)=1/2; F1 has tau=20 and e=1/2; F2 has tau=-4+16X0 and e=1/5+(3/5)X0. Population ATEs are 0,20,4. F0/F1 use the declared known randomized propensity; F2 uses the retained R nuisance path and OOB predictions. All other forest settings are fixed in the per-language design. No selected subgroup, overlap target or average fitted CATE replaces the all-population target.

An independent known-law score with true outcome surfaces and propensity has variance Var(tau(X))+400 E[1/e+1/(1-e)], hence 1,600,1,600,2,564 for F0,F1,F2. This supplies analytic truth and a precision scale, not a proof of the fitted forest's finite-sample coverage. The oracle mean-score baseline uses the same observations and its own sample-score standard error. A stratified difference-in-means baseline estimates each X0 stratum's effect and averages the two with fixed population weights 1/2; a missing treatment arm is unavailable, never filled in. Its variance is the sum of the four within-arm sample-mean variances times 1/4, with no variance invented when an arm has fewer than two observations. Both baseline intervals are labeled separately and assessed descriptively; their results cannot substitute for the native engine's screen.

For each forest cell, count (a) failure of a finite nominal 95% AIPW interval to cover the true ATE, including every unavailable interval, and (b) failure to produce a finite interval with total width at most USD 10. Prototype ceilings are 0.075 and 0.05. The coverage screen therefore targets at least 92.5%, not a claim that nominal 95% is established; this margin detects material undercoverage with a feasible proposed replication count. The width ceiling is a stipulated screening requirement roughly more than twice the known-law asymptotic widths (about USD 3.5 to 4.4), not a bank-approved precision requirement. Report signed bias, RMSE, interval width and numerical loss on all requests with explicit unavailable counts. Available-only diagnostics are supplementary and labeled. Runtime and cost comparisons cannot compensate for a failed scientific screen.

## Fixed sample sizes and multiplicity

There are eight graph cells across R and Java, two primary events per cell, and three grf cells with two events per cell: 22 primary one-sided screens. Reserve 24 slots and assign alpha=0.05/24=1/480 to each. The two unused slots are not reassigned after results. A gate with ceiling p0 passes only when its failure count K among N=2,000 is at most the largest integer k for which P[Binomial(N,p0)<=k]<=1/480. This is an exact one-sided test of a failure probability at least p0. Its threshold and power at the declared useful alternative are evaluated by rational binomial summation before any native run. Monotonicity gives the bound for all p>=p0; a union bound limits false progression of any active bad screen by 22/480<0.05. It does not provide an unrestricted guarantee outside these fixed IID replication laws.

The declared power alternatives are p=0.05 for graph mismatch with ceiling 0.10, p=0.02 for unavailability/useless width with ceiling 0.05, and p=0.05 for interval noncoverage with ceiling 0.075. N=2,000 was selected analytically to give at least 95% power for the most demanding noncoverage screen under this allocation. Final sample count and ceilings must not change with observed results. Python's finite functional corpus and the deterministic adverse cases require every specified check to pass; they make no probabilistic population-frequency claim and consume no binomial screen slot.

## Adverse regimes and failures

Each design lists numerical, semantic and scientific stress cases. Deterministically detectable invalid input or a declared unsupported sampling law must be refused before publishing a result. Unmeasured confounding, weak faithfulness or undeclared dependence can be statistically indistinguishable from valid inputs; the experiment records the resulting degradation and cannot demand that an engine universally detect them. Stress results are separate from the regular-law screens and never used to tune them. Confidence statements apply only to a justified registered sampling law.

All final trials use a reviewed generator producing one independent stream per cell and replicate, with a separately allocated engine RNG stream. Register the exact generator version, seed custody and derivation algorithm before generating the held-out data. Do not reuse preparation fixtures as final evidence. Generation failures are retained and cannot be replaced after seeing outcomes. Retries keep the same immutable request, receive a new attempt ID and never erase the first attempt from the primary denominator. The first scheduled attempt supplies each primary Bernoulli outcome; later attempts diagnose recovery only.

One local job runs at a time. Proposed hard per-attempt limits are 30 seconds/1 GiB for the small graph and symbolic profiles, 120 seconds/2 GiB for a forest fit, and 2 MiB captured diagnostic output, with an independent parent watchdog. Measure these on a fixed small engineering fixture corpus before registration. If the frozen environment cannot support the study within the available prototype compute allocation, record infeasibility and design a successor before generating final data. This is not permission to run an unbounded experiment or to treat incomplete runs as passing. Hard cancellation, process death and resource limits must return null scientific results with retained diagnostics.

There is no favorable early stopping. Finish the registered requests if feasible. A catastrophic environment or integrity failure stops that attempt with incomplete status; counts so far remain descriptive and cannot pass any screen. The count N includes scheduled requests; an uncompleted final study has no admission claim. No optional resampling, seed search, sample-size extension or selective omission is allowed. A successor design preserves the original result and uses fresh data.

Measure validation, source/environment setup, cold and warm startup, data conversion, fitting/search, uncertainty, serialization, diagnostics, failed attempts, human repair and review separately. Preserve wall/CPU time and peak memory per request plus raw attempts. Descriptive cost reports include all failures and complete workflow totals; no currency ROI is reported without actual prices. Fixed public examples may establish usability and plausibility, but their observational outcomes do not provide known causal truth. Actual bank data and institutional acceptance remain later work.
