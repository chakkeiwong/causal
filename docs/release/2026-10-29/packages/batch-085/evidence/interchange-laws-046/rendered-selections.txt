Chapter 77

Keeping the economic question
intact across methods

An analysis remains the same analysis only if its population, intervention, information and
uncertainty survive each computational step. This chapter first develops that requirement
for coordinates, graph classes and sets. It then examines the evidence from local custody,
recovery and interface trials, before comparing restricted Python identification, Java discovery
and R/native forest routes. Each route has a different scientific domain. Their common
representation makes those domains visible; it does not make their guarantees interchangeable.


77.1     The unit of exchange is an analysis with meaning
A funding service, a servicing notebook and an analyst’s agent may all request an “effect”, while
referring to different populations, actions, horizons and units. Exchanging a floating-point
number is therefore insufficient. The proposed common object contains a scientific context, an
operation, input identities, an execution disposition and a qualified result. The local reference
implementation enforces selected parts of this contract; it does not validate the truth of every
declaration. Causal banking research project (2026a,c)
  For a scalar intervention query, write the context schematically as

                              Q = (P, µ, a, a0 , Y, H, u, s, T , A, G),

where P is the population, µ its weighting measure, a and a0 the intervention and comparator,
Y the outcome, H the horizon, u the units, s the sign convention, T the information clocks, A
the assumptions and sampling declarations, and G the graph or graph class. This mathematical
notation expresses the required meaning; particular schema fields may encode only a supported
subset. The original declaration must be retained when a narrower operation representation is
used.
   Changing a − a0 from a ten-basis-point offer to a one-percentage-point offer changes the
question, even if the same coefficient field can store both. Replacing customer weights by
balance weights changes µ. Treating a post-decision observation as available history changes
T . A digest can detect that the declared context changed. It cannot establish that the context
describes the actual banking process.
  The implementation binds supplied moments and sensitivity artifacts to their scientific
context. Reusing their bytes with a changed sign, clock, unit or target is rejected unless a
new, appropriate artifact is supplied. This prevents a consumer from reinterpreting a cached

77.20      A native forest boundary that preserves the banking
           question
A servicing analyst asks whether making a specified offer changes twelve-month net receipts
for eligible customers. The proposed treatment is the offer, coded one, against no offer, coded
zero. The outcome includes the offer’s cost and is measured in dollars per customer over the
stated horizon. A heterogeneous-effect forest can help estimate this contrast under a declared
identification model. Its C++ implementation cannot decide whether the recorded offer was
randomized, whether all confounders were measured, or whether the analyst actually wants
the mean over customers, branches, or treated customers. Those choices must precede engine
dispatch and survive it.
   The proposed first grf integration uses its maintained R interface in a pinned local process,
which in turn invokes the native C++ core. Direct native embedding is a separate alternative.
Inspection covers commit 5bee99b51471, dated 30 April 2026, whose package description
declares version 2.6.1. The snapshot therefore precedes the literature cutoff; its October
acquisition date is separately retained. The design is not an installed adapter. The executed
examples below are project-owned arithmetic references; they neither train grf nor measure its
statistical performance GRF contributors (2026d); Causal banking research project (2026l,m).

77.20.4     Memory ownership, coordinates and model persistence

The inspected Data class is a read-only view of a borrowed contiguous column-major buffer.
Element (r, c) is read at offset cn + r, where n is the number of rows. Constructing the view
from a temporary vector does not transfer ownership. The host must keep the allocation alive
until all training or prediction threads have finished; it must validate shape, index ranges
and multiplication overflow before the call. A three-row, two-column example has columns
(1, 2, 3) and (10, 20, 30). Correct layout reads twenty at zero-based coordinate (1, 1); passing
row-major bytes to the same index formula reads three. Neither value is a memory error, so a
mere successful call cannot detect the scientific corruption GRF contributors (2026a); Causal
banking research project (2026m).
   Role coordinates must remain separate from predictor coordinates. The native setters
mark outcome, treatment, instrument and weight columns as disallowed split variables. The
host records the ordered covariate dictionary, row identifiers, role indices and training/query
distinction. It cannot infer those roles from whichever columns happen to be numeric. Missing
values in covariates are supported by inspected package paths, but are excluded by the initial
profile so that an undocumented imputation or missingness assumption is not introduced.
