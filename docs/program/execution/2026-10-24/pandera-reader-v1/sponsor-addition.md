## Observation contracts: what a validation pass actually buys

Pandera is a candidate substrate for episode keys, declared units and information-availability rules. The inspected cutoff source distinguishes disabled validation, skipped check scopes, sampled data, warning-only failures and completed checks. It can also transform the table through defaults, coercion, filtering and row removal. Native Polars lazy inputs have a different default check depth from eager inputs, and optional backend dispatch changes the implementation. A pass flag alone cannot carry this meaning. The proposed worker binds input, schema, effective configuration, checks run or skipped, failures, transformations and returned artifact. No native integration is admitted. \citep{exec24_pandera_source}

Exact project-owned examples explain the economic and scientific stakes. A uniform sample of ten from one hundred records with two violations misses both with probability 89/110. A selection rule in a randomized zero-effect example creates a retained observational contrast of one. Two structural worlds share the same valid-looking observed data but have intervention effects one and zero. Schema validity therefore cannot replace identification, and dropped records cannot silently redefine the banking population. \citep{exec24_pandera_reference}

The original Python worker is the preferred conditional prototype; the existing CLI is a reporting comparator whose inspected validation call does not retain the returned transformed object. The direct MIT declaration and selected dependency metadata support a reference decision, not complete distribution or runtime qualification. A proposed MCP service uses approved schemas and immutable artifact identifiers. Agents can draft rules, but their scientific meaning and failure behavior require reviewed public/generated fixtures before costly bank trials. A wholesale cross-language port has no demonstrated advantage over preserving the original semantics. \citep{exec24_pandera_source}

Full workflow cost must use accepted artifacts as well as attempts and correct refusals. For twelve stipulated attempts costing USD 48, eight process successes cost USD 6 each, while three accepted artifacts cost USD 16 each; four correct refusals remain a separate result. These are authored examples, not quoted prices or observed native performance. \citep{exec24_pandera_reference}
